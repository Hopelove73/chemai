# 陌生信息迁移与新情境题

> 一句话定位：本篇管"没见过"的题——信息题的本质是把题干里给的新知识当场学下来、当场用出去，考的是阅读协议不是记忆量。

## 是什么

新情境题的题干结构是固定的三件套：**新信息（资料卡/新反应/新名词）+ 旧知识（高中主干）+ 衔接问**。解题协议四步：

1. **标记信息源**：把题干中"与我们学过的不一样"的点划出来——新物质、新反应、新条件、新名词。新名词（如"某催化剂对反应 X 有选择性"）几乎必然在问题里被引用；
2. **归类旧模型**：陌生物质往熟悉的模型上挂——陌生含氧酸看"几元酸？强酸弱酸？氧化性酸还原性酸？"；陌生有机物数官能团。**挂得上模型就按模型算，挂不上就严格按题干给的方程式算**；
3. **信息型方程式**：条件由信息给（温度、催化剂、介质），产物由信息定（氧化性还原性顺序、介质酸碱性决定产物形态）——写完必过三守恒自查；
4. **警惕信息陷阱**：题干给的信息没用上≈解法错了（信息题不给废话）；但**信息也不是全都要用**——先用问题反推需要哪些信息再回头取用。

**类比迁移的边界**：类比到哪一步要由信息卡住——"X 与 Y 性质相似"只授权相似点范围内的推断，相似范围之外的结论必须由新信息另行给出。这是信息题与超纲的边界线。

## 为什么这样

信息题的命题逻辑是**控制变量地考能力**：新知识人人零起点，差距只在"读出来"与"用出去"。所以一切方法都指向两条——把信息找全（标记法防漏读），把模型挂对（类比法防读懵）。题干信息与问题一一对应是命题纪律，"没用上的信息"就是走错路的信号灯，这也是四步里第 4 步存在的原因。

## 典型例子与方程式

**例（克劳尔法提钛，两步全信息）**：题干给两步反应，第一步氯化：

$TiO_2 + 2C + 2Cl_2 \xrightarrow{\text{高温}} TiCl_4 + 2CO$

第二步镁热还原：$TiCl_4 + 2Mg \xrightarrow{\text{高温}} Ti + 2MgCl_2$。问"第二步在氩气氛围中进行的原因"——旧知识（Mg 高温下与 O₂、N₂、CO₂ 都反应）+ 新情境（Ti 高温活性）合答：**防止高温下 Mg（及 Ti）与空气中的 O₂/N₂ 反应**。信息题的答案常是"新信息定方向 + 旧知识给理由"的合体。

**例（信息型方程式）**：题干告知"Cu 与 FeCl₃ 溶液反应产物为 CuCl 与 FeCl₂"——不猜、按信息写 $Cu + FeCl_3 = CuCl\downarrow + FeCl_2$，用铜守恒与氯守恒自查即配平。感觉"应该是 Cu²⁺"而去改产物，是信息题第一大丢分动作。

## 常见易错点

- **"题干信息扫一眼知道大概就行"**：错。信息题的采分点精确到具体数值与条件（"60 ℃""pH≈3"），漏读一个条件整问作废，必须圈划。错因是按阅读理解的速度读化学题。
- **"陌生物质反正不认识，凭感觉写产物"**：错。陌生物质的产物**全部由题干信息指定**（氧化性强弱表、介质、催化剂选择性），感觉没有入场券。错因是把信息题当默写题。
- **"类比可以直接推到性质全面相似"**：错。类比只在题干授权的范围内有效（"与氯相似"≠"也能制漂白粉"），越界的类比必须回到信息。错因是把类比的启发性当成了证明力。
- **"新名词看不懂就跳过"**：错。新名词是命题人的"问题锚"，通常原词出现在设问里；跳过它等于跳过答案的一半。错因是恐惧驱动的回避。
- **"写完方程式直接进入下一问"**：不规范。信息型方程式**必过三守恒自查**（原子/电荷/电子），信息给错的概率为零，写错守恒的概率很高。错因是省掉了免费的验算。
