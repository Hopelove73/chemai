# 化学图像信息题方法

> 一句话定位：本篇把"看图说话"变成"按 protocol 看图"——五看顺序扫图，由图建式、由式验图双向校验，覆盖速率/平衡/滴定/电解四类高频图像。

## 是什么

**图像五看**，顺序固定：
1. **看轴**：横纵坐标各是什么量、单位、是否从 0 起（"转化率-温度"与"转化率-时间"是完全不同的两道题）；
2. **看点**：起点（投料状态）、交点（两线相等处，常是平衡点/等浓度点）、拐点（机理或状态切换处）、**特殊点**（恰好中和点、半中性点）；
3. **看线**：走势（增/减/先增后平台）、**平台=平衡或完全反应**（区分靠"时间轴有无"）；
4. **看斜率**：斜率代表变化速率——浓度-时间图的斜率即反应速率；温度渐变图的斜率变化提示速率变化；
5. **看条件标注**：图上的虚线、温度压强标记、"其他条件相同"字样——这是曲线间比较的前提。

**四类高频图像的读图锚点**：
- **速率-时间**（v-t）：正逆速率线重合且不为零 → 平衡态（$v_正 = v_逆 \neq 0$）；条件改变后两线谁上谁下直接读移动方向；
- **转化率-温度/压强**：多线比较用"定温看压、定压看温"，先固定一个变量再读另一个；
- **滴定曲线**：起点 pH 定酸碱强弱（弱酸起点 pH>1 数量级）、突跃跨度定强弱组合、半中和点 pH = pKa（弱酸）、过量段平台由过量试剂决定；
- **电解图像**：析出-耗电量的斜率对比法定放电顺序，转折点=某离子耗尽。

**双向校验**：由图建式（把曲线特征翻译成方程/不等式）之后，把式子代回图上特殊点验证——算出的交点坐标对不上图，就是建式错了。

## 为什么这样

五看的顺序是为防"看图先看结论"的直觉错误：轴都不对，后面全错。先轴后点再线，是从"坐标系是什么"到"数据说了什么"的逻辑序——化学图像题一半的错误发生在把纵轴认错（速率还是转化率、浓度还是百分含量）。

平台期区分"平衡"与"反应完全"，判据是横轴：横轴是时间且量不变 → 平衡（宏观静止微观进行）；横轴是温度且量不变 → 该温度下完全反应（如分解完全）。锚点固定，两类图像就不会互相污染。

## 典型例子与方程式

**例（v-t 图）**：某平衡体系 t₁ 时刻 v正 突然增大、v逆 逐渐增大至与 v正 再次重合，且新平衡位置更高。读图：v正 突增 → 浓度或温度条件变化；v逆 **渐变不突变** → v逆 靠浓度累积才上来 → 条件是"增大反应物浓度"；新平衡正逆速率都高于原平衡，自洽。读图结论与勒夏特列原理互验。

**例（滴定曲线）**：0.1 mol/L NaOH 滴定 20 mL 0.1 mol/L 醋酸：起点 pH≈2.9（弱酸部分电离）；半中和点（加 10 mL 碱）pH≈4.7；突跃在碱性区（计量点产物水解）。由"起点 pH 不等于 1"建式：醋酸不完全电离——图像读出了 Ka 的数量级。

## 常见易错点

- **"先看曲线形状再说别的"**：错。轴与单位不确认，形状会讲一个完全不同的故事（转化率随温度下降≠放热，可能是"时间-温度"复合图）。错因是视觉直觉抢在协议前面。
- **"曲线相交就是平衡点"**：不准确。v-t 图中 v正 与 v逆 相交是平衡；但 c-t 图中两物质浓度线相交只说明**此时浓度相等**，与平衡无关。错因是把"交点"当万能标记。
- **"平台一定是平衡"**：错。横轴是温度/压强的图里平台是"该条件下进行到底"，与化学平衡无关；判定必须回看横轴。错因是背了"水平线=平衡"。
- **"滴定曲线的突跃中点就是 pH=7"**：错。只有强酸强碱互滴计量点才是 7；弱酸强碱计量点 pH>7（水解），突跃中点随之偏移。错因是把"中性点"与"计量点"混同。
- **"读图得出结论就完事"**：不规范。由图建的式要代回特殊点**双向校验**，特殊点对不上必须回到第 3 步重新读线——这是图像题免费的验算环节。错因是省略校验直接写答案。
