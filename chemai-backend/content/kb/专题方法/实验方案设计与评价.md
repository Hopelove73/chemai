# 实验方案设计与评价

> 一句话定位：本篇把"设计一个实验"从拍脑袋变成四原则加一条设计链路——实验大题最后一问的满分模板。

## 是什么

**方案设计四原则**，评价与设计共用：
1. **科学性**：原理正确——检验 SO₂ 不能用"使品红褪色"下结论就完事（还要看能否恢复），更不能用支持燃烧/灭火这类不特异的现象；
2. **安全性**：不产生危险、不放出有毒气体外逸（如用铜与浓硝酸设计产 NO₂ 的实验必须带尾气吸收）；
3. **可行性**：条件中学实验室能实现——不要写"用 pH 计精确到 0.001"这类仪器达不到的要求；
4. **简约性**：步骤少、易操作、现象明显。

**对照与变量控制**：探究类实验必须**单一变量**——探究浓度对速率的影响，其他条件（温度、体积、催化剂、固体的表面积）全部保持一致；需要"空白对照"时设一组不加待测物/不加试剂的平行组，排除空气、溶剂本身的干扰。

**设计链路五步**：**实验目的 → 反应原理 → 装置选择 → 操作步骤 → 结论表述**。命题人常在前三步设卡：目的里"验证……"决定原理选型，原理决定要不要干燥、要不要防倒吸。

**评价题答法**：先指出方案的科学性问题（原理错/有干扰/不唯一），再给改进——"该方案不合理，因为 O₂ 也能使……，应先除尽 O₂（或改用……）"。

## 为什么这样

单一变量是因果推断的底线：速率类探究里若温度也不同，速率变化就无法归因于浓度。对照实验的本质是**把"不变的一切"钉死，让差异只剩一个来源**。

评价优先于设计的顺序也来自科学性原则：中学范围内"现象支持结论"必须满足**现象唯一性**——能使溴水褪色的不只是 SO₂（还有不饱和烃、还原性物质），不排除干扰就下结论，是科学性硬伤，也是评分细则的第一档。

## 典型例子与方程式

**例（评价型）**：某同学设计"验证 SO₂ 有氧化性"：将 SO₂ 通入氢硫酸出现淡黄色浑浊。评价：方案合理——$SO_2 + 2H_2S = 3S\downarrow + 2H_2O$，S 单质只能来自两者中 +4 价硫被还原，现象与结论唯一对应。

**例（设计型）**：设计实验比较碳酸与次氯酸的酸性强弱：将 CO₂ 通入 NaClO 溶液。原理：强酸制弱酸，$CO_2 + H_2O + NaClO = NaHCO_3 + HClO$（CO₂ 少量时），出现"溶液变酸性的间接证据"（pH 下降/石蕊先红后褪需讨论）——设计时先写原理再定装置，就是设计链路的用法。产气端用 $CaCO_3 + 2HCl = CaCl_2 + H_2O + CO_2\uparrow$ 时要注意 HCl 挥发干扰，需先通过饱和 NaHCO₃ 溶液除 HCl。

## 常见易错点

- **"设计实验时不用写排除干扰的步骤"**：错。干扰排除（除杂、对照、验纯）是科学性的一部分，缺了它现象不唯一，方案直接降档。错因是只想着"主反应对不对"。
- **"对照组就是什么都不加的一组"**：错。对照组是**不加自变量**但其余条件完全相同的一组；什么都不加连溶剂环境都变了，对照失效。错因是把对照理解成"空白"两个字。
- **"评价方案只说'不对'就够了"**：错。评价必须**指出问题+给改进**，只判不改不得全分。错因是把评价题当判断题。
- **"探究温度影响时用酒精灯直接加热更方便"**：不严谨。温度变量要可控可测，直接加热升温速率难固定，应用水浴并记录恒定温度。错因是把"能升温"当成了"控制了温度"。
- **"结论写成'证明该反应是放热反应，因为温度计读数升高了'"**：不规范。要写明对照基准（与初始温度相比、排除量热误差），单一读数不定案。错因是把现象当充分条件。
