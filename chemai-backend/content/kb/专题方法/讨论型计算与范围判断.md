# 讨论型计算与范围判断

> 一句话定位：本篇管"答案不止一种"的题——过量判断切区间，边界点定界碑，分段讨论不留缝也不重叠。

## 是什么

**过量判断**：两反应物都给量时先比"谁先用完"——把双方都换算到同一反应的比例上，实际比大于系数比的过量。判断完了才谈计算，**用不足量算产物**。

**分段讨论的通行结构**：连续反应体系按"第一反应进行到什么程度第二反应开始"切分区间，每个区间产物的种类与量是确定的函数。以 CO₂ 通入 NaOH 溶液（设 n(CO₂)/n(NaOH) = x）为例：
- **x < 1/2**：碱过量，只发生 $CO_2 + 2NaOH = Na_2CO_3 + H_2O$，产物 Na₂CO₃（剩 NaOH）；
- **x = 1/2**：**边界点**，恰好全部生成 Na₂CO₃；
- **1/2 < x < 1**：先全部生成 Na₂CO₃，过量的 CO₂ 继续反应 $CO_2 + Na_2CO_3 + H_2O = 2NaHCO_3$，两者共存，可用守恒联立求各自量；
- **x = 1**：边界点，全部为 NaHCO₃；
- **x > 1**：CO₂ 过量，产物仍全是 NaHCO₃（NaOH、Na₂CO₃ 耗尽）。

**边界点验证**：每个区间的交界点（x = 1/2、x = 1）必须单独代入检验——它属于哪一段、产物是什么、公式是否连续。边界写错是讨论题最常见的整段失分。

**范围表达**：不等号方向与"含不含边界"要跟物理事实一致；答案用集合或分段函数形式写清"x 取值 → 产物及计算式"。

## 为什么这样

分段讨论之所以必要，是因为**产物组成是投入比的阶跃函数**：碱多时把碳全压成 +4 价的 Na₂CO₃，酸多时只能到 NaHCO₃。两个稳态之间必有一个过渡带（两盐共存），过渡带内比例连续变化——不切区间就无法写出唯一算式。

边界点优先验证，是因为所有区间的公式在边界上必须衔接：若 x = 1/2 处两段公式给出不同的 n(Na₂CO₃)，说明哪一段的系数或守恒式错了——边界是自查的免费锚点。

## 典型例子与方程式

**例**：0.8 mol CO₂ 缓缓通入 1.0 L 1.0 mol/L NaOH 溶液，求产物。x = 0.8，落在 (1/2, 1) 过渡带。设 Na₂CO₃ a mol、NaHCO₃ b mol：碳守恒 a + b = 0.8；钠守恒 2a + b = 1.0。解得 a = 0.2、b = 0.6。两个守恒方程解过渡带，是本类题的标准收尾。

**例（多过程）**：Fe 与稀硝酸反应，n(Fe)/n(HNO₃) 从小到大，产物从 Fe³⁺ → Fe³⁺/Fe²⁺ 共存 → Fe²⁺ 分段——同一框架换一对反应而已。

## 常见易错点

- **"两物质量都给了就直接用系数比小的算"**：错。要先**判断过量**再选用谁；连"谁不足"都没定的计算是空中楼阁。错因是把公式套用置于判断之前。
- **"边界点随便归到哪一段都行"**：错。边界点上产物唯一（如 x = 1/2 恰好全为 Na₂CO₃），归错段则该点结果错；阅卷通常单设边界分。错因是不验证衔接。
- **"讨论区间可以重叠或留缝"**：错。区间必须**不重不漏**覆盖全部取值，漏区间就是漏情形，重叠区间会解出矛盾。错因是按感觉分段不按反应进程分段。
- **"讨论完不用写结论"**：不规范。每段末尾必须落"当 x …时，产物为 …，其物质的量为 …"的完整结论句。错因是算完即止忘了答题的完整性。
- **"分段越多越好，显得严谨"**：低效。段的数量由反应进程决定，与"严谨感"无关；能合并的区间合并，能整体处理的（如 x > 1 段产物与 x = 1 相同）不必硬拆。错因是把形式当内容。
