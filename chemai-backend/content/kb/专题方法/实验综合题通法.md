# 实验综合题通法

> 一句话定位：本篇是实验综合题的"读图语法"——一套看装置、说理由、写现象的通用顺序，适用于五册所有实验大题的第一问。

## 是什么

实验综合题的装置图再复杂，也遵循一条**主线顺序**：**气体制备 → 净化除杂 → 干燥 → 主体反应 → 收集/检测 → 尾气处理**。读图按这个顺序走，每问就能对号入座。

**仪器与装置的作用分析**按"防什么"归类：
- **除杂瓶**（盛饱和食盐水除 HCl，盛饱和 NaHSO₃ 除 SO₂等酸性气体）；
- **干燥管/洗气瓶**（浓硫酸、无水 CaCl₂、碱石灰，按气体酸碱性选）；
- **防倒吸**：倒扣漏斗、干燥管口朝上、肚容式导管——凡极易溶气体（NH₃、HCl）进水必设；
- **安全瓶**：两端短进短出的空瓶，防主体装置中的液体倒吸回前级；
- **尾气处理**：有毒气体必处理——Cl₂ 用 NaOH 溶液吸收，NH₃ 用水（加防倒吸），CO 点燃烧掉。

**气密性检查通法**只有一条原理：**封闭体系制造压强差，观察是否复原**。常见三式：微热式（手握试管，导管口有气泡冒出、松手后回升一段水柱）；液差式（从漏斗加水封住颈口，继续加水形成液面差，静置不变化则气密）；抽气式（注射器外拉，长颈漏斗下端口冒气泡）。

**现象描述规范**：按"眼→鼻→手"的感官通道写，**只写现象不写结论**——写"产生白色沉淀"而不写"生成 BaSO₄"；写"溶液变红"而不写"溶液显酸性"。必要时带量词与位置："导管口有气泡均匀冒出""液面分层，上层呈紫红色"。

## 为什么这样

装置顺序由气体逻辑决定：不先除 HCl，Cl₂ 与金属反应的实验里 HCl 会参与副反应；不干燥，水蒸气会让"遇水变质"的物质（如 Na₂O₂、无水 CuSO₄ 检验设计）失效。**每一级装置都是为下一级服务的**——问"该装置的作用"，先看它后面是什么。

防倒吸的本质是压强骤降：NH₃、HCl 一接触水就几乎全溶，管内压强瞬间低于大气压，水被压入导管。倒扣漏斗的容积让液面上升时脱离漏斗口、压强回弹，切断倒吸链条。

## 典型例子与方程式

电解饱和食盐水（氯碱工业，装置主线最完整）：

$2NaCl + 2H_2O \xrightarrow{\text{电解}} H_2\uparrow + Cl_2\uparrow + 2NaOH$

阳极产 Cl₂（黄绿色、使湿润淀粉碘化钾试纸变蓝），经饱和食盐水除 HCl、浓硫酸干燥后收集；Cl₂ 有毒，尾气用 NaOH 吸收：

$Cl_2 + 2NaOH = NaCl + NaClO + H_2O$

答"尾气处理装置作用"的标准句式：**吸收多余的 Cl₂，防止污染空气**。

## 常见易错点

- **"气密性检查先装药品再检查"**：错。气密性检查必须在**装药品之前**完成——装了药品再发现漏气，整组药品报废且可能有危险。错因是把检查当成装配的最后一步。
- **"洗气瓶导管长短无所谓"**：错。洗气必须**长进短出**（进气管插入液面下），短进长出会把瓶内液体压出去。错因是只记"洗气瓶"没记流向。
- **"干燥 NH₃ 可以用浓硫酸"**：错。NH₃ 是碱性气体与酸反应，只能用碱石灰干燥。错因是把"浓硫酸常用干燥剂"当成了万能规则。
- **"现象里写出生成物名称更准确"**：错。现象只写感官事实，写名称等于抢了结论的活——阅卷按"现象/结论"分层给分，混写丢分。错因是不区分"看到什么"与"推出什么"。
- **"尾气用大量水吸收 Cl₂ 就行"**：错。Cl₂ 在水中溶解度有限（1:2），要 NaOH 溶液吸收才彻底；NH₃ 则相反，极易溶于水、吸收时必须防倒吸。错因是用"水能吸收"一概而论。
