# 化学计算常用方法

> 一句话定位：本篇是化学计算的"工具箱"——守恒、差量、关系式、极值、三段式五件工具，按题干特征选工具而不是按章节套公式。

## 是什么

**守恒法**：找不变量列等式，绕过中间过程。
- **质量守恒**：混合物总质量拆分；
- **电子守恒**：氧化还原中升=降（多步反应只看首尾价态）；
- **电荷守恒**：溶液中阳离子所带正电荷总量 = 阴离子负电荷总量；
- **物料守恒**：某元素的原子在转化中总数不变。

**差量法**：反应前后某个量（固体质量、气体体积、溶液质量）有净变化，用"实际差量 ÷ 理论差量"直接求反应量，比例关系一步到位。

**关系式法**：多步连续反应把各步系数叠起来，建立"原料→产品"的跨步比例。如接触法制硫酸：FeS₂ → 2SO₂ → 2SO₃ → 2H₂SO₄，即 n(FeS₂) : n(H₂SO₄) = 1 : 2，中间产物全部跳过。

**极值法**：混合物组成不明，按"全部是 A"和"全部是 B"两个极端夹出真实值的范围。

**三段式**：可逆反应与平衡计算的通用骨架——起始量、变化量、平衡量三行，变化量一行用系数比填。

## 为什么这样

守恒法有效是因为化学变化中"某些总量天然不动"——电子不会凭空增减、电荷不会凭空出现。绕过中间过程不是取巧，而是**只依赖守恒律本身**，所以多步反应、复杂混合物反而更适用：步骤越多，守恒省掉的中间量越多。

差量法有效是因为化学计量数线性：每消耗 1 mol Fe₂O₃，固体质量必减少 48 g（3 mol O 去了气相），实际固体差量与反应量严格成正比——比例成立的条件是"同一路径、同一系数关系"。

## 典型例子与方程式

**例（电子守恒）**：足量 NaOH 溶液吸收 2.24 L（标况）Cl₂ 后，溶液中 ClO⁻ 与 Cl⁻ 之比？歧化反应 $Cl_2 + 2NaOH = NaCl + NaClO + H_2O$ 电子守恒直接给 1 : 1，不必讨论量。

**例（差量法）**：$Fe_2O_3 + 3CO \xrightarrow{\text{高温}} 2Fe + 3CO_2$，固体减轻 4.8 g，求参加反应的 Fe₂O₃。理论：1 mol Fe₂O₃ → 2 mol Fe 固体减重 48 g（失去 3 个 O）。实际 4.8 g → n(Fe₂O₃) = 0.1 mol，一步完成。

**例（关系式）**：铝土法产氢气分两步放 H₂，用**物料守恒**合成总式：$2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2\uparrow$，n(H₂) = 1.5 n(Al)，跳过偏铝酸钠生成的细节。

## 常见易错点

- **"差量法任何反应都能用"**：错。差量成立的前提是**同一系数关系下的净变化**——两个平行反应各自消耗原料时必须分设未知数，不能混用一个差量。错因是记住了比例式没记住成立条件。
- **"电荷守恒就是正负电荷数目相等"**：不准确。是**电荷量**相等：c(阳离子)×离子电荷数 之和 = c(阴离子)×离子电荷数 之和，多元离子要乘价态。错因是忽略价态权重。
- **"极值法求出的就是答案"**：错。极值给出的是**范围边界**，混合物真实值在两极之间，还要结合第二条件（如气体总体积）定位。错因是夹逼之后忘了落点。
- **"三段式必须从物质的量开始列"**：不必。同温同压下气体可以直接用体积列三段式（系数比即体积比），恒温恒容下用压强也行——三段式是结构不是单位。错因是把工具绑死在一种量上。
- **"多步连续反应必须一步步算"**：低效。每步转化率都 100%（或已知总转化率）时，关系式法叠系数一步到位；只有各步转化率不同且要分布计算时才逐步算。错因是对"过程化学"过度忠实。
