# 定量实验与误差分析

> 一句话定位：本篇管"数从哪来、差从哪来"——仪器精度定读数位数，误差三步法定偏高偏低，浓度配制与滴定两条主线全覆盖。

## 是什么

**仪器精度与读数规则**（读数位数由仪器决定，不由计算决定）：
- 托盘天平：精确到 **0.1 g**；左物右码，游码归零再调平；
- 量筒：精确到 **0.1 mL**，不能加热、不能配液、不能作反应容器；
- 滴定管：精确到 **0.01 mL**（估读一位），0 刻度在上，用前查漏、水洗后必须**润洗**；
- 容量瓶：只有一条刻度线，标的是**容积精度**（如 100 mL ±0.1 mL），用前查漏，不能溶解、不能久储溶液。

**误差分析三步法**：操作 → 哪个物理量偏大/偏小 → 结果偏高/偏低。公式先行——误差分析的钩子永远是计算式。以配制 1.00 mol/L 溶液 $c = n/V$ 为例：称量时物码颠倒（动用了游码）→ n 偏小 → c 偏低；定容仰视刻度 → 加水超过刻度 → V 偏大 → c 偏低。

滴定的通用算式：

$c(\text{待测}) = \dfrac{c(\text{标准}) \times V(\text{标准}) \times \text{系数比}}{V(\text{待测})}$

**有效数字**：结果保留位数对齐最弱一环——滴定管读数 4 位有效数字，体积若读 20.00 mL，结果就保留 4 位；托盘天平称量 3 位起步。

## 为什么这样

滴定管必须润洗，是因为内壁挂的水膜会稀释标准液——浓度变小、耗用体积变大，三步法里这就是"V(标准) 偏大 → 待测偏高"。**每条操作规范都能翻译成一次误差方向**，这是本篇"为什么"的全部：规范不是仪式，是让误差可归零的努力。

容量瓶不能直接溶解，是因为多数溶解伴随吸热/放热，容积热胀冷缩，刻度就不准了——先在烧杯中溶解、**冷却至室温**再转移，就是这个原因。

## 典型例子与方程式

**NaOH 标准液滴定醋酸**：用酚酞作指示剂（终点粉红且半分钟不褪）。若滴定管尖嘴处有气泡、滴定后消失——V(读数) 偏大 → 测得酸浓度偏高；若用锥形瓶接液时摇出少量液滴——V(待测) 实际变小而读数按原体积算 → 偏低。

**配制一定浓度溶液七步**：计算 → 称量 → 溶解（烧杯+玻璃棒）→ 冷却 → 转移（玻璃棒引流）→ 洗涤（洗涤液一并转入，2~3 次）→ 定容摇匀。跳过"洗涤"一步，溶质残留烧杯壁 → n 偏小 → 偏低——误差三步法直接套用。

## 常见易错点

- **"滴定管用蒸馏水洗净就能装标准液"**：错。必须再用标准液**润洗 2~3 次**，否则残留水稀释标准液，结果偏高。错因是把"干净"当成了"无残留液体"。
- **"定容时俯视刻度线更精确"**：错。俯视使液面**实际低于**刻度线 → V 偏小 → c 偏高；仰视相反。错因是没把视线-液面-刻度的几何关系画出来。
- **"天平物码放反只是习惯问题"**：错。需要游码时物码颠倒，游码质量加到了物的一侧 → 称量值偏大（m码 = m物 + 游码 的关系被破坏）。不用游码时无影响——误差分析要落到具体数字上。错因是只背"左物右码"不知道为什么。
- **"读数估读到 0.01 mL 是多读一位没必要"**：错。滴定管刻度 0.1 mL 一格，估读一位到 0.01 mL 是仪器设计的一部分，不估读丢精度也丢分。错因是把估读当主观发挥。
- **"中和滴定终点就是酸碱恰好完全反应"**：不准确。终点是指示剂变色点，与化学计量点之间存在指示剂误差；选对指示剂（强酸滴弱碱用甲基橙、弱酸用酚酞）正是为了缩小这个差。错因是混淆"终点"与"计量点"两个概念。
