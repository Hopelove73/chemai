# 化学用语与方程式书写规范

> 一句话定位：本篇是"会写更要写对"的规范手册——四类方程式各自的高频扣分点清单，配平自查三守恒。

## 是什么

**化学方程式四查**：查化学式（Fe₃O₄ 不能写成 FeO·Fe₂O₃ 随手混写）、查配平、查条件（点燃/加热 Δ/高温/催化剂——暗设条件不标即错）、查状态符号（↑↓ 只标**产物中的**气体与沉淀，反应物不标）。

**离子方程式写拆删查四步**的规范点：强酸强碱可溶性盐拆，**浓硫酸、HClO、Ca(OH)₂（石灰乳）不拆**；微溶物 clarity——澄清写离子、浑浊写化学式。系数约分只在"全部系数有公因子"时做，反应物中部分参与的部分电离物质（如 Ca(HCO₃)₂ 与 NaOH 少量）按"少量定 1"原则写。

**热化学方程式三件套**：标状态 (g)/(l)/(s)/(aq)、ΔH 带正负号与单位 kJ/mol、系数与热量成比例（系数翻倍 ΔH 翻倍）。$H_2(g) + \frac{1}{2}O_2(g) = H_2O(l)\ \Delta H = -285.8\ kJ/mol$ 是标准格式样板。

**电极反应式**：负极氧化写电子失去（$2Cl^- - 2e^- = Cl_2\uparrow$），正极还原；介质参与要写（酸性不出现 OH⁻、碱性不出现 H⁺）；两极电子数相加消电子得总反应——**用总反应验电极式**是最快的自查。

**配平自查三守恒**：原子守恒、电荷守恒（离子方程式两侧总电荷相等）、电子守恒（氧化还原升降总数相等）。三查全过才能交卷。

## 为什么这样

↑↓ 只标产物，是因为它们表达的是"该条件下物质脱离体系"的事实——反应物是投料不是生成，标了反而误导条件。浓硫酸不拆，是因为它主要以分子形式存在并体现强氧化性，写成离子会掩盖高价的参与方式。

热化学方程式标状态，是因为 ΔH 依赖物质的状态与条件：同是水，气态液态差 44 kJ/mol 量级——不标状态的 ΔH 没有确定值。这就是"规范"不是洁癖：**每个符号都承载物理信息**。

## 典型例子与方程式

**例（拆与不拆）**：碳酸钙与盐酸：$CaCO_3 + 2H^+ = Ca^{2+} + H_2O + CO_2\uparrow$——CaCO₃ 难溶不拆、HCl 强酸拆。同是碳酸钙与醋酸：$CaCO_3 + 2CH_3COOH = Ca^{2+} + 2CH_3COO^- + H_2O + CO_2\uparrow$——醋酸弱酸不拆。同一个"写不拆"决定了一类题的对错。

**例（电极式验总式）**：电解饱和食盐水，阳极 $2Cl^- - 2e^- = Cl_2\uparrow$，阴极 $2H_2O + 2e^- = H_2\uparrow + 2OH^-$，相加得 $2Cl^- + 2H_2O \xrightarrow{\text{电解}} Cl_2\uparrow + H_2\uparrow + 2OH^-$，与总方程式一致，两极式互验通过。

## 常见易错点

- **"配平了就对了"**：错。配平只是四查之一——条件缺失、状态符号错位、化学式写错（如把 Na₂O₂ 写成 NaO）在配平正确的方程式里照样存在。错因是只查了守恒没查全套。
- **"ΔH 为负代表吸热"**：反了。ΔH < 0 放热、ΔH > 0 吸热；且"放热反应"的 ΔH 数值越小（越负）放热越多。错因是把符号与温度变化直觉混淆。
- **"离子方程式两边电荷数相等就行"**：不准确。要**电荷代数和**相等且各自与实际一致——两边同时错一样的电荷也能"相等"，必须回到真实离子价态检查。错因是把守恒当形式等号。
- **"电极反应式里出现 H⁺ 和 OH⁻ 都可以"**：错。介质决定离子禁区——酸性介质写 OH⁻、碱性介质写 H⁺ 都是硬伤；中性介质放电后局部可生 OH⁻ 但要写明来源。错因是背了写法没带介质意识。
- **"约分是美观要求随时可做"**：错。离子方程式系数约分必须**全体系数**有公因子；部分约分（如只把 2:4 改 1:2 而另一系数是 3）直接改变组成比。错因是把分数运算习惯带进化学式。
