# 氨与氨水

> 一句话定位：氨是唯一显碱性的常见气体——极易溶于水、与酸生白烟、还能被催化氧化，是氮从 -3 价出发走向硝酸的起点。

## 是什么

氨（NH3）是无色、有**刺激性气味**的气体，密度比空气小，**极易溶于水**（常温下 1 体积水约溶 700 体积 NH3），易液化（液氨可作制冷剂）。

**氨水显弱碱性**：NH3 溶于水后大部分与水结合成 NH3·H2O，NH3·H2O 部分电离出 NH4+ 和 OH-。所以氨水是混合物，显碱性的实质是 NH3·H2O 的电离。

氨的化学性质：

1. **与水反应**：生成 NH3·H2O，显弱碱性；
2. **与酸反应**：生成铵盐，与挥发性酸（HCl、HNO3）相遇产生白烟；
3. **还原性**：-3 价氮可被氧化，催化氧化是工业制硝酸的第一步；
4. **与某些盐溶液反应**：如侯氏制碱中氨先与 CO2、水、NaCl 反应生成 NaHCO3。

## 为什么这样

氨中氮为 **-3 价**，是氮的最低价，所以氨**只有还原性、没有氧化性**：催化氧化时 -3 → +2，被氧气氧化。

为什么氨水显碱性而 NH3 本身不是碱？NH3 分子中没有 OH-，它靠与水反应生成 NH3·H2O，再由 NH3·H2O 电离出 OH-。所以"氨水是碱"成立，"氨气是碱"不成立。

**喷泉实验**的原理：NH3 极易溶于水，烧瓶内气体迅速溶解，压强骤降，外界大气压把烧杯中的水压入烧瓶形成喷泉。实验成功的关键是装置气密性好、氨气充满烧瓶。

## 典型例子与方程式

**NH3 + H2O ⇌ NH3·H2O ⇌ NH4+ + OH-**：氨溶于水形成弱碱性溶液。它说明氨水的碱性来自 NH3·H2O 的部分电离，所以氨水是弱碱。

**NH3 + HCl = NH4Cl**：两根分别蘸有浓氨水和浓盐酸的玻璃棒靠近，产生白烟。它说明氨与挥发性酸反应生成固体铵盐小颗粒；白烟是 NH4Cl 固体，不是氨气。

**4NH3 + 5O2 --催化剂、加热--> 4NO + 6H2O**：氨的催化氧化，工业制硝酸的第一步。它说明 -3 价氮能被氧化到 +2，氨在此作还原剂。

**NaCl + NH3 + CO2 + H2O = NaHCO3↓ + NH4Cl**：侯氏制碱法的核心反应。它说明氨的碱性可以促进 CO2 的吸收，氨在流程中先通入、后通 CO2（详见 M1-T5-KP02）。

## 常见易错点

- **"液氨就是氨水"**：错。液氨是液态的 NH3，属于纯净物；氨水是 NH3 溶于水形成的混合物。
- **"NH3 是碱，因为它能使湿润红色石蕊试纸变蓝"**：错。使试纸变蓝的是氨水中的 OH-，碱性来自 NH3·H2O 的电离；NH3 本身不是碱。
- **"NH3 与 HCl 产生的白烟是氨气"**：错。白烟是 NH4Cl 固体小颗粒；氨气本身无色。
- **"NH3 用浓硫酸干燥"**：错。氨是碱性气体，会与浓硫酸反应，应使用碱石灰。
