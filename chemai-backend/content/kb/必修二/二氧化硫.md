# 二氧化硫

> 一句话定位：+4 价硫的代表物——既是酸性氧化物，又能被氧化、被还原，还能可逆漂白，是必修阶段"一种物质多重性质"的典型。

## 是什么

二氧化硫（SO2）是无色、有**刺激性气味**的有毒气体，密度比空气大，**易溶于水**（常温下 1 体积水约溶 40 体积 SO2）。

- **酸性氧化物**：与水反应生成亚硫酸（H2SO3，弱酸），与碱、碱性氧化物反应。
- **还原性为主**：+4 价可被氧化到 +6，能被 O2、Cl2、溴水、Fe3+、酸性 KMnO4 氧化。
- **氧化性**：与 H2S 等还原剂反应时，+4 价可被还原到 0。
- **漂白性**：与某些有色物质**化合**成不稳定的无色物质，加热后恢复原色——是**可逆漂白**。

## 为什么这样

硫在 SO2 中为 **+4 价**，处在 0 与 +6 之间，所以既能升价（还原性）又能降价（氧化性）。这是"中间价态兼有氧化性和还原性"（M1-T2-KP06）的直接应用。

漂白为什么可逆？SO2 的漂白是**化合**而非破坏：SO2 与色素分子结合生成无色物质，受热时结合物分解，色素恢复。对比次氯酸（M1-T2-KP13）是把色素**氧化破坏**，不可逆；活性炭是**吸附**，也不可逆。三种漂白机理不同，这是判断题的常考点。

## 典型例子与方程式

**SO2 + H2O ⇌ H2SO3**：SO2 溶于水部分与水反应，生成弱酸亚硫酸，溶液显酸性。它说明 SO2 是酸性氧化物；亚硫酸不稳定，受热易分解回 SO2 和水。

**2SO2 + O2 ⇌ 2SO3（催化剂、加热）**：接触法制硫酸的第二步。它说明 SO2 的还原性（+4 → +6），同时提醒反应可逆、需要催化剂和加热。

**SO2 + 2H2S = 3S↓ + 2H2O**：SO2 与硫化氢混合析出淡黄色硫单质。这是归中反应（-2 与 +4 都变 0），说明 SO2 也能作氧化剂。

**SO2 + Cl2 + 2H2O = H2SO4 + 2HCl**：SO2 使氯水褪色，自身被氧化到 +6。它说明 SO2 的还原性——这里的褪色不是漂白，而是把 Cl2 还原成了 Cl-。

**SO2 + 2NaOH = Na2SO3 + H2O**：实验室与工业用碱液吸收 SO2 尾气。它说明酸性氧化物通性；NaOH 过量时生成 Na2SO3，SO2 过量时生成 NaHSO3。

## 常见易错点

- **"SO2 使品红褪色后加热也不复原"**：错。SO2 漂白可逆，加热恢复红色；次氯酸漂白才不可逆。错因是把化合型漂白与氧化型漂白混为一谈。
- **"SO2 使溴水、氯水褪色，说明 SO2 有漂白性"**：错。那是 SO2 的还原性，Br2、Cl2 被还原为 Br-、Cl-，与漂白无关。错因是见"褪色"就归为漂白。
- **"SO2 与 CO2 都能使澄清石灰水变浑浊，无法鉴别"**：错。SO2 能使品红褪色、能使酸性 KMnO4 褪色、有刺激性气味，CO2 都不能；且 SO2 通入品红后加热恢复。错因是只记共同现象。
- **"SO2 是酸性氧化物，只有酸性氧化物的性质"**：错。+4 价居中，还原性和氧化性都显著，还能漂白。
