# 化学电源与能源利用

> 一句话定位：原电池原理的三种"产品形态"——一次电池用完就弃、二次电池可充可放、燃料电池不断供燃料；它们共同构成现代社会的移动能源。

## 是什么

**化学电源**按能否充电分为三类：

1. **一次电池**：锌锰干电池，放电后不能充电，用完即弃；
2. **二次电池**：铅蓄电池、锂离子电池，放电后可以充电，电能与化学能可逆转化；
3. **燃料电池**：氢氧燃料电池、甲烷燃料电池，只要持续供应燃料和氧化剂就能持续发电，产物主要是水。

**能源结构**：化石能源（煤、石油、天然气）不可再生、燃烧产生污染物；新能源包括太阳能、风能、水能、核能、氢能等。化学电池是把化学能直接转化为电能的装置，能量转化效率通常高于"燃烧→热能→机械能→电能"的多次转化。

## 为什么这样

二次电池为什么能"可逆"？放电时发生自发氧化还原反应，化学能→电能；充电时外加电源迫使反应逆向进行，电能→化学能。所以充电不是"把电存进电池"，而是把电能转化为化学能储存起来。

燃料电池为什么效率高？它不经过燃烧，燃料的化学能直接转化为电能，避免了燃烧产生的大量热损失；氢氧燃料电池的唯一产物是水，几乎不产生污染物。

## 典型例子与方程式

**Pb + PbO2 + 2H2SO4 = 2PbSO4 + 2H2O**：铅蓄电池放电的总反应。它说明二次电池放电时正、负极都转化为 PbSO4；充电时反应逆向进行。

**2H2 + O2 = 2H2O**：氢氧燃料电池的总反应。它说明燃料电池的本质仍是氧化还原，但电子经外电路转移，直接产生电流。

**CH4 + 2O2 = CO2 + 2H2O**：甲烷燃料电池的总反应。它说明燃料电池的燃料可以是氢气，也可以是甲烷、甲醇等含氢燃料。

## 常见易错点

- **"干电池可以反复充电"**：错。锌锰干电池是一次电池，放电后不能充电。
- **"燃料电池需要点燃才能工作"**：错。燃料电池通过电极上的催化反应持续供能，不需要点燃。
- **"氢能属于化石能源"**：错。氢能是二次能源/新能源，需要由水或其他原料制取。
- **"二次电池充电时化学能转化为电能"**：错。充电时是电能转化为化学能；放电时才是化学能转化为电能。
- **"电池使用时电子在电解质溶液中移动"**：错。电子经外电路移动，溶液中是离子定向移动。
