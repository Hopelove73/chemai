# 蛋白质与氨基酸

> 一句话定位：蛋白质是"氨基酸用肽键串起来的长链"——氨基酸两性、蛋白质能盐析能变性，这两组性质是食品、医药与重金属中毒处理的化学依据。

## 是什么

**蛋白质**是高分子化合物，组成元素主要有 C、H、O、N，有的还含 S。它由**氨基酸**通过**肽键（—CO—NH—）**连接而成。

**氨基酸**：分子中同时含有**氨基（—NH2）**和**羧基（—COOH）**，因此具有**两性**——既能与酸反应，又能与碱反应。最简单的氨基酸是甘氨酸 H2NCH2COOH。

**蛋白质的性质**：

1. **水解**：在酸、碱或酶的作用下，肽键断裂，最终生成氨基酸；
2. **盐析**：加入浓的轻金属盐溶液（如饱和硫酸铵），蛋白质析出，**可逆**（加水又能溶解）；
3. **变性**：加热、紫外线、重金属盐、强酸强碱、酒精等使蛋白质**不可逆**地失去生理活性；
4. **颜色反应**：某些蛋白质遇浓硝酸变黄；
5. **灼烧**：产生烧焦羽毛的气味。

## 为什么这样

蛋白质为什么能水解？肽键是酰胺键，在酸或碱的催化下与水反应断裂，生成氨基酸。人体消化蛋白质就是靠酶催化水解。

**盐析与变性的区别**：盐析只是降低蛋白质的溶解度，蛋白质的空间结构没有被破坏，所以可逆；变性是空间结构被破坏（肽键未断），所以不可逆。重金属中毒时喝大量牛奶或蛋清，就是让重金属与食物中的蛋白质结合变性，减少人体蛋白质的损伤。

## 典型例子与方程式

**H2NCH2CONHCH2COOH + H2O --酸或碱--> 2H2NCH2COOH**：二肽水解生成两分子甘氨酸。它说明肽键是蛋白质水解的断裂位点。

**H2NCH2COOH + HCl = ClH3NCH2COOH**：甘氨酸与盐酸反应。它说明氨基酸的氨基具有碱性，能与酸成盐。

**H2NCH2COOH + NaOH = H2NCH2COONa + H2O**：甘氨酸与氢氧化钠反应。它说明氨基酸的羧基具有酸性，能与碱成盐——氨基与羧基并存，就是"两性"。

## 常见易错点

- **"盐析和变性是一回事"**：错。盐析可逆，蛋白质结构未破坏；变性不可逆，空间结构被破坏。错因是二者都表现为"蛋白质析出"。
- **"重金属中毒可以喝盐水解毒"**：错。应喝大量牛奶、蛋清，让重金属与食物蛋白质结合；盐水不能解毒。
- **"蛋白质是高分子，氨基酸也是高分子"**：错。蛋白质是高分子，氨基酸是小分子。
- **"蛋白质水解的最终产物是多肽"**：错。最终产物是氨基酸；多肽是中间产物。
- **"灼烧蛋白质没有特殊气味"**：错。灼烧蛋白质有烧焦羽毛的气味，可用于鉴别。
