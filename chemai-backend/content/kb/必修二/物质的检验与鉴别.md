# 物质的检验与鉴别

> 一句话定位：必修二把检验从"认单个离子"升级为"排干扰、定顺序"——SO4^2-、NH4+、Fe3+、Cl- 四个高频离子的检验都要能说清"先加什么、为什么"。

## 是什么

**检验**是确认某物质是否存在；**鉴别**是把几种物质区分开。必修二重点掌握：

- **SO4^2-**：先加稀盐酸酸化，再加 BaCl2 溶液，生成白色沉淀（BaSO4）证明有 SO4^2-。
- **NH4+**：加 NaOH 溶液并加热，产生使湿润红色石蕊试纸变蓝的气体（NH3）。
- **Fe3+**：加 KSCN 溶液，溶液变血红色；Fe2+ 不显色，可先用氯水氧化再检验。
- **Cl-**：加稀硝酸酸化，再加 AgNO3 溶液，生成白色沉淀（AgCl）。
- **SO2 与 CO2 的鉴别**：SO2 能使品红溶液褪色（加热复原）、能使酸性 KMnO4 溶液褪色，CO2 不能；二者都能使澄清石灰水变浑浊，所以石灰水不能用来鉴别。

## 为什么这样

检验的关键不是"看到现象"，而是**排除干扰**：

- CO3^2-、SO3^2- 与 Ba2+ 也生成白色沉淀，Ag+ 与 Cl- 生成白色 AgCl——所以 SO4^2- 检验必须先用稀盐酸酸化，把 CO3^2-、SO3^2- 赶走并排除 Ag+ 干扰。
- CO3^2-、SO3^2- 与 Ag+ 也生成白色沉淀——所以 Cl- 检验必须先用稀硝酸酸化。
- Fe2+ 与 KSCN 不显红色，但 Fe2+ 易被氧化，所以检验 Fe2+ 要先加 KSCN（不变红）再加氯水（变红）。

## 典型例子与方程式

**Ba2+ + SO4^2- = BaSO4↓**：白色沉淀不溶于稀盐酸，是 SO4^2- 的特征反应。检验顺序是先酸化、后加 BaCl2；顺序颠倒时 Ag+ 干扰无法排除。

**NH4+ + OH- --加热--> NH3↑ + H2O**：铵盐与碱共热放出氨气，用湿润红色石蕊试纸变蓝确认。它说明 NH4+ 检验必须加热，稀溶液常温下产生的 NH3 太少。

**Fe3+ + 3SCN- = Fe(SCN)3**：溶液变血红色，是 Fe3+ 的特征反应。注意产物是配合物溶液，不是沉淀。

**Ag+ + Cl- = AgCl↓**：白色沉淀不溶于稀硝酸，是 Cl- 的特征反应。加硝酸是为了排除 CO3^2- 等干扰。

## 常见易错点

- **"检验 SO4^2- 先加 BaCl2 再加稀盐酸"**：错。必须先加稀盐酸酸化，再加 BaCl2；否则无法排除 Ag+ 与 CO3^2-、SO3^2- 的干扰。
- **"Fe3+ 与 KSCN 反应生成红色沉淀"**：错。生成的是血红色溶液（配合物），不是沉淀。错因是把"颜色变化"当成"沉淀生成"。
- **"NH4+ 检验加 NaOH 后不加热也能明显放出氨气"**：错。稀溶液需加热才能放出足够的 NH3；且要用湿润的红色石蕊试纸检验。
- **"用澄清石灰水鉴别 SO2 与 CO2"**：错。二者都能使石灰水变浑浊；应用品红溶液或酸性 KMnO4 溶液鉴别 SO2。

## 与其他知识的联系
