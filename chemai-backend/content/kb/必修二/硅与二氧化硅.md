# 硅与二氧化硅

> 一句话定位：硅是"半导体元素"，二氧化硅是"玻璃的骨架"——两者都不是金属，却支撑了芯片、光导纤维与整个无机非金属材料体系。

## 是什么

**硅（Si）**：灰黑色固体，有金属光泽但属于**非金属**，是良好的**半导体**。化学性质：常温下稳定；能与 HF、强碱溶液反应；高温下能与 O2、Cl2 等反应。

**二氧化硅（SiO2）**：无色透明或白色固体，是**酸性氧化物**，但不溶于水。它与一般的酸性氧化物不同：

- 能与 **HF** 反应（SiF4 气体）——这是雕刻玻璃的原理；
- 能与 **强碱** 反应生成硅酸钠（Na2SiO3）——所以盛放 NaOH 的试剂瓶要用橡胶塞；
- 高温下能被 **C** 还原制粗硅；
- 用途：光导纤维、石英玻璃、水晶、建筑材料。

## 为什么这样

SiO2 是**空间网状结构**（每个硅原子与四个氧原子相连，氧原子再连硅原子），没有单个分子。共价键网络使它的熔点高、硬度大、难溶于水——所以"酸性氧化物"的通性（与水反应生成酸、与碱反应）在 SiO2 上只部分成立：**与碱能反应，与水不能反应**。

硅为什么能作半导体？它的导电性介于导体与绝缘体之间，且对温度、杂质敏感——这是芯片材料的物理基础，属于"结构决定性质"的延伸。

## 典型例子与方程式

**Si + 2NaOH + H2O = Na2SiO3 + 2H2↑**：硅与强碱溶液反应放出氢气。它说明硅虽是非金属，却能像铝一样与强碱反应；实验室保存硅要注意隔绝碱液。

**Si + 4HF = SiF4↑ + 2H2↑**：硅与氢氟酸反应。它说明 HF 能腐蚀硅，是半导体加工中刻蚀硅的基础。

**SiO2 + 4HF = SiF4↑ + 2H2O**：氢氟酸雕刻玻璃的反应。它说明 HF 是唯一能与 SiO2 反应的酸，所以氢氟酸不能用玻璃瓶盛放。

**SiO2 + 2NaOH = Na2SiO3 + H2O**：SiO2 与强碱反应生成硅酸钠。它说明玻璃瓶不能长期盛放 NaOH——生成的 Na2SiO3 有黏性，会使玻璃塞与瓶口粘住。

**SiO2 + 2C --高温--> Si + 2CO↑**：工业上用焦炭在高温下还原 SiO2 制粗硅。它说明 SiO2 在高温下能被强还原剂还原，是硅工业的第一步。

## 常见易错点

- **"SiO2 是酸性氧化物，所以能与水反应生成硅酸"**：错。SiO2 不溶于水，也不与水反应；硅酸要用可溶性硅酸盐与酸反应制取。
- **"硅是金属"**：错。硅是非金属，只是有金属光泽、能导电（半导体）。
- **"盛放 NaOH 溶液可以用玻璃塞"**：错。SiO2 与 NaOH 反应生成有黏性的 Na2SiO3，会使瓶塞粘住，应使用橡胶塞。
- **"光导纤维的主要成分是硅单质"**：错。光导纤维的主要成分是 SiO2（高纯石英玻璃），不是硅单质。
- **"氢氟酸是强酸，所以能腐蚀玻璃"**：错。氢氟酸是弱酸，能腐蚀玻璃是因为 F- 与 Si 的特殊反应，不是酸性强弱的问题。
