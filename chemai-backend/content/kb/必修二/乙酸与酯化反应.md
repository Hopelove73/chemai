# 乙酸与酯化反应

> 一句话定位：乙酸是"羧基"的代表——比碳酸强、能酯化；它与乙醇生成乙酸乙酯的反应，是可逆反应与浓硫酸"催化 + 吸水"双重作用的经典案例。

## 是什么

**乙酸（CH3COOH）** [SMILES:CC(=O)O]，俗称醋酸：无色、有强烈刺激性气味的液体，能与水互溶。官能团是**羧基（—COOH）**。

**化学性质**：

1. **酸性**：弱酸，但酸性比碳酸强，能使石蕊变红，与碱、碳酸钠、碳酸氢钠反应；
2. **酯化反应**：与乙醇在浓硫酸催化、加热条件下生成乙酸乙酯和水。反应**可逆**，浓硫酸同时起**催化剂**和**吸水剂**作用。

**乙酸乙酯**：无色、有果香味的液体，密度比水小，难溶于水。

## 为什么这样

乙酸的酸性来自羧基：—COOH 中的 O—H 键能电离出 H+。但乙酸是**弱酸**，只部分电离，所以酸性弱于盐酸、硫酸，强于碳酸——因此乙酸能与 Na2CO3、NaHCO3 反应放出 CO2（强酸制弱酸）。

酯化反应为什么可逆？乙酸与乙醇生成酯和水，同时酯和水在酸性条件下又能水解回乙酸和乙醇。浓硫酸吸水，把水"拿走"，使平衡向生成酯的方向移动——这是"通过移走产物提高产率"的典型。

## 典型例子与方程式

**CH3COOH + NaOH = CH3COONa + H2O**：乙酸与碱中和。它说明乙酸具有酸的通性，可与碱发生中和反应。

**2CH3COOH + Na2CO3 = 2CH3COONa + CO2↑ + H2O**：乙酸与碳酸钠反应放出 CO2。它说明乙酸酸性比碳酸强，能"顶出"碳酸。

**CH3COOH + NaHCO3 = CH3COONa + CO2↑ + H2O**：乙酸与碳酸氢钠反应。它说明可用 NaHCO3 区分乙酸与乙醇（乙醇不反应）。

**CH3COOH + C2H5OH ⇌ CH3COOC2H5 + H2O（浓硫酸、加热）**：酯化反应。它说明反应可逆；制备时用饱和 Na2CO3 溶液吸收乙酸、溶解乙醇、降低酯的溶解度，便于分层收集。

## 常见易错点

- **"乙酸是强酸"**：错。乙酸是弱酸，只能部分电离；但酸性比碳酸强。
- **"酯化反应中浓硫酸只作催化剂"**：错。浓硫酸还作吸水剂，移走水使平衡右移，提高产率。
- **"酯化反应是不可逆的"**：错。酯化与酯的水解互为逆反应，是可逆反应。
- **"制备乙酸乙酯时导管插入饱和 Na2CO3 溶液液面下"**：错。导管口应在液面上方，防止倒吸。
- **"饱和 Na2CO3 溶液只是为了吸收乙酸"**：不全面。它还溶解乙醇、降低乙酸乙酯的溶解度，便于分层。
