# 铵盐

> 一句话定位：铵盐是 NH4+ 的"身份证"——受热易分解、遇碱放氨，这两条性质既是检验方法，也是氮肥不能与碱性物质混用的原因。

## 是什么

铵盐是铵根离子（NH4+）与酸根离子构成的盐，如 NH4Cl、NH4HCO3、NH4NO3、(NH4)2SO4。它们多为白色晶体，**易溶于水**。

铵盐的两条核心性质：

1. **受热易分解**：NH4Cl 受热分解为 NH3 和 HCl（遇冷又化合成 NH4Cl）；NH4HCO3 受热分解为 NH3、CO2 和 H2O；NH4NO3 受热分解产物随温度不同而变化。
2. **与碱反应**：与 NaOH、Ca(OH)2 等碱共热放出 NH3——这是检验 NH4+ 的原理，也是铵态氮肥不能与草木灰（含 K2CO3，显碱性）混用的原因。

铵盐是重要的**氮肥**：NH4HCO3（碳铵）、NH4NO3（硝铵）、(NH4)2SO4（硫铵）、NH4Cl（氯铵）。

## 为什么这样

NH4+ 与 OH- 相遇，结合生成 NH3·H2O；加热时 NH3·H2O 分解放出 NH3。所以铵盐与碱的反应在常温下也能发生，但**加热才能把 NH3 较完全地赶出**——检验时必须加热。

铵盐受热分解的本质是 NH4+ 与酸根之间的质子转移：NH4+ 给出质子变成 NH3，酸根接受质子变成相应的酸。不同铵盐的酸根不同，分解产物也不同，不能一概写成"NH3 + 酸"。

## 典型例子与方程式

**NH4Cl --加热--> NH3↑ + HCl↑**：试管口附近又出现白色固体，说明 NH3 与 HCl 遇冷重新化合。它说明 NH4Cl 的"分解"是可逆的，不能靠加热 NH4Cl 收集氨。

**NH4HCO3 --加热--> NH3↑ + CO2↑ + H2O**：碳酸氢铵受热放出三种物质，是氮肥必须密封保存的原因。它说明铵盐分解不一定只生成两种产物。

**NH4NO3 + NaOH --加热--> NaNO3 + NH3↑ + H2O**：铵盐与碱共热的通式化表达。它说明铵盐与碱反应生成新盐、氨和水。

**NH4+ + OH- --加热--> NH3↑ + H2O**：NH4+ 检验的离子方程式。用湿润的红色石蕊试纸靠近试管口，试纸变蓝即证明有 NH4+。

## 常见易错点

- **"所有铵盐受热分解都生成 NH3 和对应的酸"**：错。NH4HCO3 还生成 CO2 和 H2O；NH4NO3 的分解产物更复杂。错因是把 NH4Cl 的个例当通式。
- **"铵态氮肥与草木灰混合施用"**：错。草木灰显碱性，会与铵盐反应放出 NH3，降低肥效。
- **"检验 NH4+ 加碱后不加热"**：错。稀溶液常温下放出的 NH3 太少，必须加热并用湿润红色石蕊试纸检验。
- **"NH4Cl 受热分解得到的 NH3 和 HCl 可以分别收集"**：错。二者遇冷立即重新化合生成 NH4Cl，无法分离收集。
