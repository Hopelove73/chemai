# 糖类

> 一句话定位：糖类是"碳水化合物的旧名字"——从单糖到多糖，分子越大越不甜、越难溶，但都能（或最终能）水解成葡萄糖。

## 是什么

糖类按能否水解及水解产物分为三类：

1. **单糖**：不能水解，如葡萄糖、果糖，分子式都是 C6H12O6，互为同分异构体；
2. **二糖**：水解生成两分子单糖，如蔗糖、麦芽糖，分子式都是 C12H22O11；
3. **多糖**：水解生成许多分子单糖，如淀粉、纤维素，通式 (C6H10O5)n。

**重要性质**：

- **葡萄糖**：能与新制氢氧化铜悬浊液反应生成砖红色沉淀（还原性糖的特征）；
- **蔗糖**：非还原性糖，水解后生成葡萄糖和果糖；
- **淀粉**：遇碘变蓝，水解最终产物是葡萄糖；
- **纤维素**：水解最终产物也是葡萄糖，但人体缺乏分解纤维素的酶，不能消化吸收。

## 为什么这样

糖类为什么能用 (CH2O)n 表示？多数糖类的 H、O 原子个数比恰好是 2∶1，所以历史上叫"碳水化合物"。但这只是经验式，符合此比例的不一定是糖（如甲醛 CH2O），糖也不一定符合（如脱氧核糖）。

淀粉与纤维素都是 (C6H10O5)n，为什么不是同分异构体？因为 n 值不同，且二者都是**混合物**，没有确定的分子式；它们的结构单元连接方式也不同（纤维素有大量氢键，难溶于水）。

## 典型例子与方程式

**C6H12O6 + 6O2 --酶--> 6CO2 + 6H2O**：葡萄糖在体内氧化，放出能量。它说明糖类是重要的能源物质。

**C12H22O11 + H2O --稀硫酸、加热--> 2C6H12O6**：蔗糖水解生成葡萄糖和果糖。它说明二糖水解需要酸催化并加热；蔗糖本身是非还原性糖，水解后才出现还原性。

**(C6H10O5)n + nH2O --稀硫酸、加热--> nC6H12O6**：淀粉（或纤维素）水解。它说明多糖最终都能水解为葡萄糖；淀粉水解是否完全，可用碘液检验（不变蓝即水解完全）。

## 常见易错点

- **"糖类都有甜味"**：错。淀粉、纤维素没有甜味；糖类不等于"甜的物质"。
- **"淀粉和纤维素互为同分异构体"**：错。二者都是 (C6H10O5)n，但 n 值不同且都是混合物，不是同分异构体。
- **"蔗糖是还原性糖"**：错。蔗糖是非还原性糖；麦芽糖、葡萄糖是还原性糖。
- **"葡萄糖与果糖不是同分异构体"**：错。二者分子式都是 C6H12O6，结构不同，互为同分异构体。
- **"人体能消化吸收纤维素"**：错。人体缺乏分解纤维素的酶，纤维素不能提供能量，但能促进肠道蠕动。
