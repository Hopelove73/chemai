# 硫酸与浓硫酸的性质

> 一句话定位：同一瓶硫酸，稀与浓是两种"性格"——稀硫酸的氧化剂是 H+，浓硫酸的氧化剂是 +6 价硫，这条分界线是元素化合物最经典的对比。

## 是什么

硫酸是二元强酸。**稀硫酸**具有酸的通性：使指示剂变色，与活泼金属、碱、碱性氧化物、盐反应。**浓硫酸**（质量分数约 98%）则有三大特性：

1. **吸水性**：吸收现成的水分子，可作干燥剂（但不能干燥 NH3 等碱性气体）；
2. **脱水性**：按 H、O 原子个数比 2∶1 夺取有机物中的氢、氧，使蔗糖变黑（"黑面包"实验）；
3. **强氧化性**：+6 价硫得电子，与 Cu、C 等反应，自身被还原为 SO2；常温下使 Fe、Al **钝化**。

## 为什么这样

稀硫酸中起氧化作用的是 **H+**，它只能氧化排在氢前的活泼金属，得到 H2；浓硫酸中起氧化作用的是 **+6 价硫**，它能把 Cu、C 这类 H+ 氧化不了的物质氧化，自身被还原为 SO2。所以"浓硫酸的氧化性不是 H+ 的氧化性"——这是理解产物差异的关键。

钝化不是不反应：常温下浓硫酸使铁、铝表面生成**致密氧化膜**，阻止反应继续；加热后氧化膜被破坏，反应又能进行。所以常温可用铁槽车运输浓硫酸。

## 典型例子与方程式

**Zn + H2SO4(稀) = ZnSO4 + H2↑**：稀硫酸与活泼金属的典型反应。它说明稀硫酸的氧化剂是 H+，产物是氢气。

**Cu + 2H2SO4(浓) --加热--> CuSO4 + SO2↑ + 2H2O**：铜片在浓硫酸中加热，溶液变蓝并放出有刺激性气味的气体。它说明浓硫酸的强氧化性来自 +6 价硫，产物是 SO2 而不是 H2。

**C + 2H2SO4(浓) --加热--> CO2↑ + 2SO2↑ + 2H2O**：木炭与浓硫酸共热，生成两种气体。它说明浓硫酸连非金属单质也能氧化，强氧化性不限于金属。

**Ba2+ + SO4^2- = BaSO4↓**：硫酸根离子的检验。检验时要先用稀盐酸酸化，排除 CO3^2-、SO3^2-（生成 BaCO3、BaSO3 白色沉淀）和 Ag+（生成 AgCl 白色沉淀）的干扰。

## 常见易错点

- **"浓硫酸与铜反应生成 H2"**：错。浓硫酸把铜氧化，自身还原为 SO2；只有稀硫酸与活泼金属才放 H2。错因是套用"酸与金属反应放氢气"的通性。
- **"稀释浓硫酸时把水倒入浓硫酸"**：错。必须把浓硫酸沿器壁缓缓倒入水中并不断搅拌；反之局部剧烈放热会使酸液飞溅。错因是把"混合"当成不分先后。
- **"吸水性就是脱水性"**：错。吸水性吸收现成的水分子（物理变化为主，作干燥剂）；脱水性把有机物中的 H、O 按 2∶1 夺走（化学变化）。错因是名称相近。
- **"检验 SO4^2- 只需加 BaCl2"**：错。必须先用稀盐酸酸化，排除 CO3^2-、SO3^2-、Ag+ 的干扰。错因是只记白色沉淀、不记干扰。
