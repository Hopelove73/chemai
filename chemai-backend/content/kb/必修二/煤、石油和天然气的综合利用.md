# 煤、石油和天然气的综合利用

> 一句话定位：化石能源不只是燃料——煤的干馏、石油的裂解、天然气的转化，把"黑色燃料"变成塑料、纤维、橡胶的原料，这就是"燃料变材料"。

## 是什么

**煤的综合利用**：

- **干馏**：隔绝空气加强热，得到焦炭、煤焦油、焦炉气（化学变化）；
- **气化**：煤与水蒸气在高温下反应，生成 CO 和 H2（水煤气，化学变化）；
- **液化**：煤转化为液体燃料（化学变化）。

**石油的综合利用**：

- **分馏**：利用各组分沸点不同，分离出汽油、煤油、柴油等（物理变化）；
- **裂化**：把长链烃断裂为较短链烃，提高汽油产量（化学变化）；
- **裂解**：在更高温度下深度裂解，得到乙烯、丙烯等基础化工原料（化学变化）。

**天然气**：主要成分是甲烷，可作燃料，也可转化为氢气、炭黑等化工原料。

## 为什么这样

为什么分馏是物理变化而干馏是化学变化？分馏只是按沸点把原有组分分开，没有生成新物质；干馏是隔绝空气加强热，煤发生复杂的分解与缩合，生成了焦炭、煤焦油等新物质。

裂化与裂解的区别在**目的**：裂化是为了得到更多汽油（C8 左右的烃），裂解是为了得到乙烯、丙烯等小分子烯烃（化工原料）。温度越高、裂解越深。

## 典型例子与方程式

**C + H2O --高温--> CO + H2**：煤的气化，生成水煤气。它说明煤可以转化为清洁的气体燃料，CO 与 H2 还可用于合成氨、甲醇。

**C16H34 --催化剂、加热--> C8H18 + C8H16**：十六烷裂化为辛烷和辛烯。它说明裂化把长链烃"切断"，提高汽油产量，同时产生烯烃。

**CH4 --高温--> C + 2H2**：甲烷高温分解。它说明天然气不仅是燃料，还能制取氢气和炭黑。

## 常见易错点

- **"石油分馏是化学变化"**：错。分馏利用沸点差异，是物理变化；裂化、裂解才是化学变化。
- **"煤的干馏就是煤的燃烧"**：错。干馏是隔绝空气加强热，燃烧需要氧气，二者产物不同。
- **"煤焦油就是煤油"**：错。煤焦油是煤干馏的液体产物（含苯、酚等），煤油是石油分馏的产物。
- **"裂化和裂解是一回事"**：错。裂化主要为了提高汽油产量，裂解主要为了得到乙烯、丙烯等化工原料。
- **"化石能源取之不尽"**：错。煤、石油、天然气不可再生，应节约使用并发展新能源。
