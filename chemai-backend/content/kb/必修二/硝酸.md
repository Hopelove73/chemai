# 硝酸

> 一句话定位：硝酸是氮的最高价含氧酸——+5 价氮让它成为强氧化剂，浓与稀的还原产物不同（NO2 与 NO），一条主线串起铜、碳、铁三类反应。

## 是什么

纯硝酸是无色、易挥发、有刺激性气味的液体，属于一元强酸。市售浓硝酸常因溶有 NO2 而显黄色。

硝酸的三大性质：

1. **强酸性**：具有酸的通性，但与金属反应不放出 H2；
2. **强氧化性**：+5 价氮得电子，能氧化 Cu、Ag 等不活泼金属，也能氧化 C、S 等非金属；常温下使 Fe、Al **钝化**；
3. **不稳定性**：见光或受热分解，生成 NO2、O2 和水，所以保存在棕色瓶中、避光低温。

**浓、稀硝酸与铜的产物不同**：浓硝酸主要被还原为 NO2（+4），稀硝酸主要被还原为 NO（+2）。

## 为什么这样

硝酸中氮为 **+5 价**，是氮的最高价，**只能得电子、不能失电子**，所以硝酸只表现氧化性。这与硫酸不同：稀硫酸的氧化剂是 H+，浓硫酸的氧化剂是 +6 价硫。

为什么浓硝酸得 NO2、稀硝酸得 NO？浓硝酸氧化性强、浓度大，+5 价氮只下降到 +4 就停止；稀硝酸中硝酸浓度低，氮被还原得更彻底，下降到 +2。必修阶段记住"浓→NO2、稀→NO"的对应即可，更细的规律在选择性必修继续学习。

## 典型例子与方程式

**3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O**：铜与稀硝酸反应，溶液变蓝、有无色气体逸出，遇空气变红棕色。它说明稀硝酸的还原产物是 NO，且反应不放 H2。

**Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2↑ + 2H2O**：铜与浓硝酸反应，立即产生红棕色气体。它说明浓硝酸的还原产物是 NO2，氧化性比稀硝酸强。

**4HNO3 --光照或加热--> 4NO2↑ + O2↑ + 2H2O**：浓硝酸久置变黄的原因。它说明硝酸不稳定，必须用棕色瓶避光保存。

**C + 4HNO3(浓) --加热--> CO2↑ + 4NO2↑ + 2H2O**：木炭与浓硝酸共热，生成两种气体。它说明硝酸不仅能氧化金属，也能氧化非金属单质。

## 常见易错点

- **"硝酸与铜反应生成 H2"**：错。硝酸是氧化性酸，+5 价氮得电子，产物是 NO 或 NO2，不是 H2。错因是套用盐酸、稀硫酸与金属的通性。
- **"稀硝酸与铜不反应"**：错。稀硝酸同样能氧化铜，只是还原产物为 NO。错因是把"稀"当成"不氧化"。
- **"硝酸见光分解生成 NO"**：错。分解生成 NO2、O2 和 H2O；NO 是硝酸与金属反应时可能得到的还原产物。
- **"铁与稀硝酸反应一定生成 Fe3+"**：错。硝酸过量时生成 Fe3+，铁过量时 Fe3+ 会被铁还原为 Fe2+。错因是忽略"过量"对产物的影响。
- **"浓硝酸能用铁制容器长期盛放"**：不严谨。常温下铁被浓硝酸钝化，可以短时间盛放；但加热或长期接触会破坏氧化膜，仍需规范储存。
