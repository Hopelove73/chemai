# 乙烯与烯烃

> 一句话定位：乙烯是"不饱和烃"的代表——碳碳双键让它能发生加成与加聚，也让它成为石化工业最重要的基础原料。

## 是什么

**乙烯（C2H4）** [SMILES:C=C]：无色气体，稍有甜味，难溶于水。分子中两个碳原子之间以**双键**相连，六个原子共平面，键角约 120°。

**化学性质**：

1. **氧化**：燃烧（明亮火焰、黑烟）；能被酸性 KMnO4 溶液氧化，使溶液褪色；
2. **加成反应**：双键中的一个键断裂，两个碳原子各与一个原子或原子团结合——与 Br2 的 CCl4 溶液或溴水反应（褪色）、与 H2 加成、与 HCl 加成、与水加成生成乙醇；
3. **加聚反应**：许多乙烯分子相互加成，生成聚乙烯。

**烯烃**：含一个碳碳双键的链状烃，通式 **CnH2n**。乙烯是最简单的烯烃。

## 为什么这样

乙烯为什么容易发生加成？碳碳双键由一个 σ 键和一个 π 键组成，π 键较弱、容易断裂。断裂后两个碳原子各"空出一个价"，正好与 Br2、H2、HCl 等加成。所以**加成是烯烃的特征反应**，而烷烃只能取代。

加聚反应为什么能得到高分子？成千上万个乙烯分子通过双键打开、彼此连接，形成很长的碳链——聚乙烯。高分子中 n 不同，所以聚乙烯是**混合物**，没有固定熔点。

## 典型例子与方程式

**C2H4 + 3O2 --点燃--> 2CO2 + 2H2O**：乙烯燃烧，火焰明亮并伴有黑烟（含碳量高）。它说明乙烯可作燃料，也说明不饱和烃燃烧不如烷烃充分。

**C2H4 + Br2 = C2H4Br2**：乙烯使溴水或溴的 CCl4 溶液褪色。它说明加成反应是检验碳碳双键的经典方法——褪色是因为 Br2 被加成消耗，不是取代。

**C2H4 + H2 --催化剂、加热--> C2H6**：乙烯加氢生成乙烷。它说明双键可以加氢饱和，工业上用于调节汽油成分。

**C2H4 + HCl --催化剂--> C2H5Cl**：乙烯与氯化氢加成生成氯乙烷。它说明加成反应可以引入卤素，是有机合成的重要一步。

**nC2H4 --催化剂--> [-CH2-CH2-]n**：乙烯加聚生成聚乙烯。它说明小分子（单体）可以通过加聚变成高分子，聚乙烯是产量最大的塑料之一。

## 常见易错点

- **"乙烯使溴水褪色是取代反应"**：错。烯烃使溴水褪色是加成反应；取代反应需要光照，且产物有 HBr。
- **"聚乙烯是纯净物"**：错。聚乙烯中 n 值不同，是混合物，没有固定熔点。
- **"乙烯与水加成生成乙酸"**：错。乙烯与水加成生成乙醇；乙酸由乙醇氧化得到。
- **"乙烯是直线型分子"**：错。乙烯是平面型分子，六个原子共平面，不是直线。
- **"乙烯能使酸性 KMnO4 褪色，说明发生了加成"**：错。那是氧化反应，KMnO4 把乙烯氧化；加成是针对 Br2、H2 等。
