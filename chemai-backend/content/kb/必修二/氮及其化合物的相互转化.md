# 氮及其化合物的相互转化

> 一句话定位：把氮气、氨、氮氧化物、硝酸串成一张价态网络——-3、0、+2、+4、+5 五个价态，构成合成氨与硝酸工业的完整链条。

## 是什么

氮元素在必修二的常见价态与代表物质：

| 价态 | 代表物质 |
|---|---|
| -3 | NH3、NH4+、铵盐 |
| 0 | N2 |
| +2 | NO |
| +4 | NO2、N2O4 |
| +5 | HNO3、硝酸盐 |

**两条主线**：

1. **固氮线**：N2 → NH3（合成氨，0 → -3）；
2. **硝酸线**：NH3 → NO → NO2 → HNO3（-3 → +2 → +4 → +5）。

两条线在 **NH4NO3** 处汇合：NH3 + HNO3 = NH4NO3，既得到氮肥，也把 -3 与 +5 两种价态装进同一种盐。

## 为什么这样

每一步转化都需要合适的氧化剂或还原剂：N2 → NH3 需要 H2（还原剂）和高温高压催化剂；NH3 → NO 需要 O2 和催化剂；NO → NO2 只需空气中的 O2；NO2 → HNO3 是 NO2 与水的歧化。**价态每升一级，都要付出相应的氧化条件**。

为什么硝酸工业要"氨→NO→NO2→HNO3"绕一圈？因为 N2 太稳定，无法直接氧化成硝酸；先合成氨把氮"活化"到 -3 价，再逐步氧化，是工业上最经济的路线。

## 典型例子与方程式

**N2 + 3H2 ⇌ 2NH3（高温、高压、催化剂）**：合成氨，固氮线的起点。它说明 N2 需要苛刻条件才能被还原，反应可逆、转化率有限。

**4NH3 + 5O2 --催化剂、加热--> 4NO + 6H2O**：氨的催化氧化，硝酸线的第一步。它说明 -3 价氮被氧化到 +2，是"活化氮"的关键一跃。

**2NO + O2 = 2NO2**：无色 NO 遇空气变红棕色。它说明 NO 不能排空气收集，也是硝酸线中不耗能的自然一步。

**3NO2 + H2O = 2HNO3 + NO**：NO2 与水歧化生成硝酸，同时放回 NO。它说明工业制硝酸需要把放出的 NO 再氧化、循环吸收，才能提高原料利用率。

**NH3 + HNO3 = NH4NO3**：氨与硝酸化合生成硝酸铵。它说明两条线可以汇合；此反应中氮的价态不变（-3 与 +5），不是氧化还原反应。

## 常见易错点

- **"NH3 与 HNO3 反应时氮的价态发生变化"**：错。-3 与 +5 在 NH4NO3 中保持不变，这是化合反应，不是氧化还原反应。
- **"NO2 与水反应可以完全转化为硝酸"**：错。还生成 NO，需要补充 O2 把 NO 再氧化，循环吸收。
- **"合成氨与制硝酸无关"**：错。氨是制硝酸的原料，硝酸工业的第一步就是氨的催化氧化。
- **"氮肥只有铵态氮肥"**：错。还有硝态氮肥（硝酸盐），以及 NH4NO3 这类含两种形态的氮肥。
