# 实验方案的设计与评价

> 一句话定位：从"照方抓药"到"自己开方"——实验方案要回答目的、原理、装置、步骤、证据五件事，评价则从科学性、可行性、安全性、环保性四个维度挑毛病。

## 是什么

**实验方案的基本要素**：

1. **目的**：要验证或探究什么；
2. **原理**：用哪个反应、依据什么性质；
3. **装置**：发生、净化、收集、尾气处理；
4. **步骤**：先做什么、后做什么、控制什么条件；
5. **证据**：观察什么现象、记录什么数据、如何得出结论。

**评价维度**：科学性（原理是否正确）、可行性（装置与操作能否实现）、安全性（有无爆沸、倒吸、中毒风险）、环保性（尾气与废液如何处理）、简约性（步骤是否必要）。

**核心方法**：控制变量法（只改变一个因素）、对比实验（设置对照组）、空白实验（排除干扰）。

## 为什么这样

控制变量是"因果判断"的前提：如果同时改变浓度和温度，就无法判断速率变化是哪个因素造成的。所以探究"浓度对 H2O2 分解速率的影响"时，温度、催化剂用量、H2O2 体积都必须相同，只改变浓度。

对比实验是"排除干扰"的手段：要证明 MnO2 能加快 H2O2 分解，必须设置"不加 MnO2"的对照组；要证明某气体是 CO2，必须用"能使澄清石灰水变浑浊"这一特征现象，并排除 SO2 等干扰。

## 典型例子与方程式

**2H2O2 --MnO2--> 2H2O + O2↑**：比较不同催化剂或不同浓度对分解速率的影响。它说明控制变量实验的设计：只改一个因素，其余条件一致，用气泡产生快慢或带火星木条复燃作证据。

**CaCO3 + 2HCl = CaCl2 + CO2↑ + H2O**：实验室制 CO2 的原理。它说明装置选择要匹配"固体 + 液体不加热"，并用向上排空气法收集（CO2 密度比空气大、能溶于水）。

**CO2 + Ca(OH)2 = CaCO3↓ + H2O**：检验 CO2 的特征反应。它说明"检验"要选特征现象，且要排除 SO2 等也能与石灰水反应的干扰气体。

## 常见易错点

- **"探究浓度对速率的影响时，同时改变温度"**：错。未控制变量，无法判断是浓度还是温度造成差异。
- **"用排水法收集 CO2"**：错。CO2 能溶于水并与水反应，应用向上排空气法。
- **"实验评价只看现象是否明显"**：错。还要看原理是否正确、操作是否安全、尾气是否处理、步骤是否简约。
- **"验证某物质只需要做一个实验"**：错。需要对照与干扰排除；例如检验 SO4^2- 要先酸化再加 BaCl2。
- **"为了加快反应，把酒精灯火焰调大即可"**：不严谨。升温可能改变产物或使反应物挥发，方案设计要先确认温度对反应的影响。
