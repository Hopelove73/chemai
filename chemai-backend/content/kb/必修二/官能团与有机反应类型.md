# 官能团与有机反应类型

> 一句话定位：有机化学的"语法书"——看到官能团就知道能发生什么反应，看到试剂就能反推官能团，这是有机推断的全部基础。

## 是什么

**官能团**是决定有机物特殊性质的原子或原子团。必修二常见官能团与反应：

| 官能团 | 代表物 | 特征反应 |
|---|---|---|
| 碳碳双键 C=C | 乙烯 | 加成、加聚、氧化（KMnO4 褪色） |
| 羟基 —OH | 乙醇 | 与钠置换、催化氧化、酯化 |
| 羧基 —COOH | 乙酸 | 弱酸性、酯化 |
| 酯基 —COO— | 乙酸乙酯 | 水解（酸性可逆、碱性不可逆） |
| 苯环 | 苯 | 取代（溴代、硝化）、加氢 |

**四大反应类型**：

1. **取代反应**：有机物分子中某些原子或原子团被其他原子或原子团替换。如烷烃的卤代、苯的溴代/硝化、酯化、酯的水解。
2. **加成反应**：双键（或三键）中的不饱和键断裂，两端各加上原子或原子团。如乙烯与 Br2、H2、HCl、H2O 的加成。
3. **氧化反应**：有机物得氧或失氢。如燃烧、乙醇催化氧化、醛被氧化。
4. **加聚反应**：含双键的单体相互加成生成高分子。

## 为什么这样

官能团决定性质：同一官能团在不同分子中表现相似的性质（乙醇与丙醇都与钠反应），不同官能团性质差异很大（乙醇与二甲醚分子式相同，但乙醇与钠反应、二甲醚不反应）。

判断反应类型的方法：**看官能团的变化**。双键变单键 → 加成；某个原子被替换 → 取代；得氧/失氢 → 氧化；小分子变高分子且无双键 → 加聚。

## 典型例子与方程式

**CH2=CH2 + Br2 = CH2BrCH2Br**：乙烯使溴水褪色。它说明碳碳双键的加成反应，也是检验不饱和键的经典方法。

**2C2H5OH + O2 --Cu、加热--> 2CH3CHO + 2H2O**：乙醇催化氧化为乙醛。它说明羟基可以被氧化；醇的氧化是有机合成中引入醛基的重要一步。

**CH3COOH + C2H5OH ⇌ CH3COOC2H5 + H2O（浓硫酸、加热）**：酯化反应。它说明羧基与羟基之间的取代（酯化），浓硫酸催化并吸水。

**CH3COOC2H5 + NaOH --加热--> CH3COONa + C2H5OH**：酯的碱性水解。它说明酯基的水解；碱性条件不可逆，酸性条件可逆。

## 常见易错点

- **"酯化反应不是取代反应"**：错。酯化是羧基与羟基之间的取代反应。
- **"乙烯使溴水褪色与苯使溴水褪色原理相同"**：错。乙烯是加成（化学变化），苯是萃取（物理变化）。
- **"氧化反应必须有氧气参加"**：错。乙醇被酸性 KMnO4 氧化、乙醛被银氨溶液氧化，都不需要 O2。
- **"水解反应都是取代反应"**：必修阶段可把酯的水解、蛋白质水解归入取代；但要注意它们的方向与条件不同。
- **"有双键就一定能发生加成"**：不严谨。苯环中的特殊键难加成；需要看具体结构与条件。
