# 化学品的合理使用

> 一句话定位：化学品没有绝对的"好"与"坏"，关键在于"用对剂量、用对场合"——化肥、农药、药物、食品添加剂都遵循同一条原则。

## 是什么

**化肥与农药**：

- 化肥主要有氮肥、磷肥、钾肥。合理施用能提高产量；过量施用会造成水体富营养化、土壤板结。
- 农药如波尔多液（硫酸铜与石灰乳的混合物），能防治病害，但过量使用会残留、污染环境。

**合理用药**：

- 处方药（R）需凭医生处方购买，非处方药（OTC）可自行购买；
- 阿司匹林等解热镇痛药、抗生素等都要按剂量、按疗程使用；滥用抗生素会导致细菌耐药性。

**食品添加剂**：

- 按功能分为防腐剂、着色剂、调味剂、营养强化剂等；
- 在规定范围内使用是安全的；超范围、超限量使用才危害健康。

## 为什么这样

为什么"剂量决定毒性"？任何物质在足够高的剂量下都可能有害；食品添加剂经过风险评估，规定了每日允许摄入量和最大使用量，按标准使用不会危害健康。

为什么化肥过量反而减产？过量施肥会使土壤盐分升高、板结，作物根系吸水困难；同时氮、磷随雨水进入水体，造成藻类疯长（富营养化），破坏水生态。

## 典型例子与方程式

**NH4HCO3 --加热--> NH3↑ + CO2↑ + H2O**：碳酸氢铵受热分解。它说明铵态氮肥要密封、避光、阴凉保存，不能与碱性物质混用。

**CuSO4 + Ca(OH)2 = Cu(OH)2↓ + CaSO4**：波尔多液的配制反应。它说明农药的有效成分是 Cu(OH)2（及铜离子），配制时不能过量。

**NaHCO3 + HCl = NaCl + H2O + CO2↑**：碳酸氢钠中和胃酸。它说明 NaHCO3 可作抗酸药；但过量服用会产生 CO2，胃溃疡患者需慎用。

## 常见易错点

- **"食品添加剂都是有害的"**：错。按国家标准在规定范围内使用是安全的；有害的是超范围、超限量使用。
- **"天然物质一定安全"**：错。天然物质也可能有毒（如毒蘑菇、烟草），安全性取决于物质本身与剂量。
- **"化肥施得越多越好"**：错。过量施肥会造成土壤板结、水体富营养化，反而减产。
- **"抗生素可以随意使用"**：错。滥用抗生素会导致细菌耐药性，必须遵医嘱、按疗程使用。
- **"波尔多液可以任意浓度配制"**：错。浓度过高会灼伤作物、造成铜污染，应按规范配比。
