# 氮氧化物与酸雨

> 一句话定位：NO 与 NO2 是氮的两种"问题氧化物"——NO 一见空气就变红棕色，NO2 遇水既生成硝酸又放回 NO，这条链通向硝酸型酸雨与光化学烟雾。

## 是什么

**一氧化氮（NO）**：无色、无味、难溶于水的有毒气体。常温下极易与 O2 化合生成 NO2，所以只能用排水法收集。

**二氧化氮（NO2）**：红棕色、有刺激性气味的有毒气体，密度比空气大，易溶于水并与水反应。

两者都是**氮氧化物（NOx）**，主要来源是汽车尾气、硝酸工业与化石燃料燃烧。危害包括：**硝酸型酸雨**、**光化学烟雾**（NOx 与挥发性有机物在阳光下反应）、刺激呼吸道。

**处理**：碱液吸收（工业尾气）、汽车尾气催化转化（NO 与 CO 反应生成 N2 与 CO2）。

## 为什么这样

NO 中氮为 **+2 价**，易被 O2 氧化到 +4；NO2 中氮为 **+4 价**，与水反应时**歧化**：一部分升到 +5（HNO3），一部分降到 +2（NO）。所以 NO2 与水反应不是简单的"酸性氧化物 + 水"，而是氧化还原反应。

正因为如此，**NO2 不是硝酸的酸酐**——硝酸的酸酐是 N2O5，它与水化合只生成 HNO3，没有价态变化。

## 典型例子与方程式

**2NO + O2 = 2NO2**：无色气体接触空气立即变红棕色。它说明 NO 不能排空气收集，也是"检验 NO 被氧化"的最直观现象。

**3NO2 + H2O = 2HNO3 + NO**：NO2 溶于水生成硝酸，同时放出一氧化氮。它说明 NO2 与水反应是歧化（+4 → +5 与 +2），工业制硝酸的尾气吸收也基于此。

**2NO2 ⇌ N2O4**：NO2 与 N2O4 在常温下共存，加压时颜色变浅（向 N2O4 方向移动）。它说明"红棕色"是混合体系的颜色，不是单一 NO2。

**2NO2 + 2NaOH = NaNO2 + NaNO3 + H2O**：用碱液吸收 NO2 尾气。它说明 NO2 的尾气不能用简单水吸收（会放出 NO），用碱可同时吸收两种价态。

**2NO + 2CO --催化剂--> N2 + 2CO2**：汽车尾气催化转化器中的反应。它说明 NO 的氧化性可以被利用来消除 CO，把两种污染物同时转化为无害物质。

## 常见易错点

- **"NO 可以用排空气法收集"**：错。NO 与 O2 迅速反应生成 NO2，只能用排水法。
- **"NO2 是酸性氧化物，是硝酸的酸酐"**：错。NO2 与水反应发生氧化还原，生成 HNO3 和 NO；硝酸的酸酐是 N2O5。
- **"酸雨只由 SO2 造成"**：错。SO2 造成硫酸型酸雨，NOx 造成硝酸型酸雨，二者常同时存在。
- **"NO2 溶于水只生成硝酸"**：错。还生成 NO，反应是歧化；这也是工业制硝酸需要补充空气把 NO 再氧化的原因。
