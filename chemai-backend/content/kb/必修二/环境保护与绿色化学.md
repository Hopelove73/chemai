# 环境保护与绿色化学

> 一句话定位：环境保护的终点不是"把污染物处理掉"，而是"从一开始就不产生污染物"——这就是绿色化学与末端治理的根本区别。

## 是什么

**主要环境问题**：

- **大气污染**：酸雨（pH < 5.6，硫酸型由 SO2 引起、硝酸型由 NOx 引起）、光化学烟雾、温室效应、颗粒物（PM2.5）；
- **水污染**：富营养化（氮、磷过量导致藻类疯长）、重金属污染、有机物污染；
- **土壤污染**：重金属、农药残留、固体废弃物。

**三废处理**：废气（碱液吸收、脱硫脱硝）、废水（中和、沉淀、生化处理）、废渣（回收、填埋、资源化）。

**绿色化学**：从源头上减少或消除污染，核心是**原子经济性**——使反应物的原子尽可能多地进入目标产物。原子利用率 = 目标产物的质量 ÷ 反应物总质量 × 100%。

## 为什么这样

为什么绿色化学优于末端治理？末端治理是"先污染后处理"，成本高、可能产生二次污染；绿色化学从原料、反应、催化剂、产品全流程设计，减少甚至不产生污染物。

为什么原子经济性重要？原子利用率高的反应，原料浪费少、副产物少、分离成本低。例如化合反应、加成反应的原子利用率可达 100%，而取代反应通常有副产物，原子利用率较低。

## 典型例子与方程式

**SO2 + CaO --高温--> CaSO3**：燃煤脱硫，把 SO2 转化为 CaSO3（可进一步氧化为石膏）。它说明废气可以通过化学转化被固定，减少酸雨。

**2NO2 + 2NaOH = NaNO2 + NaNO3 + H2O**：用碱液吸收氮氧化物尾气。它说明 NO2 的歧化可以被利用来处理尾气；但更好的办法是从源头减少 NOx 的生成。

**原子经济性示例**：乙烯与溴的加成反应 C2H4 + Br2 = C2H4Br2，反应物原子全部进入产物，原子利用率为 100%；而取代反应通常有副产物，原子利用率较低。

## 常见易错点

- **"绿色化学就是末端治理"**：错。绿色化学强调源头减量，末端治理是污染产生后的补救。
- **"原子利用率就是产率"**：错。产率是实际产量与理论产量之比；原子利用率是目标产物质量与反应物总质量之比，二者不同。
- **"CO2 是有毒污染物"**：不准确。CO2 不是有毒污染物，但大量排放会引起温室效应；"污染物"与"温室气体"要区分。
- **"酸雨就是 pH < 7 的雨水"**：错。正常雨水也呈弱酸性（约 pH 5.6），酸雨指 pH < 5.6 的降水。
- **"只要处理了废气，就不算污染"**：错。还应从源头减少废气产生，并防止废水、废渣的二次污染。
