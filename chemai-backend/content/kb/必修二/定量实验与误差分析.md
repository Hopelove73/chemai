# 定量实验与误差分析

> 一句话定位：定量实验不只问"能不能做"，更问"测得准不准"——误差分析的核心是判断操作让测量量偏大还是偏小，再代入公式看结果往哪边偏。

## 是什么

必修阶段的定量实验主要有三类：

1. **质量法**：结晶水合物中结晶水的测定（加热前后质量差）、碳酸氢钠纯度测定（加热放出 CO2 与 H2O 的质量差）、沉淀法测含量；
2. **气体体积法**：金属与酸反应测氢气体积、碳酸盐与酸反应测 CO2 体积；
3. **滴定法**：中和滴定等（选择性必修系统学习）。

**误差分析**分两步：先判断操作使**测量量**偏大还是偏小，再代入计算式判断**最终结果**偏大还是偏小。

## 为什么这样

误差方向由"测量值与真实值的关系"决定，不是凭感觉。以结晶水测定为例：

- 坩埚**未干燥** → 加热后剩余固体质量偏大 → 算出的水的质量偏小 → 结晶水数目偏小；
- 加热**不充分** → 结晶水没有完全失去 → 剩余固体偏大 → 结晶水数目偏小；
- 加热后在**空气中冷却** → 无水硫酸铜吸水 → 剩余固体偏大 → 结晶水数目偏小。

同一个公式，三种操作，结论却不同——所以必须逐项分析"哪一步、哪个量、偏大还是偏小"。

## 典型例子与方程式

**CuSO4·5H2O --加热--> CuSO4 + 5H2O↑**：蓝色晶体加热变白，质量减少。它说明结晶水测定靠"加热前后质量差"；必须在干燥器中冷却后称量。

**2NaHCO3 --加热--> Na2CO3 + CO2↑ + H2O**：碳酸氢钠受热分解，固体质量减少。它说明可用质量差法测 NaHCO3 的纯度；加热不充分会使测得的 NaHCO3 偏小。

**Zn + H2SO4 = ZnSO4 + H2↑**：用一定质量的锌与足量稀硫酸反应，测氢气体积。它说明气体体积法要等装置冷却到室温再读数，否则气体体积偏大。

**CaCO3 + 2HCl = CaCl2 + CO2↑ + H2O**：用盐酸与碳酸钙反应测 CO2 体积。它说明气体法要检查装置气密性，否则逸出的气体偏少、结果偏小。

## 常见易错点

- **"加热后的坩埚放在空气中冷却"**：错。应在干燥器中冷却，否则无水硫酸铜吸水，剩余固体质量偏大、结晶水数目偏小。
- **"多次测量取平均值可以消除系统误差"**：错。取平均值只能减小偶然误差，系统误差（如仪器不准、操作顺序错误）不会因重复而消失。
- **"量筒读数仰视偏大"**：错。量筒刻度自下而上增大，仰视时视线偏低，读数偏小；应平视凹液面最低处。
- **"气体体积法不需要冷却到室温"**：错。反应放热会使气体膨胀，未冷却读数偏大；必须冷却后再读。
