# 常见气体的实验室制备（硫氮）

> 一句话定位：把必修一的"气体制备四步法"用到硫、氮上——发生装置看反应物状态与条件，收集方法看密度与溶解性，尾气处理看毒性。

## 是什么

实验室制备气体统一按四步设计：**发生 → 净化 → 收集 → 尾气处理**。

- **SO2**：亚硫酸钠固体与浓硫酸常温反应，**向上排空气法**收集（密度比空气大、易溶于水），尾气用 NaOH 溶液吸收。
- **NH3**：氯化铵与熟石灰共热，**向下排空气法**收集（密度比空气小、极易溶于水），试管口塞棉花减少对流，用湿润的红色石蕊试纸检验；用**碱石灰**干燥。
- **NO**：铜与稀硝酸反应，**排水法**收集（NO 易与空气中的 O2 反应，不能排空气）。
- **NO2**：铜与浓硝酸反应，**向上排空气法**收集（密度比空气大），尾气用 NaOH 溶液吸收。

## 为什么这样

**发生装置**由反应物状态和反应条件决定：固体 + 液体不加热（SO2、NO、NO2）用启普发生器类或试管；固体 + 固体加热（NH3）用大试管、酒精灯，试管口略向下倾斜。

**收集方法**由密度和溶解性决定：比空气轻且极易溶（NH3）→ 向下排空气；比空气重且溶于水（SO2、NO2）→ 向上排空气；难溶于水且与空气反应（NO）→ 排水法。

**尾气处理**由毒性决定：SO2、NO、NO2 都有毒，必须用碱液吸收或点燃处理，不能直接排空。

## 典型例子与方程式

**Na2SO3 + H2SO4(浓) = Na2SO4 + SO2↑ + H2O**：亚硫酸钠与浓硫酸常温反应即得 SO2，不需要加热，发生装置简单。它说明"强酸制弱酸"也适用于制备酸性气体。

**2NH4Cl + Ca(OH)2 --加热--> CaCl2 + 2NH3↑ + 2H2O**：铵盐与碱共热放出氨气，用向下排空气法收集。它说明 NH3 的制备本质是 NH4+ 与 OH- 在加热下反应；不能只用 NH4Cl 加热，因为分解出的 NH3 与 HCl 遇冷又会化合成 NH4Cl。

**3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O**：铜与稀硝酸反应生成无色 NO，只能用排水法收集。它说明 NO 一旦接触空气就迅速被氧化为红棕色 NO2。

**Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2↑ + 2H2O**：铜与浓硝酸反应生成红棕色 NO2，用向上排空气法收集。它说明浓、稀硝酸的还原产物不同（详见 M2-T2-KP09）。

## 常见易错点

- **"NH3 用向上排空气法收集"**：错。NH3 密度比空气小，应向下排空气；试管口向下并塞棉花。错因是默认"排空气都向上"。
- **"NH3 用浓硫酸干燥"**：错。NH3 是碱性气体，会与浓硫酸反应；应使用碱石灰。无水 CaCl2 也不行，会生成 CaCl2·8NH3。
- **"NO 用排空气法收集"**：错。NO 常温下立即与 O2 反应生成 NO2，只能用排水法。
- **"SO2 用排水法收集"**：错。SO2 易溶于水并与水反应，不能用排水法；应用向上排空气法。
- **"实验室用加热 NH4Cl 的方法制 NH3"**：错。NH4Cl 受热分解生成的 NH3 与 HCl 遇冷重新化合，收集不到氨；必须与碱共热。
