# 乙醇

> 一句话定位：乙醇是第一个含氧官能团的有机物——羟基（—OH）决定了它既能与钠反应、又能被催化氧化，是"官能团决定性质"的第一课。

## 是什么

**乙醇（C2H5OH）** [SMILES:CCO]：无色、有特殊香味的液体，密度比水小，能与水**任意比例互溶**，是酒的主要成分，也是重要溶剂和燃料。

乙醇的分子可以看作乙烷分子中的一个氢被**羟基（—OH）**取代。羟基是乙醇的**官能团**——决定乙醇特殊性质的原子团。

**化学性质**：

1. **与钠反应**：生成乙醇钠和氢气，反应比钠与水**缓和**；
2. **催化氧化**：在 Cu 或 Ag 催化、加热条件下被 O2 氧化为乙醛（CH3CHO）；
3. **燃烧**：放出大量热，火焰淡蓝色，可作燃料（乙醇汽油）；
4. **与酸性 KMnO4 溶液反应**：被氧化，使溶液褪色。

## 为什么这样

乙醇的性质为什么与乙烷不同？因为多了羟基。羟基中的 O—H 键极性强，氢原子较活泼，能与钠反应放出 H2；同时，羟基使乙醇分子能与水形成氢键，所以乙醇与水互溶——这正是"官能团决定性质"的典型。

为什么乙醇与钠反应比水缓和？乙醇中羟基的氢不如水中的氢活泼（乙基是推电子基团，使 O—H 键极性减弱），所以反应放氢的速率比钠与水慢。

## 典型例子与方程式

**2C2H5OH + 2Na = 2C2H5ONa + H2↑**：钠块投入乙醇中，缓慢产生气泡，钠沉在底部。它说明乙醇的羟基氢能被置换，但反应比水缓和；也说明乙醇与钠反应不是"钠浮在液面"。

**2C2H5OH + O2 --Cu、加热--> 2CH3CHO + 2H2O**：灼热的铜丝插入乙醇中，反复几次后闻到刺激性气味（乙醛）。它说明乙醇能被催化氧化，铜丝先被氧化为 CuO、再被乙醇还原，起催化剂作用。

**C2H5OH + 3O2 --点燃--> 2CO2 + 3H2O**：乙醇完全燃烧。它说明乙醇可作燃料；乙醇汽油是乙醇与汽油的混合物，能减少部分污染物排放。

## 常见易错点

- **"乙醇与钠反应比钠与水更剧烈"**：错。乙醇中羟基氢的活性低于水中的氢，反应更缓和。
- **"乙醇的官能团是乙基"**：错。官能团是羟基（—OH）；乙基是烃基，不决定乙醇的特征性质。
- **"医用酒精是 100% 乙醇"**：错。医用消毒酒精通常是 75%（体积分数）的乙醇溶液，过高浓度会使细菌表面蛋白质过快凝固，反而影响杀菌效果。
- **"乙醇汽油是化合物"**：错。乙醇汽油是乙醇与汽油的混合物。
- **"乙醇不能使酸性 KMnO4 溶液褪色"**：错。乙醇能被酸性 KMnO4 氧化，使溶液褪色。
