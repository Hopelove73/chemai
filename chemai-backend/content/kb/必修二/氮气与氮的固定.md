# 氮气与氮的固定

> 一句话定位：氮气占空气近八成却"不活泼"——N≡N 三键是它稳定的原因，也是人类必须用合成氨"打开"它的原因。

## 是什么

氮气（N2）是无色无味气体，难溶于水，约占空气体积的 78%。氮分子中两个氮原子以**三键（N≡N）**结合，键能很大，所以常温下化学性质**很稳定**：不与氧气、酸、碱反应，也不与大多数金属反应。

**氮的固定**：把游离态的氮（N2）转化为化合态氮的过程。三条路径：

1. **自然固氮**：雷电固氮（N2 与 O2 在放电条件下生成 NO）、生物固氮（根瘤菌等把 N2 转化为含氮化合物）；
2. **人工固氮**：工业合成氨（N2 + 3H2 ⇌ 2NH3）；
3. **仿生固氮**：模拟生物固氮的温和条件，仍在研究中。

**氮循环**：大气中的 N2 → 固氮 → 含氮化合物 → 动植物吸收 → 分解、反硝化 → 回到 N2。

## 为什么这样

N≡N 三键键能大，断裂需要很高能量，所以氮气稳定。要让 N2 参与反应，必须提供**高温、放电或催化剂**等条件——这就是合成氨需要高温、高压、催化剂的原因（条件选择见 M2-T3-KP04）。

从氧化还原看：N2 中氮为 **0 价**，既可被还原（0 → -3，如合成氨），也可被氧化（0 → +2，如放电生成 NO），但两个方向都需要苛刻条件。

## 典型例子与方程式

**N2 + 3H2 ⇌ 2NH3（高温、高压、催化剂）**：工业合成氨，最重要的人工固氮。它说明 N2 的稳定性要靠苛刻条件打破；反应可逆，所以实际转化率不可能达到 100%（M1-T3-KP08）。

**N2 + O2 --放电--> 2NO**：雷电时空气中生成 NO，随后被氧化为 NO2 并溶于雨水，是自然固氮与硝酸型酸雨的起点。它说明氮气在高能条件下可被氧化。

**N2 + 3Mg --点燃--> Mg3N2**：镁条在氮气中燃烧生成氮化镁。它说明 N2 在高温下能与活泼金属反应；也提醒"镁条在空气中燃烧"的产物不止 MgO。

## 常见易错点

- **"N2 化学性质稳定，所以不与任何物质反应"**：错。条件足够时 N2 可与 H2、O2、Mg 等反应；"稳定"是相对的。
- **"氮的固定只有工业合成氨"**：错。雷电固氮、生物固氮都是自然固氮；人工固氮只是其中一条路径。
- **"N2 无毒，所以氮的氧化物也无毒"**：错。NO、NO2 都有毒，NO 能与血红蛋白结合，NO2 强烈刺激呼吸道。
- **"合成氨在常温常压下就能顺利发生"**：错。常温常压下反应极慢，必须高温、高压并使用催化剂。
