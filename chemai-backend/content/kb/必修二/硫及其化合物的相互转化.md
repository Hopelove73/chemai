# 硫及其化合物的相互转化

> 一句话定位：把硫单质、SO2、硫酸串成一张价态网络——-2、0、+4、+6 四个价态之间的升降，就是硫元素化合物的全部主线。

## 是什么

硫元素在化合物中常见四个价态：

| 价态 | 代表物质 |
|---|---|
| -2 | H2S、Na2S、FeS |
| 0 | S（硫单质） |
| +4 | SO2、H2SO3、Na2SO3 |
| +6 | SO3、H2SO4、Na2SO4 |

**转化主线**：-2 → 0 → +4 → +6 逐级被氧化；反向逐级被还原。同价态之间则通过酸碱反应、复分解反应转化（如 SO2 与 NaOH 生成 Na2SO3）。生成 0 价硫单质的常见路径有两条：**不完全氧化**（O2 少量时 2H2S + O2 = 2S↓ + 2H2O）与**归中**——硫化氢与二氧化硫混合直接析出硫单质（2H2S + SO2 = 3S↓ + 2H2O）。

**工业制硫酸**：硫（或硫铁矿）燃烧生成 SO2 → SO2 催化氧化为 SO3 → 用 98.3% 浓硫酸吸收 SO3 得到硫酸。

## 为什么这样

价态变化的方向由氧化剂、还原剂决定：升价要加氧化剂，降价要加还原剂。**相邻价态之间不发生氧化还原**——例如 SO2（+4）与浓硫酸（+6）混合不反应，因为 +4 再升到 +6 需要更强的氧化条件，而 +6 也无意降到 +4。

**归中原理**：同种元素的高价与低价相遇，会向中间价态靠拢，且**不交叉**。H2S（-2）与 SO2（+4）反应生成 S（0）而不生成更低价或更高价产物，就是这个原理。

## 典型例子与方程式

**S + O2 --点燃--> SO2**：硫燃烧，0 → +4。它是整个网络的入口，说明硫单质可被氧化到 +4。

**H2S + H2SO4(浓) = S↓ + SO2↑ + 2H2O**：-2 价的 H2S 与 +6 价的浓硫酸相遇，生成 0 价的 S 与 +4 价的 SO2。它同时体现归中与"浓硫酸的强氧化性"。

**2H2S + SO2 = 3S↓ + 2H2O**：硫化氢与二氧化硫两种气体混合，生成淡黄色的硫单质并析出。它说明 -2 与 +4 归中到 0，是归中原理最干净的样本。混合前两种气体都无色，反应后出现淡黄色固体——看到硫单质析出，就应想到"低价 + 高价 → 归中生成 0 价"。

**2SO2 + O2 ⇌ 2SO3（催化剂、加热）**：+4 → +6，接触法制硫酸的核心一步。它说明升价需要催化剂与加热，且反应可逆。

**SO3 + H2O = H2SO4**：SO3 与水化合生成硫酸。工业上不用水直接吸收，而用 98.3% 浓硫酸，避免放热形成酸雾、降低吸收效率——这是"实验室反应"与"工业实现"的差别。

## 常见易错点

- **"SO2 与浓硫酸能反应"**：错。二者是相邻价态（+4 与 +6），不发生氧化还原；浓硫酸不能把 SO2 再氧化。错因是见"强氧化性"就以为能氧化一切。
- **"硫的转化只能靠氧化还原反应"**：错。同价态之间靠复分解或酸碱反应，如 SO2 + 2NaOH = Na2SO3 + H2O、H2SO4 + BaCl2 = BaSO4↓ + 2HCl。
- **"工业制硫酸用水吸收 SO3"**：错。用水吸收会放出大量热、形成酸雾，吸收效率低；工业用 98.3% 浓硫酸吸收。
- **"酸雨只由 SO2 造成"**：错。SO2 主要造成硫酸型酸雨，氮氧化物还造成硝酸型酸雨（见 M2-T2-KP06）。
