# 溶解性与手性

> 一句话定位："相似相溶"给溶解性装上分子级解释；手性碳连着四个不同基团——镜像互为对映异构体，生命分子几乎都是"单手"的。

## 是什么

**相似相溶**：极性分子易溶于极性溶剂（水），非极性分子易溶于非极性溶剂（汽油、CCl4）。

- 修正一：**氢键**可显著提升水溶性（乙醇、氨、乙酸与水任意比互溶）；
- 修正二：结构相似性比"极性标签"更根本（H2O 与乙醇互溶、与苯不溶；NaCl 溶于水不溶于汽油——离子化合物另论）。

**手性碳**：连接**四个互不相同**原子/基团的碳原子。含手性碳的分子与其镜像**不能重叠**——互为**对映异构体**（性质在旋光等手性环境中不同，生理活性常天差地别）。

**判断步骤**：找 sp³ 碳 → 看四个基团是否两两不同（按 C 原子序数比到分出差异为止）。

## 为什么这样

为什么"相似相溶"？溶解的推动力是"溶质分子与溶剂分子之间的吸引"：极性-极性（偶极-偶极、氢键）、非极性-非极性（范德华力）都能建立亲密关系；极性与非极性之间"聊不来"，能量上不合算。H2O 溶解乙醇是氢键的功劳，溶解 NaCl 是水合离子的功劳——机制不同，结论同向。

为什么镜像不能重叠？手性碳的四个基团呈四面体分布——就像左手与右手，任何旋转平移都无法让左手变右手。这类"立体差异"在普通化学反应中难以区分，但在生物酶（手性环境）中天差地别——历史上"反应停"致畸就是两种对映体一好一坏。

## 典型例子与方程式

**乙醇与二甲醚**：分子式相同（C2H6O），乙醇有羟基能与水形成氢键 → 与水任意比互溶；二甲醚无 O—H → 气体、微溶于水。它说明"氢键能力"比极性标签更能解释溶解性。

**CHFClBr**：碳上连 H、F、Cl、Br 四个不同基团 → 手性碳。它说明最小的手性分子判断；CH2ClBr 则不是（两个 H 相同）。

**乳酸 CH3CH(OH)COOH**：中心碳连 H、OH、CH3、COOH 四个不同基团 → 手性。它说明人体内常见的手性分子；发酵产生的乳酸与运动产生的乳酸是对映体。

## 常见易错点

- **"极性分子都溶于水"**：错。看整体：CH3Cl 是极性分子但只有微溶于水（不能形成足够氢键、烃基占主导）。
- **"手性碳必须连四个不同**原子**"**：错。是四个不同**原子或基团**——-OH 与 -OCH3 是不同基团。
- **"有手性碳就一定有两种对映体都能买到"**：错。自然界酶促反应常只产一种对映体；人工合成常得外消旋混合物。
- **"对映异构体的熔沸点不同"**：错。普通（非手性）环境中对映体物理性质完全相同；差别只在旋光与手性环境下的反应性。
