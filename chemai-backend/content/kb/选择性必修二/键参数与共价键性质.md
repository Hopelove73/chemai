# 键参数与共价键性质

> 一句话定位：给共价键做"体检"的三个指标——键能定强弱、键长定距离、键角定形状；等电子体是"结构相似"的判断工具。

## 是什么

**键能**：气态分子断开 1 mol 某键生成气态原子/基团所吸收的能量。**越大 → 键越牢固 → 分子越稳定**。

**键长**：成键两原子核间的平均距离。**越短 → 键越强**（同族氢化物 H—F < H—Cl < H—Br < H—I，键能递减）。

**键角**：两共价键之间的夹角——决定分子的**空间构型**（H2O 104.5° → V 形；CO2 180° → 直线形）。

**等电子体**：**原子总数相同、价电子总数相同**的微粒——结构与性质相似（CO2 与 N2O、CO 与 N2）。判断"长得像"的快捷工具。

## 为什么这样

为什么键能大分子就稳定？分解分子要断键，键能是断键的"成本"——成本高的分子不易分解（N≡N 键能 946 kJ/mol → N2 极稳定）。注意"键能"衡量的是**该键**的强度，分子的热稳定性还要看分子内所有键的整体。

为什么键长越短键越强？核间距离小，电子云与两核的吸引更充分——同主族从上到下半径增大、键长变长、键能变小，一环扣一环。

为什么键角能定构型？几个键角组合起来就是分子的立体形状——109.5° 是四面体、120° 是平面三角形、180° 是直线形（与 VSEPR/杂化对应，M4-T2-KP03/04）。

## 典型例子与方程式

**H—F、H—Cl、H—Br、H—I 键能递减**：568 → 431 → 366 → 299 kJ/mol。它说明"键长越长键能越小"，并解释卤化氢稳定性 HF > HCl > HBr > HI。

**键角家族**：CH4 109°28′、NH3 107°、H2O 104.5°。它说明"孤对电子压缩键角"的初步证据（VSEPR 下篇展开）。

**等电子体 CO 与 N2**：都是 2 原子 10 价电子。它说明两者性质相似（都难溶、都作还原剂）——等电子推理在陌生分子题中的应用。

## 常见易错点

- **"键能越大，含有该键的分子一定越稳定"**：不严谨。比较的是**该键**的强度；分子稳定性综合所有键（如 H2O 分子稳定看 O—H 键能，不看 O=O）。
- **"键角越大分子越稳定"**：错。键角只定形状，与稳定性无直接因果。
- **"等电子体只要原子数相同"**：错。必须原子数与价电子数**都**相同。
- **"键能可以从液体分子上测"**：错。键能定义限定**气态**。
