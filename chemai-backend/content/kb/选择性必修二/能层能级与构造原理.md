# 能层能级与构造原理

> 一句话定位：把必修一的"电子分层排布"精细化——层里有能级、能级里有轨道，电子按构造原理从低到高填。

## 是什么

**能层**：电子层，n = 1、2、3……（K、L、M、N），能量随 n 增大而升高。

**能级**：同一能层内能量还有细分，s、p、d、f……；第 n 能层有 n 个能级（ns、np、nd……），能量 s < p < d < f。同一能级最多容纳 2s² 2p⁶ 2d¹⁰ ……（2n² 总容量）。

**构造原理**：电子填入能级的能量顺序——1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s……（注意 4s 先于 3d 的"能级交错"）。

**基态与激发态**：电子处于最低能量排布为基态；吸收能量跃迁到高能级为激发态——**原子光谱**（发射/吸收）就是跃迁的指纹，可用于鉴定元素。

## 为什么这样

为什么要分层再分级？必修一的"分层"解释不了多电子原子的精细光谱——同一层里的电子能量并不完全相同，p 比 s 高一点，d 更高。能级是光谱实验"逼"出来的结构单位。

为什么 4s 比 3d 先填？多电子原子中，4s 电子能"钻"到内层附近（钻穿效应），平均能量反而低于 3d——所以钾、钙的最后一个电子进 4s 而不是 3d。这是"能量最低"在多电子体系里的具体表现。

## 典型例子与方程式

**构造原理顺序**：1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p。它说明写电子排布式要按此顺序填（如 Fe：1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s²）——书写时按能层归并，但填充顺序按构造原理。

**焰色与光谱**：钠的黄色焰色（M1-T1-KP06）对应 Na 外层电子跃迁释放的特定能量。它说明"激发态 → 基态"放出光子，波长由能级差决定——每种元素一套独特谱线。

## 常见易错点

- **"能级数与能层序数无关"**：错。第 n 能层恰好有 n 个能级（K 层只有 1s）。
- **"3d 能量一定低于 4s"**：错。多电子原子存在能级交错，填充时 4s 先于 3d。
- **"电子排布式按能层顺序书写就是填充顺序"**：错。书写按 1s 2s 2p 3s 3p 3d 4s 归并（d 写在 s 前），填充按构造原理（4s 先于 3d）。
- **"激发态原子会一直发光"**：错。跃迁回基态放光后即回到稳定态；持续发光需要持续供给能量。
