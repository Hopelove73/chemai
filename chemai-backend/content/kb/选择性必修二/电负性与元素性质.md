# 电负性与元素性质

> 一句话定位：原子"抢电子"的胃口量化成数——电负性差大生离子键、差小生共价键，同周期非金属性的电负性标尺。

## 是什么

**电负性**：衡量原子在化合物中**吸引电子能力**的相对大小（鲍林标度，F 最大定为 4.0）。

**周期性**：同周期从左到右增大（F > O > N ≈ Cl > …）；同主族从上到下减小。

**应用三条**：

1. **金属性/非金属性判据**：电负性小 → 金属性强；电负性大 → 非金属性强；
2. **键型与极性预测**：Δχ 很大（Na 与 Cl）→ 离子键；Δχ 较小 → 极性共价键；Δχ = 0（同种元素）→ 非极性共价键；
3. **化合价与氧化性预测**：高电负性元素显负价、作氧化剂。

## 为什么这样

为什么电负性能"预测"键型？成键电子的归属由两原子抢电子的能力差决定：差到一边倒 → 电子彻底转移（离子键）；有差但不悬殊 → 共用偏移（极性共价）；无差 → 对称共用（非极性共价）。**离子键与共价键不是两种孤立物质，是"抢电子差"光谱的两端**。

为什么 F 是标度顶点？F 原子半径小、核电荷对最外层拉力强（第二周期无 d 轨道屏蔽），抢电子能力全表最强——这也是氟化物中 F 恒显 -1 价的原因。

## 典型例子与方程式

**同周期排序**：电负性 Na < Mg < Al < Si < P < S < Cl（F 最强）。它说明非金属性 Cl > S > P 的电负性注脚，与最高价氧化物水化物酸性强弱（M1-T3-KP04）互证。

**键型三分**：NaCl（Δχ = 2.1）离子键；HCl（Δχ = 0.9）极性共价键；Cl2（Δχ = 0）非极性共价键。它说明"差值光谱"判断键型的用法。

**HF 与 HI 的对比**：电负性差 H—F > H—I，HF 键的极性更强。它说明由电负性差预测共价键极性的具体操作。

## 常见易错点

- **"电负性就是化合价"**：错。电负性是抢电子能力；化合价是成键数目与正负的表述。
- **"电负性差大就一定是离子键"**：不严谨。差大**倾向**离子键，但极性共价与离子键是渐变；中学阶段按"典型对"判断。
- **"电负性与电离能是一回事"**：错。电离能是丢电子的难度（原子性质），电负性是抢电子的能力（分子内行为），两者同源不同义。
- **"稀有气体电负性按周期律外推最小"**：错。稀有气体数据特殊（部分标度高），不参与常规比较。
