# 共价晶体

> 一句话定位：整块晶体就是一颗"大分子"——原子间全靠共价键连成空间网状，熔点高、硬度大、不导电（硅除外）。

## 是什么

**共价晶体**（旧称原子晶体）：晶格结点上排列**原子**，靠**共价键**连成空间网状结构。

**代表**：

- **金刚石**：每个碳与 4 个碳成键（sp³），正四面体向三维延伸——天然最硬的物质之一，熔点 3550 ℃；键角 109°28′；
- **二氧化硅**：每个 Si 与 4 个 O、每个 O 与 2 个 Si（Si∶O = 1∶2）；石英、水晶的主要成分；
- **硅、锗**：类金刚石结构，半导体。

**通性**：熔点**高**、硬度**大**、**不导电**（硅、锗半导体例外）、难溶于一般溶剂。

**结构决定性能**：打破晶体必须断**共价键**（几百 kJ/mol）——这与分子晶体"只断分子间力"形成极端对照。

## 为什么这样

为什么金刚石与石墨同是碳、性能天差地别？金刚石 sp³ 杂化三维网状（硬、绝缘）；石墨 sp² 层状、层内大 π 键（导电）、层间范德华力（软、滑）。**同素异形体的性质差异全部来自"连接方式"**——这是"结构决定性质"最震撼的样本。

为什么 SiO2 硬而 CO2 常温是气体？SiO2 是共价晶体（Si—O 共价键贯穿整块）；CO2 是分子晶体（分子内 C=O 键很强，但分子间只有范德华力）。**"谁在维系晶体"决定性质，不是"键多强"决定**。

## 典型例子与方程式

**金刚石网状结构**：每个 C 是四配位中心，键角 109°28′（与甲烷同款）。它说明 sp³ 杂化在晶体中的"放大"；切割金刚石要沿特定晶面（各向异性）。

**SiO2 结构**：Si 与 O 交替连接的骨架；Si∶O = 1∶2 与化学式一致。它说明"化学式的计量比"在网状结构中的来源；也与 SiO2 + 4HF = SiF4↑ + 2H2O（M2-T2-KP11 唯一能腐蚀它的酸）呼应。

**硅的半导体性**：类金刚石结构但导电性介于导体绝缘体之间。它说明"结构类似、性能可调"——掺杂半导体是芯片的物理基础。

## 常见易错点

- **"SiO2 是分子式"**：错。它是化学式（计量比）；共价晶体没有"单个分子"，SiO2 应写作 SiO2 而非 (SiO2)n。
- **"共价晶体都不导电"**：不严谨。硅、锗是半导体（本篇例外要记住）；金刚石不导电但导热极好。
- **"共价晶体能溶于水"**：错。断共价键的溶解几乎不存在（SiO2 只与 HF 反应）。
- **"硬度大就是共价晶体"**：错。判断看微粒与维系力；硬度只是结果之一。
