# 合成高分子的基本方法

> 一句话定位：高分子只有两条出生路——加聚（只断 π 不掉东西）与缩聚（成键同时掉小分子）；"反推单体"是高分子题的一半功夫。

## 是什么

**加聚反应**（加成聚合）：含不饱和键（C=C）的单体**开键相连**，无小分子副产物。

- 单体特征：含 C=C（或 C≡C）；
- 例：乙烯 → 聚乙烯；氯乙烯 → 聚氯乙烯（PVC）；丙烯 → 聚丙烯。

**缩聚反应**（缩合聚合）：单体间成键**同时脱去小分子**（H2O 等）。

- 单体特征：**至少两个**官能团（二元酸+二元醇 → 聚酯；氨基酸 → 蛋白质/尼龙）；
- 例：对苯二甲酸 + 乙二醇 → 涤纶（聚酯纤维）+ 水。

**三个术语**：**单体**（原料小分子）、**链节**（高分子中的重复单元）、**聚合度 n**（链节数目）。

**反推单体（断键还原法）**：

- 加聚高分子：把主链**每两个碳一刀切**回 C=C——[-CH2-CH2-]n → CH2=CH2；
- 缩聚高分子：在**成键处补回脱掉的小分子**（酯键处补水、肽键处补水）——涤纶的酯键 -COO- 拆成 -COOH 与 -OH。

## 为什么这样

为什么缩聚要求"至少两个官能团"？每个单体要向**两个方向**继续成键才能连成长链——一官能团单体只能成小分子（如乙酸与乙醇只成乙酸乙酯就"封口"了）。**官能团数目 ≥ 2 是缩聚成链的门票**。

为什么加聚的产物写不出"确定的分子量"？聚合度 n 是统计分布——聚乙烯是 n 从几百到几万的混合物，没有固定分子式，只有链节与 n 的范围。

## 典型例子与方程式

**nCH2=CH2 --催化剂--> [-CH2-CH2-]n**：聚乙烯。它说明加聚"开 π 键、闭合成链"，链节 = CH2—CH2，单体唯一。

**nHOOC-C6H4-COOH + nHOCH2CH2OH --催化剂--> 涤纶 + 2nH2O**：涤纶（聚酯）缩聚。它说明缩聚的"双官能团对拉 + 脱水"；单体有两种——反推时要在每个酯键处补水拆解。

**蛋白质 → 氨基酸**：肽键处水解补氢补羟基。它说明生物高分子与合成高分子共用"缩聚-水解"化学（M5-T3-KP02）。

## 常见易错点

- **"加聚反应有小分子生成"**：错。加聚只开不饱和键、无小分子；掉小分子的是缩聚。
- **"缩聚单体可以只含一个官能团"**：错。一官能团"封口"无法成链。
- **"反推单体时把整条链一刀切成两半"**：错。加聚按"每个双键单元两碳一切"；缩聚按每个成键处补水。
- **"链节就是单体"**：不严谨。加聚的链节与单体组成相同（但结构变了）；**缩聚的链节比单体少 H2O**——涤纶链节 -OC-C6H4-CO-OCH2CH2- 不含原单体的全部氢氧。
- **"聚合度 n 是定值"**：错。n 是分布；高聚物是混合物（M2-T4-KP11）。

## 与其他知识的联系

先修：有机高分子材料（M2-T4-KP11）的加聚初步；酯与油脂深化（M5-T2-KP09）的酯化/水解是缩聚/解聚的模板；蛋白质与氨基酸深化（M5-T3-KP02）的肽键是生物缩聚。

后继：高分子材料（M5-T3-KP05）把方法学落到材料性能；环境保护与绿色化学（M2-T5-KP05）的降解问题在高分子端解决。
