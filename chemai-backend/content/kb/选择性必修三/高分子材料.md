# 高分子材料

> 一句话定位：三大合成材料（塑料、橡胶、纤维）的性能密码写在链与链之间——线型/体型结构、结晶度、交联度，加上"能设计功能"的下一代高分子。

## 是什么

**结构决定性能的两条主线**：

- **线型高分子**：长链状，链间靠范德华力/氢键——**可溶、可熔**（热塑性，可反复加工）：聚乙烯、聚氯乙烯；
- **体型（交联）高分子**：链间共价"桥"——**不溶不熔**（热固性）：酚醛塑料（电木）、硫化橡胶。

**三大材料**：

1. **塑料**：热塑（PE、PVC、PP）与热固（酚醛）；
2. **橡胶**：硫化前线型（可塑），硫化后适度交联（弹性）——硫化程度决定硬度；
3. **纤维**：合成纤维（涤纶、锦纶、腈纶）多为线型结晶度高——强度大。

**功能高分子**：在主链或侧链接上"功能基团"——高吸水性树脂（尿不湿）、导电高分子（2000 年诺贝尔奖）、高分子膜（海水淡化）。

**降解与治理**：聚乙烯等 C-C 骨架极难降解 → 白色污染；对策：可降解材料（聚乳酸 PLA、淀粉基）、回收再生、减量化。

## 为什么这样

为什么硫化橡胶有弹性而塑料没有？天然橡胶是线型聚异戊二烯，受拉伸分子链"解蜷曲"、放松即回缩——但纯线型会永久变形（冷流）；**硫化**在链间架起少量共价"桥"，让回缩有"锚点"——交联度低=弹性好，交联度高=硬而脆。

为什么热塑性能反复加工而热固性不能？热塑性是线型分子：加热软化（分子间力减弱）可重新塑形；热固性体型结构一旦成型，共价交联网络再加热只会分解不会流动——**"能不能再流动"就是线型与体型的分水岭**。

## 典型例子与方程式

**nCH2=CHCl --催化剂--> [-CH2-CHCl-]n**：聚氯乙烯。它说明加聚引入取代基可调性能（PVC 硬、耐腐蚀、可加增塑剂变软）。

**橡胶硫化**：线型聚异戊二烯 + 少量 S → 交联网络（S 桥）。它说明"交联度"是性能旋钮：轮胎（中度硫化）与硬橡皮（高度硫化）。

**聚乳酸（PLA）**：乳酸缩聚成聚酯——可在堆肥中水解降解为 CO2 与 H2O。它说明"可降解"的化学设计：**在主链里预埋可水解的酯键**。

## 常见易错点

- **"塑料都能加热重塑"**：错。只有热塑性（线型）；热固性（体型）不能。
- **"橡胶的弹性来自共价键被拉伸"**：错。弹性来自分子链的**构象变化**（蜷曲↔伸展），共价键本身不被拉伸。
- **"降解就是烧掉"**：错。降解指在环境中分解为小分子（水解/生物降解）；焚烧是处理方式之一但产生污染。
- **"功能高分子是新材料，与必修高分子无关"**：错。功能高分子 = 普通高分子骨架 + 功能基团，方法学同源。
- **"白色污染只指塑料袋"**：不严谨。泛指难降解塑料废弃物（农膜、包装、一次性制品等）。
