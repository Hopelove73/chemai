# 醇

> 一句话定位：羟基是"多功能接口"——断 O—H 显活泼氢（与钠）、断 C—O 走消去与取代、α-C 的 H 决定能否催化氧化。

## 是什么

**醇**：羟基（—OH）与**饱和碳**相连的化合物（R—OH）。分类：一元/二元/多元醇（乙二醇防冻液、丙三醇甘油）；伯/仲/叔醇（—OH 所在碳连 1/2/3 个碳）。

**羟基的四条性质线**：

1. **与活泼金属**：与钠放氢（比水缓和）——2C2H5OH + 2Na = 2C2H5ONa + H2↑；
2. **催化氧化**：Cu/Ag、加热——2C2H5OH + O2 --Cu、加热--> 2CH3CHO + 2H2O；**伯醇 → 醛，仲醇 → 酮，叔醇不氧化**（α-C 无氢）；
3. **消去**：浓硫酸、**170 ℃** → 烯烃（分子内脱水）；**140 ℃** → 醚（分子间脱水）——温度决定"分子内还是分子间"；
4. **酯化**：与羧酸（M2-T4-KP07）。

**与卤代烃对照**：醇的消去需**浓硫酸**催化脱水，卤代烃用 **NaOH 醇溶液**——官能团不同、条件不同、产物同为烯烃。

## 为什么这样

为什么叔醇不能催化氧化？催化氧化的机制是"α-C 上的 C—H 与 O—H 一起脱氢成 C=O"——叔醇的 α-C 上没有氢（连着三个碳），无氢可脱，反应无法进行。**"有没有 α-H"是氧化路径的开关**。

为什么 170 ℃ 与 140 ℃ 产物不同？低温下分子间碰撞生成醚（两分子脱一水）；高温提供足够能量走分子内消去（单分子脱一水成烯）——**温度改变的是"谁跟谁脱水"**。

## 典型例子与方程式

**C2H5OH --浓硫酸、170℃--> CH2=CH2↑ + H2O**：分子内消去建双键。它说明"醇 → 烯"的合成方向；温度计水银球插入液面下（测液温）。

**2C2H5OH --浓硫酸、140℃--> C2H5OC2H5 + H2O**：分子间脱水成乙醚。它说明同试剂不同温度的分叉；乙醚是麻醉剂与溶剂。

**2CH3CHO + 2H2O ← 2CH3CH2OH + O2 --Cu-->**：伯醇氧化为醛。它说明"伯→醛→酸"的氧化链（醇 → 醛 → 羧酸，M5-T2-KP08）是合成路线的纵向通道。

## 常见易错点

- **"所有醇都能催化氧化成醛"**：错。伯醇→醛、仲醇→酮、**叔醇不被催化氧化**。
- **"醇的消去和卤代烃一样用 NaOH"**：错。醇用**浓硫酸**脱水；条件体系完全不同。
- **"消去温度写 140 ℃"**：错。170 ℃ 成烯、140 ℃ 成醚——温度错产物错。
- **"乙醇与钠反应比水剧烈"**：反了。羟基氢不如水活泼，反应更缓和（M2-T4-KP06）。
- **"多元醇的羟基都能一一与钠反应"**：对——但要注意计量：1 mol 乙二醇与足量钠放 1 mol H2（两个羟基）。
