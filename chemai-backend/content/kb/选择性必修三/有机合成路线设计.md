# 有机合成路线设计

> 一句话定位：合成题就是"官能团走格子"——从原料到目标的每一步都是一个标准转化，路线设计 = 找差值 + 倒推格子。

## 是什么

**核心工具箱**（每格一个标准转化）：

| 目标 | 常用操作 |
|---|---|
| 建 C=C | 醇的消去（浓硫酸 170 ℃）；卤代烃消去（NaOH 醇溶液） |
| 断 C=C / 引入 X | 烯烃加成（X2、HX、H2O） |
| 引入 —OH | 卤代烃水解（NaOH 水溶液）；烯烃加水 |
| —OH → —CHO / —CO— | 催化氧化（Cu、O2）——限伯/仲醇 |
| —CHO → —COOH | O2/催化剂、酸性 KMnO4、银氨/新制氢氧化铜（酸化） |
| —COOH → —COOR | 酯化（醇、浓硫酸） |
| 碳链增长 | 醛/酮 + HCN；酯化引入酯基；取代接碳 |
| 碳链缩短 | 烯烃氧化断裂（KMnO4）；水解脱羧类转化 |

**设计三步**：

1. **对比原料与目标**：数碳链变化、列官能团差异；
2. **倒推**（逆合成分析）：目标 ← 上一步的前体 ← …… 直到原料——每个箭头必须落在工具箱里；
3. **正写路线**：标注每步的试剂与条件（条件错 = 步骤错）。

**注意事项**：官能团的**保护**（不需要被氧化的基团先转化规避）；步骤**经济性**（步骤越少越好）；**绿色化学**（原子经济、避免有毒试剂）。

## 为什么这样

为什么用"倒推"而不是顺着写？正向从原料出发有很多条岔路，倒推从目标出发只有"能生成它的前体"这一个收敛方向——**逆向分析把开放题变成选择题**。每问一次"谁能在一步内变成它"，路线自动长出来。

为什么强调"条件写在箭头上"？有机反应对条件极敏感：NaOH 水溶液 vs 醇溶液、170 ℃ vs 140 ℃——同一个底物条件不同产物不同。**条件是反应的一半**。

## 典型例子与方程式

**乙烯 → 乙酸乙酯**（五步主线）：乙烯 --加 H2O--> 乙醇 --氧化--> 乙醛 --氧化--> 乙酸 --酯化--> 乙酸乙酯。它说明"官能团主链"的完整走法；每步条件见对应篇章。

**2-溴丙烷 → 丙酸**：消去（NaOH 醇）→ 丙烯 --加 H2O--> 2-丙醇 --氧化--> 丙酮——卡住了！丙酮不再氧化 → **换路**：2-溴丙烷 --NaOH 水--> 2-丙醇，2-丙醇氧化仍到丙酮。正确路：1-溴丙烷（消去成丙烯再马氏加水回到 2-丙醇不行）→ 用 1-丙醇氧化得丙醛再氧化得丙酸。它说明"倒推发现死路要换路"——倒推法的价值就在提前发现死胡同。

**苯 → 苯甲酸**：甲苯氧化（KMnO4）——先烷基化（傅-克反应，中学记结论）再氧化侧链。它说明芳香路线的特殊格子；"α-C 有 H 才氧化"（M5-T2-KP03）的判据在此消费。

## 常见易错点

- **"消去条件与水解条件写混"**：高频错误。NaOH **醇**溶液消去、**水**溶液取代——箭头上必须写清溶剂。
- **"叔醇催化氧化成酮"**：错。叔醇 α-C 无氢，不氧化；路线设计要避开。
- **"酯化用稀硫酸"**：错。必须浓硫酸（催化+吸水）。
- **"引入羧基只能氧化"**：不完整。还可酯水解后酸化、腈水解等；工具箱越全路越宽。
- **"路线越长越保险"**：错。每步都有损耗，步骤越多总产率越低；条件允许时选最短合规路线。
