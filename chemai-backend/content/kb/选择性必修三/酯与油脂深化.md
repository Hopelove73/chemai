# 酯与油脂深化

> 一句话定位：把必修二的酯化水解升级为"官能团转化网络"——油脂的氢化与皂化、酯在合成路线里的"枢纽"地位。

## 是什么

**酯的水解两条件**（深化对比）：

- 酸性（稀硫酸）：可逆，生成酸 + 醇；
- 碱性（NaOH）：不可逆（中和掉生成的酸），生成羧酸钠 + 醇——**皂化**的通式版。

**油脂的化学**：

- **氢化（硬化）**：不饱和脂肪酸甘油酯 + H2（Ni 催化）→ 饱和——液态油变固态"人造脂肪"（人造奶油、硬化油）；
- **皂化**：油脂 + NaOH → 高级脂肪酸钠（肥皂）+ 甘油；
- 油脂的**不饱和度**可由"能与多少 Br2 加成"衡量（M5-T2-KP02）。

**官能团转化网络**（合成路线的骨架）：

```
醇 ⇄（消去/加成） 烃（烯） —— 卤代烃 ⇄ 醇
                    ↓
醇 →（氧化）醛 →（氧化）羧酸 ⇄（酯化/水解）酯
```

## 为什么这样

为什么碱性水解不可逆？水解生成的羧酸立即被 NaOH 中和成羧酸钠——产物被"抽走"，平衡只能单向走完（勒夏特列原理 M1-T3-KP08 的应用）。这就是"皂化"用 NaOH 而不用 H2SO4 的原因：要肥皂（钠盐）而不是要酸。

为什么油脂能氢化而酯化产物不能随便加氢？C=C 加氢要 Ni 催化且针对**不饱和碳链**；羧基/酯基的 C=O 在普通条件下不加氢——**加氢的对象是碳碳双键**，这是"硬化油"选择性氢化的原理。

## 典型例子与方程式

**CH3COOC2H5 + H2O ⇌ CH3COOH + C2H5OH（稀硫酸）**：酸性水解（可逆）。它说明"酸来酸往"——生成的乙酸与乙醇在酸催化下又酯化回去；对比下一条碱性水解的不可逆。

**CH3COOC2H5 + NaOH --加热--> CH3COONa + C2H5OH**：碱性水解（皂化通式）。它说明"不可逆"来自中和抽走产物；定量关系 n(酯) = n(NaOH)。

**C17H33COOCH2… + 3H2 --Ni、加热--> C17H35COOCH2…**：油酸甘油酯氢化为硬脂酸甘油酯。它说明 1 mol 双键耗 1 mol H2——氢化耗量计算；液体油变固体脂（人造奶油）。

**官能团网络示例**：乙烯 → 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯，五步全在"烯-醇-醛-酸-酯"主线上。它说明合成路线题（M5-T2-KP10）的套路来自这张网。

## 常见易错点

- **"酯的水解都是可逆的"**：错。酸性可逆、**碱性不可逆**。
- **"皂化产物是高级脂肪酸"**：错。碱性条件下得到的是**高级脂肪酸钠**（肥皂）与甘油。
- **"油脂氢化消耗 NaOH"**：错。氢化消耗的是 H2（Ni 催化）；皂化才消耗 NaOH。
- **"酯化反应用的浓硫酸可以换成稀硫酸"**：错。稀硫酸不带吸水性还引入水，平衡左移、产率骤降。
- **"1 mol 油脂水解消耗 3 mol NaOH，所以油脂分子量一定是 3 的倍数"**：前半对、后半无因果——水解计量看酯基数（3 个），与分子量无关。
