# 蛋白质与氨基酸深化

> 一句话定位：从"两性"深入到"等电点"——氨基酸既是酸又是碱，脱水缩合成肽链，蛋白质的一切行为（变性、酶催化）都写在这条链上。

## 是什么

**氨基酸的结构通式**：H2N—CH(R)—COOH（α-碳连氨基、羧基、H、侧链 R）。R 不同 → 20 种常见氨基酸；**必需氨基酸**人体不能合成、必须摄入（8 种）。

**两性电离**：

- 与酸：H2NCH2COOH + HCl = ClH3NCH2COOH（氨基成盐）；
- 与碱：H2NCH2COOH + NaOH = H2NCH2COONa + H2O（羧基成盐）；
- **内盐与等电点**：分子内氨基质子化、羧基电离，形成两性离子；等电点处溶解度最小——电泳分离蛋白质的原理。

**肽键**：—CO—NH—，脱水缩合形成；水解断键回氨基酸。二肽、多肽、蛋白质是同一条链的长短。

**酶**：蛋白质类的生物催化剂——**专一性、高效性、条件温和性**（温度 pH 敏感，过热即变性失活）。

## 为什么这样

为什么氨基酸有两性？氨基（碱性，接受 H+）与羧基（酸性，给出 H+）并存——一个分子里"自带酸碱"。调节 pH，分子所带净电荷变化：pH 低带正电、pH 高带负电、等电点净电荷为零——**蛋白质的电泳、结晶都在等电点附近操作**。

为什么酶失活与变性同源？变性（M2-T4-KP10：热、重金属、强酸碱）破坏的是空间结构（氢键、疏水作用等次级键），肽键未断——酶的活性位点正是靠特定空间构型工作的，构型一散，催化即停。**"肽键在、功能亡"**。

## 典型例子与方程式

**H2NCH2COOH + HCl = ClH3NCH2COOH**：氨基的碱性。它说明与酸成盐；对照与碱成盐——两性的两份证据。

**二肽缩合**：H2NCH2COOH + H2NCH2COOH → H2NCH2CONHCH2COOH + H2O（脱水缩合）。它说明肽键的形成与"n 个氨基酸失 (n-1) 个水"的计量。

**酶催化示例**：唾液淀粉酶把淀粉水解为麦芽糖——口腔里的温和水解（M5-T3-KP01 的水解在体内的版本）。它说明酶的温和高效；高温（如发烧40℃以上）酶活性下降。

## 常见易错点

- **"蛋白质变性后还能水解回氨基酸"**：对。变性破坏空间结构，**肽键未断**——水解照常（这也是"变性食物更易消化"的部分原因）。
- **"氨基酸的氨基显酸性"**：反了。氨基显**碱性**（接受质子），羧基显酸性。
- **"n 个氨基酸缩合失去 n 个水"**：错。链状失 (n−1)；环状才失 n。
- **"酶是万能催化剂，任何反应都能催化"**：错。专一性——一把钥匙一把锁。
- **"重金属盐使蛋白质凝结是盐析"**：错。重金属导致**变性**（不可逆）；盐析（浓轻金属盐）可逆——救命常识：重金属中毒喝牛奶是利用变性"牺牲"食物蛋白。

## 与其他知识的联系

先修：蛋白质与氨基酸（M2-T4-KP10）的盐析变性初步；羧酸（M5-T2-KP08）提供羧基酸性与酯化（氨基酸也能成肽/酰胺键）。

后继：核酸（M5-T3-KP03）的碱基与氢键；合成高分子的基本方法（M5-T3-KP04）的缩聚以肽键/酯键为模板。
