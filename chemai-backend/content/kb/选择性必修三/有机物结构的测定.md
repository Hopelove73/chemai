# 有机物结构的测定

> 一句话定位：纯品之后"验明正身"——元素分析定组成、质谱定分子量、红外认键、核磁数氢，四步合围出结构。

## 是什么

**测定流程**：

1. **元素分析**：燃烧法测 C、H（O）含量 → **实验式**（最简式）；
2. **质谱（MS）**：分子失电子成离子，按质荷比分离——**最大质荷比（分子离子峰）≈ 相对分子质量**；由实验式 + 分子量 → **分子式**；
3. **红外光谱（IR）**：不同化学键/官能团吸收特定频率红外光——**识别有哪些化学键与官能团**（如 C=O、O—H 的特征峰）；
4. **核磁共振氢谱（¹H-NMR）**：不同化学环境的 H 吸收频率不同——**峰的组数 = 氢的环境种数；峰面积比 = 各环境氢原子数之比**。

四步合围：实验式 → 分子式 → 官能团清单 → 氢环境分布 → **唯一（或少数候选）结构**。

## 为什么这样

为什么核磁能"数氢"？同一种化学环境里的 H（如 CH4 的 4 个 H）在磁场中共振吸收位置相同，算一组峰；不同环境（乙醇的 CH3、CH2、OH）共振位置不同，分成三组。**环境由"隔壁邻居"决定**——这就是结构信息的来源。

为什么质谱峰最大值是分子量？分子被打掉一个电子形成的分子离子质量最大（碎片的质荷比都更小）；所以谱图**最右侧**的主峰对应相对分子质量。

## 典型例子与方程式

**乙醇的氢谱**：三组峰，面积比 3∶2∶1——对应 CH3（3H）、CH2（2H）、OH（1H）。它说明"峰组数+面积比"的读法；二甲醚（CH3OCH3）则只有一组峰（8H 等效）——**氢谱能区分乙醇与二甲醚**。

**由数据定分子式**：实验式 CH2O（元素分析）、质谱分子量 60 → (CH2O)₂ = C2H4O2。它说明"实验式 × n"的推理；结合 IR 有 C=O 与 O—H → 乙酸而非甲酸甲酯（还需氢谱验证）。

**红外识别官能团**：谱图出现 O—H 宽峰与 C=O 峰 → 含羧基/羟基组合。它说明 IR 是"官能团清单"的直接来源。

## 常见易错点

- **"质谱峰的个数等于氢的环境数"**：错。那是核磁；质谱峰对应**碎片与分子离子**。
- **"实验式就是分子式"**：错。实验式是最简比；分子式 = 实验式 × n，n 由分子量定。
- **"红外光谱能给出分子量"**：错。IR 只认键与官能团；分子量看质谱。
- **"氢谱峰面积比就是各基团个数"**：对，但**换算**时要考虑等效氢——先数环境、再按面积比配平总氢数。
- **"测结构不需要分离提纯"**：错。样品不纯，谱图混杂；提纯（M5-T1-KP02）是测定的前提。
