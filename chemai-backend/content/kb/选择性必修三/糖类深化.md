# 糖类深化

> 一句话定位：从"分类表"深入到"结构决定性质"——葡萄糖是多羟基醛（有还原性的原因），二糖多糖的水解与鉴别由此展开。

## 是什么

**葡萄糖**：多羟基醛——五个羟基 + 一个醛基。**还原性**来自醛基：银镜反应、与新制 Cu(OH)2 共热生成砖红色 Cu2O（检测尿糖的化学基础）。环状结构：C5 上的羟基与醛基加成成环（半缩醛），水溶液中链状与环状共存。

**二糖**：

- **蔗糖**（非还原性糖，无醛基）：水解 → 葡萄糖 + 果糖（一分子葡萄糖一分子果糖）；
- **麦芽糖**（还原性糖）：水解 → 2 分子葡萄糖。

**多糖**：

- **淀粉**：(C6H10O5)n，遇碘变蓝；水解逐步：淀粉 → 糊精 → 麦芽糖 → 葡萄糖；
- **纤维素**：同为 (C6H10O5)n 但 n 与结构不同；人体不能水解（无纤维素酶），反刍动物可以。

**在生命中的作用**：葡萄糖是直接能源；糖原储能；核糖/脱氧核糖构成核酸骨架（M5-T3-KP03）。

## 为什么这样

为什么葡萄糖有还原性而蔗糖没有？还原性来自**游离醛基**——葡萄糖是醛糖；蔗糖的两个羰基都参与了苷键（缩合后无游离醛/酮），水解后单糖才"长出"还原性——**"水解前后还原性变化"是鉴别二糖类型的钥匙**。

为什么淀粉与纤维素的 n 不同就不是同分异构体？两者都是混合物（n 是统计分布值），没有确定的分子式——"同分异构"只对**确定的分子**有意义（M2-T4-KP02 的边界条件）。

## 典型例子与方程式

**CH2OH(CHOH)4CHO + 2Cu(OH)2 --加热--> CH2OH(CHOH)4COOH + Cu2O↓ + 2H2O**：葡萄糖氧化为葡萄糖酸。它说明 1 mol 醛基耗 2 mol Cu(OH)2、出 1 mol Cu2O；与醛与酮（M5-T2-KP07）同款反应。

**C12H22O11 + H2O --稀硫酸、加热--> 2C6H12O6**：麦芽糖水解。它说明"水解产物都是葡萄糖"与蔗糖（葡萄糖+果糖）的对照；水解后才能发生银镜（验证"非还原性糖"）。

**(C6H10O5)n + nH2O --催化剂--> nC6H12O6**：淀粉/纤维素水解终点都是葡萄糖。它说明"糖类水解的判定"：加碘不变蓝 + 银镜出现 = 水解完全。

## 常见易错点

- **"蔗糖是还原性糖，能发生银镜反应"**：错。蔗糖无游离羰基；水解后才银镜——"先水解后检验"是标准流程。
- **"淀粉与纤维素互为同分异构体"**：错。都是混合物（n 不定），分子式不确——只能说是"同类型的聚合糖"。
- **"葡萄糖的环状结构破坏了醛基"**：不严谨。开链与环状互变平衡中总有一部分游离醛基，还原性依然可测。
- **"检验葡萄糖可以用溴水"**：不严谨。醛基可使溴水褪色，但果糖（酮糖）在碱性条件下也能还原溴水/银氨——严格区分需谨慎；中学范围用银镜/新制氢氧化铜。
- **"无糖食品不含糖类"**：错。商家的"糖"指蔗糖；淀粉、糊精仍是糖类。
