# 卤代烃

> 一句话定位：官能团是卤素原子，两条"分叉路"——NaOH 水溶液走取代生成醇，NaOH 醇溶液加热走消去生成烯烃；条件一字之差，产物天壤之别。

## 是什么

**卤代烃**：烃分子中的氢被卤素原子取代的产物（官能团：—X）。溴乙烷 C2H5Br：无色液体、不溶于水、密度比水大。

**两条反应路径**（都以 NaOH 为试剂）：

1. **取代（水解）**：**NaOH 水溶液**、加热 → 生成**醇**：C2H5Br + NaOH --水--> C2H5OH + NaBr；
2. **消去**：**NaOH 乙醇溶液**、加热 → 生成**烯烃**：断 C—X 与相邻碳（β-C）上的 C—H，脱下 HX。

**消去的结构条件**：与 C—X 相连的**相邻碳（β-C）上必须有氢**——CH3Br、(CH3)3CCH2Br 这类"邻碳无氢"的卤代烃不能消去。

**卤素检验**：取样 → 加 NaOH 水溶液加热水解 → **加稀硝酸酸化**（中和过量 NaOH）→ 加 AgNO3 → 白/淡黄/黄色沉淀判 Cl/Br/I。**不酸化直接加 AgNO3 会得到黑色 Ag2O 干扰**。

## 为什么这样

为什么条件决定"取代还是消去"？水是高极性溶剂，OH⁻ 浓度相对低且被水化，进攻 α-C 发生取代；乙醇溶剂中 OH⁻"裸露"更碱性，且加热利于脱去 β-H——**溶剂与温度改变的是 OH⁻ 的"角色"**（亲核试剂 vs 强碱）。同一试剂在不同介质里做不同的事，这是有机反应条件的核心逻辑。

为什么消去要"邻碳有氢"？消去是"C—X 断 + β C—H 断 + 成 C=C"的协同过程——没有 β-H 就无氢可脱、无法成双键。

## 典型例子与方程式

**C2H5Br + NaOH --水--> C2H5OH + NaBr（取代/水解）**：官能团转换 X → OH 的第一步。它说明"卤代烃是连接烃与醇的桥梁"——合成路线的中转站。

**C2H5Br + NaOH --乙醇、加热--> CH2=CH2↑ + NaBr + H2O（消去）**：建双键的标准操作。它说明"消去建烯、加成断烯"的往返设计（M5-T2-KP10 合成路线的骨架）。

**卤素检验流程**：水解 → 硝酸酸化 → AgNO3 → 沉淀颜色定卤素。它说明"先转化（把 C—X 变成 X⁻）再检验"的两步法——卤素在烃里不能直接与 Ag⁺ 沉淀。

## 常见易错点

- **"NaOH 水溶液加热就是消去"**：错。介质是**水**走取代；**乙醇**溶液才消去——一字之差全错。
- **"所有卤代烃都能发生消去"**：错。β-C 无氢（CH3Br、邻碳全被占）不能消去。
- **"检验卤素直接加 AgNO3"**：错。卤素原子在分子内不电离，必须先水解转化成 X⁻，且要酸化排除 OH⁻ 干扰。
- **"消去产物只有一种烯烃"**：错。不对称卤代烃消去可向两个方向（如 2-溴丁烷 → 1-丁烯 + 2-丁烯），主产物是更稳定的烯（氢少的一侧）。
- **"氯乙烯也是这样消去"**：错。CH2=CHCl 的 Cl 直接连在双键碳上（乙烯基卤），既难取代也难消去——性质要具体分析。

## 与其他知识的联系

先修：烯烃与炔烃（M5-T2-KP02）的加成是卤代烃的"上游"（烯 + HX → 卤代烃）；乙醇（M2-T4-KP06）是取代产物。

后继：醇（M5-T2-KP05）的消去成烯与本篇对偶；有机合成路线设计（M5-T2-KP10）把卤代烃当"官能团转换器"使用。
