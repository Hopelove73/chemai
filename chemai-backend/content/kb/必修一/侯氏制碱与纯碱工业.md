# 侯氏制碱与纯碱工业

> 一句话定位：本篇是 STSE 的中国样本——侯德榜联合制碱法如何用"溶解度差异+循环利用"同时产出纯碱与氮肥，既考化学也讲家国。

## 是什么

**纯碱（Na₂CO₃）**是玻璃、造纸、洗涤剂工业的基础原料。**侯氏制碱法（联合制碱法）**由侯德榜 1943 年创立，核心两步：

1. **析晶**：向饱和食盐水中先通 NH₃ 再通 CO₂，生成 NaHCO₃——因 NaHCO₃ 溶解度**较小**而结晶析出（NaCl + NH₃ + CO₂ + H₂O = NaHCO₃↓ + NH₄Cl）；
2. **煅烧**：加热 NaHCO₃ 分解得**纯碱 Na₂CO₃**，放出的 CO₂**回收循环**使用（2NaHCO₃ --Δ--> Na₂CO₃ + H₂O + CO₂↑）。

**"联合"的含义**：与合成氨厂联合——CO₂ 来自合成氨的原料气，副产物 **NH₄Cl 是氮肥**直接出售。两种产品、一份原料、母液循环。

**与索尔维法（氨碱法）的区别**：索尔维法副产物 CaCl₂ 用途有限、食盐利用率仅约 70%；侯氏法食盐利用率提高到 **96% 以上**，且副产物是氮肥——**绿色化学与经济效益双赢**（M1-T5-KP01 的循环利用思想）。

## 为什么这样

为什么先通 NH₃ 再通 CO₂（顺序不能反）？NH₃ 极易溶于水使溶液**显碱性**，大量吸收 CO₂ 后生成高浓度 HCO₃⁻——碱性的"接力"让 CO₂ 的吸收量成倍增加。若先通 CO₂（溶解度小），吸收量少，产率大减。**通气顺序是流程的第一个考点**。

为什么析出的是 NaHCO₃ 而不是 NaCl 或 NH₄Cl？**四种盐同时存在于溶液中，析出谁取决于溶解度**：该温度下 NaHCO₃ 的溶解度**最小**，离子组合时它先达到饱和析出——"溶解度差异"是结晶分离的全部依据（M1-T2-KP11 的溶解度对比在这里工业化）。

为什么食盐利用率能到 96%？索尔维法的 NaCl 母液含大量未反应的 NaCl 只能废弃；侯氏法在母液中**加入细盐并冷却**，让 NH₄Cl 单独结晶（同温下 NH₄Cl 溶解度随温度变化大、NaCl 变化小——冷却结晶分离），母液回到第一步循环——每一点 NaCl 都被"榨干"。

## 典型例子与方程式

**NaCl + NH₃ + CO₂ + H₂O = NaHCO₃↓ + NH₄Cl**：总反应。三个关键词：饱和食盐水、先氨后碳、NaHCO₃ 析晶。它说明流程设计的前提是**溶解度的数据**——化学工艺是"把性质差异变成分离手段"。

**2NaHCO₃ --Δ--> Na₂CO₃ + H₂O + CO₂↑**：煅烧得纯碱 + CO₂ 循环回第一步。它说明"分解产物不是废弃物而是原料"——循环的化学本质。

## 常见易错点

- **"先通 CO₂ 再通 NH₃ 效果一样，只是顺序不同"**：错。NH₃ 先行让溶液显碱性才能大量吸收 CO₂；顺序颠倒产率大减。错因是没把"碱性吸酸气"的原理落到顺序上。
- **"析出 NaHCO₃ 是因为它难溶"**：不准确。NaHCO₃ **能溶**（可配溶液），只是**在该体系四种盐中溶解度最小**、先达饱和析出。错因是"溶/不溶"二元化。
- **"侯氏制碱的'碱'指烧碱 NaOH"**：错。指**纯碱 Na₂CO₃**（碳酸钠俗名纯碱）。错因是俗称与化学名错位。
- **"NH₄Cl 副产物是废弃物"**：反了。NH₄Cl 是**氮肥**产品——这正是侯氏法优于索尔维法（副产 CaCl₂ 废渣）的关键。错因是没理解"联合"二字的商业与环保含义。
