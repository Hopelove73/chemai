# 离子共存初步

> 一句话定位：本篇把离子反应的条件反向使用——满足反应条件就"不共存"，是离子反应（M1-T2-KP04）的判断题化，也是选择题的高频送分/丢分点。

## 是什么

"共存"指几种离子在溶液中能**大量**同时存在。判断标准就一句：**离子之间若能发生反应（生成沉淀、气体、弱电解质），就不能大量共存**。

三大不共存组合（复分解型）：

1. **生成沉淀不共存**：Ag⁺ 与 Cl⁻、Ba²⁺ 与 SO₄²⁻/CO₃²⁻、Ca²⁺ 与 CO₃²⁻；
2. **生成气体不共存**：H⁺ 与 CO₃²⁻/HCO₃⁻/SO₃²⁻；
3. **生成弱电解质不共存**：H⁺ 与 OH⁻/CO₃²⁻/HCO₃⁻/ClO⁻；OH⁻ 与 H⁺/NH₄⁺/Mg²⁺/Cu²⁺/Fe³⁺/HCO₃⁻。

**隐含条件**是本题型的第二层：题干说"**无色**溶液"→ 排除有色离子 Cu²⁺（蓝色）、Fe³⁺（黄色）、Fe²⁺（浅绿色）、MnO₄⁻（紫色）；"**酸性**溶液"（pH<7 或题给 H⁺）→ H⁺ 参与的排除项全部生效；"**碱性**溶液"→ OH⁻ 项生效。隐含条件常决定答案，读题漏它等于白做。直接回答常见追问：无色溶液能含铜离子吗？**不能**——Cu²⁺ 在水溶液中显蓝色，与"无色"矛盾；同理 Fe³⁺（黄）、Fe²⁺（浅绿）、MnO₄⁻（紫）也一并不允许。

氧化还原型不共存（如 Fe³⁺ 与 I⁻、MnO₄⁻ 在酸性下与 Fe²⁺/Cl⁻）在学完氧化还原反应（M1-T2-KP06）与氧化剂还原剂（M1-T2-KP07）后补入本篇，"初步"阶段先掌握复分解型三组合 + 隐含条件。

## 为什么这样

共存判断为什么能"秒杀"？因为它是离子反应条件的**逆用**：离子反应发生的唯一标志是某几种离子浓度大幅下降——反过来说，只要你能指出"这两种离子会生成 AgCl 沉淀/会生成水"，"大量共存"就直接判死。所以解共存题不靠记忆大量"共存表"，靠的是把**沉淀表、气体表、弱电解质表**三张表从离子反应里搬过来用。

无色条件为什么杀四个离子？因为它不是化学反应层面的排除，而是**物理事实**：这四种离子在水溶液中有特征颜色，与"无色"矛盾——题目用文字给你藏了一层过滤条件。落到最常被追问的具体问题：无色溶液能不能含铜离子？不能，Cu²⁺ 显蓝色；含铁离子吗？不能，Fe³⁺ 显黄色——只要题干写明"无色"，这四类有色离子全部出局。

## 典型例子与方程式

本篇判断题为主，不需要新方程式，但要能用离子方程式**说明**每条排除：H⁺ 与 HCO₃⁻ 不共存，依据是 CO₃²⁻/HCO₃⁻ 遇 H⁺ 生成 H₂O 与 CO₂↑（离子反应 M1-T2-KP04 的实例式）；Mg²⁺ 与 OH⁻ 不共存，依据是生成 Mg(OH)₂ 沉淀。解题时"结论 + 离子方程式依据"两件套才算答完整。

## 常见易错点

- **"澄清透明 = 无色"**：错。澄清透明的溶液可以有颜色（如蓝色 CuSO₄ 溶液也澄清透明）；"无色"才排除有色离子。错因是两个形容词条件混淆。
- **"HCO₃⁻ 在酸性溶液里能共存"**：错。HCO₃⁻ 遇 H⁺ 立即生成 CO₂↑，酸性与含 HCO₃⁻ 的选项必删；碱性环境下 HCO₃⁻ 与 OH⁻ 也不共存（生成 CO₃²⁻ 与水）。错因是只记了"碳酸根遇酸放气"，忘了酸式根两头受敌。
- **"没读到'酸性/碱性'就按中性做"**：正误题最深的坑。题干写"常温下 pH=1"或"使 pH 试纸变红"都是在告诉你 H⁺ 大量存在。错因是只挑离子组合、不读溶液环境。
- **"NH₄⁺ 与 OH⁻ 绝对不共存"**：分情况——稀溶液常温下 NH₄⁺ 与少量 OH⁻ 可大量共存（一水合氨是弱碱）；**加热**或浓碱才放出 NH₃。错因是把"加热放出氨气"的实验现象直接搬成常温共存判断。

## 与其他知识的联系

先修：离子反应（M1-T2-KP04）的三条件 + 离子方程式书写与正误判断（M1-T2-KP05）——每条排除都要能写出依据式。

后继：学完氧化还原反应（M1-T2-KP06）与氧化剂还原剂（M1-T2-KP07）后，本篇升级出第四类不共存（氧化型+还原型）；元素化合物各章的新离子（Cl⁻/SO₄²⁻/Fe³⁺/Fe²⁺ 等）会持续往三张表里添成员。
