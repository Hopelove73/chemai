# 离子方程式书写与正误判断

> 一句话定位：本篇把离子反应（M1-T2-KP04）落成可写的式子、可判的题——拆写规则 + 两守恒是必修正误题的全部技术底座。

## 是什么

**写离子方程式的四步法**：

1. **写**：写出配平的化学方程式；
2. **拆**：把易溶且易电离的强电解质（强酸、强碱、可溶盐）拆成离子形式；沉淀、气体、弱电解质（水、弱酸、弱碱）、非电解质、单质**保留化学式**；
3. **删**：删去两边不参加反应的旁观离子；
4. **查**：原子守恒 + **电荷守恒**两边都查。

拆的口诀是"**强酸、强碱、可溶盐拆**"：HCl、H₂SO₄、HNO₃ 拆；NaOH、KOH、Ba(OH)₂ 拆；NaCl、CuSO₄ 等可溶盐拆。保留化学式的六类要背牢：**难溶物、气体、水（弱电解质）、弱酸（H₂CO₃、HClO）、弱碱（NH₃·H₂O）、非电解质与单质**。

微溶物（如 Ca(OH)₂、CaSO₄）看场合：澄清稀溶液作反应物拆（澄清石灰水拆成 Ca²⁺+OH⁻），石灰乳或生成物写化学式。

## 为什么这样

为什么有的拆有的不拆？拆写的对象必须是**以自由离子形式真实存在**的物种。可溶性强电解质在溶液里根本没有"分子"，只有水合离子——化学方程式里的 NaOH 只是统计记法，写成 Na⁺ + OH⁻ 才是溶液的真相。而沉淀（离子束缚在晶格）、气体（已经跑掉）、弱电解质（大部分以分子存在）在溶液里不以离子为主，写成离子形式就是失真。

为什么必须查电荷守恒？溶液整体是电中性的，任何时刻都不能凭空出现净电荷。原子守恒化学方程式也要查，**电荷守恒是离子方程式的专属检查项**——正误判断题一半的陷阱在这里。

## 典型例子与方程式

**Cu + 2Ag⁺ = Cu²⁺ + 2Ag**：金属与盐溶液的置换。它说明单质永远写化学式（不拆），且这是氧化还原型离子反应——电荷守恒（左 +2，右 +2）与电子守恒同时对上。

**CO₃²⁻ + 2H⁺ = H₂O + CO₂↑**：可溶性碳酸盐与强酸。它说明化学计量数要跟着删完旁观离子后的实际情况走（H⁺ 前配 2），不是照抄化学方程式的系数。

**2Na + 2H₂O = 2Na⁺ + 2OH⁻ + H₂↑**：钠与水。生成物 NaOH 是强碱、可溶——**生成物侧也要拆**；H₂O 是弱电解质保留化学式。它说明"拆"对生成物同样适用，初学者常只在反应物侧拆。

## 常见易错点

- **"浓硫酸、HCl 全拆"**：HCl 拆（强酸），**浓硫酸不拆**——浓硫酸中水极少，主要以分子存在且表现强氧化性；浓盐酸、稀硫酸拆。错因是把"强酸拆"背成了万金油，忘了"在溶液中以离子为主"这个拆的前提。
- **"Ca(OH)₂ 一律拆 / 一律不拆"**：看状态——**澄清**石灰水拆成 Ca²⁺ + 2OH⁻；**石灰乳**或作为生成物的 Ca(OH)₂ 写化学式。微溶物的口诀"稀拆浓不拆、拆反应物不拆生成物"。错因是想用一条规则打天下。
- **"弱酸酸式盐（如 NaHCO₃）把 HCO₃⁻ 拆成 H⁺ + CO₃²⁻"**：错。HCO₃⁻ 是弱酸酸根，**保留整体**；NaHCO₃ 拆成 Na⁺ + HCO₃⁻ 为止。错因是分不清"盐电离到离子"与"弱酸根继续电离"两步——第二步极难进行。
- **"√ 的式子只查了原子守恒就放行"**：正误题的经典陷阱是**电荷不守恒**的式子（如 MnO₂ + 4H⁺ + 2Cl⁻ 的变形把电荷写丢），原子守恒但电荷不守恒照样错。错因是检查清单少了专属项。
- **"量不同写法相同"**：过量问题里，谁的量少谁决定产物形态（如 NaHCO₃ 与 Ca(OH)₂ 反应，Ca(OH)₂ 过量与不足的离子方程式不同）。错因是以为离子方程式与用量无关。

## 与其他知识的联系

先修：离子反应（M1-T2-KP04）——本篇写的就是它的"实质式"；电解质与非电解质（M1-T2-KP03）的强弱之分决定拆与不拆。

后继：**离子共存初步**（M1-T2-KP23）用本篇的拆写规则表达共存判断；第二章起所有溶液中的元素化合物反应都要求写离子方程式；**常见离子的检验**（M1-T1-KP03）的每个"特征反应"都以离子方程式作答。
