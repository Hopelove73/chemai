# 镁及其化合物

> 一句话定位：本篇是活泼金属家族的最后一块拼图——镁能在氮气、二氧化碳这些"支持燃烧的气体"里燃烧，推断题的金属气体反应它占一半。

## 是什么

**镁的燃烧三连**（都是点燃条件，产物都是碱性形式的镁化合物加一种单质）：
- 在氧气中剧烈燃烧，发出**耀眼白光**（镁光灯原理）：$2Mg + O_2 \xrightarrow{\text{点燃}} 2MgO$；
- 在氮气中燃烧生成氮化镁：$3Mg + N_2 \xrightarrow{\text{点燃}} Mg_3N_2$——**认为镁与氮气不反应是经典错误**；
- 在二氧化碳中燃烧：$2Mg + CO_2 \xrightarrow{\text{点燃}} 2MgO + C$——**镁燃烧引起的火灾不能用二氧化碳灭火器**（剧烈燃烧、生成白色粉末和黑色固体，推断题"一金属一气体生成一黑一白"的题眼）；
- 同理在二氧化硫中燃烧：$2Mg + SO_2 \xrightarrow{\text{点燃}} 2MgO + S$，生成的硫还能继续与镁反应生成硫化镁（Mg+S=MgS）。

**锂与钠的对照**（族内反常是考点）：锂燃烧只生成普通氧化物 Li₂O 无过氧化物；钠常温生成 Na₂O、燃烧生成 Na₂O₂。镁与热水缓慢反应生成 Mg(OH)₂ 与 H₂（冷水几乎不反应——比钠温和得多）。

**重要化合物**：氧化镁 MgO（碱性氧化物、高熔点耐火材料）；氯化镁 MgCl₂（易溶、易潮解，海水/光卤石是镁的资源）；氮化镁 Mg₃N₂（与水彻底水解：Mg₃N₂+6H₂O=3Mg(OH)₂↓+2NH₃↑）。

## 为什么这样

镁为什么能在 N₂、CO₂ 里烧？**镁的还原性极强**——夺取氧的能力足以把二氧化碳、二氧化硫中的氧抢出来，甚至能夺取氮气中十分稳定的 N≡N 三键。这也解释了灭火逻辑：灭火器的原理是"隔绝氧气、用不支持燃烧的气体覆盖"，而镁自己能在这些气体里烧，这条路对镁失效，只能用沙土覆盖。

镁与氮气反应生成 Mg₃N₂ 的本质是"活泼金属氮化物"：金属太活泼，连最稳定的氮气都能反应——同期铁与氯气生成高价（FeCl₃）、与硫只能生成低价（FeS）的规律也一致：**越活泼的金属，越能把对手打到高价或拿下更强的键**。

## 典型例子与方程式

**例 1（推断题眼）**：某金属在气体 A 中剧烈燃烧，生成白色粉末和黑色固体。答案：金属为 Mg、气体为 CO₂（白色 MgO + 黑色 C）。同型题眼还有"淡黄色固体"（Na₂O₂）、"在氮气中燃烧"（Mg 或 Li 之外皆不反应）。

**例 2（计算链）**：Mg₃N₂ 与水反应：$Mg_3N_2 + 6H_2O = 3Mg(OH)_2\downarrow + 2NH_3\uparrow$。由 NH₃ 的量反推 Mg₃N₂，是"镁在氮气中燃烧产物"定量分析的标准链条——用电子守恒：每 mol Mg₃N₂ 生成 2 mol NH₃。

**例 3（合金）**：镁铝合金（见 M6 化学计算方法例题）密度小、硬度大，用于飞机与汽车部件——合金硬度比各组分大、熔点比各组分低的通则在这类题里反复出现。

## 常见易错点

- **"镁与氮气不反应"**：错。3Mg+N₂=Mg₃N₂（点燃），这是镁的特征反应之一。错因是把氮气"稳定"误当成"不与任何金属反应"。
- **"镁着火用二氧化碳灭火器"**：错。镁能在 CO₂ 中燃烧（2Mg+CO₂=2MgO+C），灭火要用干燥沙土。错因是背了"CO₂ 灭火"忘了它是活泼金属的助燃气。
- **"Mg₃N₂ 溶于水生成 Mg(OH)₂ 和 N₂"**：错。水解产物是 NH₃（-3 价 N 不变价），Mg₃N₂+6H₂O=3Mg(OH)₂↓+2NH₃↑，不是氧化还原。错因是把水解当置换。
- **"锂燃烧也生成过氧化钠那样的过氧化物"**：错。锂燃烧只生成 Li₂O（锂离子半径小、极化能力弱，过氧化物不稳定）。错因是族内规律套用不看反常。
- **"镁与冷水剧烈反应"**：错。镁与冷水几乎不反应（表面生成 Mg(OH)₂ 覆盖），与沸水才缓慢反应放出氢气——活泼性排序里它排在钠之后有依据。错因是拿钠的行为平移到镁。
