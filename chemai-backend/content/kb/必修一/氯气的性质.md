# 氯气的性质

> 一句话定位：本篇是元素化合物第一个非金属样本——氯气的强氧化性贯穿与金属、氢气、水、碱四类反应，"燃烧不一定需要氧气"在这里诞生。

## 是什么

**物理性质**：黄绿色、有**刺激性气味**的有毒气体，密度比空气大，能溶于水（1 体积水溶约 2 体积 Cl₂）。闻有毒气体的规范：**扇闻**（M1-T1-KP02）。

**化学性质一条主线：Cl₂ 是强氧化剂**（Cl 0 → −1，得电子），四类反应全是它"抢电子"：

1. **与金属**（点燃）：与 Na（白焰）、Cu（棕黄色烟 CuCl₂）、Fe（棕褐色烟 FeCl₃）——**变价金属被氧化到高价**（FeCl₃ 不是 FeCl₂）；
2. **与氢气**：点燃或光照都爆炸式化合，苍白色火焰，产物 HCl 溶于水即盐酸；
3. **与水**：部分 Cl₂ 与水反应生成盐酸和次氯酸（可逆，⇌）；
4. **与碱**：与 NaOH 生成 84 消毒液（NaCl + NaClO），与石灰乳生成漂白粉——**工业上用碱液吸收氯尾气**。

**燃烧的重新定义**：Cu 在 Cl₂ 中剧烈燃烧（棕色烟）——**燃烧不一定有氧气参加**，发光发热的剧烈氧化还原反应都叫燃烧。

**氯水**的成分与性质：Cl₂ 溶于水后得到含 **Cl₂、HClO、H₂O（分子）与 H⁺、Cl⁻、ClO⁻、OH⁻（离子）** 的混合体系——七种微粒（还有少量水合氢离子细节归后续）。氯水漂白性来自 **HClO**（不是 Cl₂）；酸性与 Cl⁻ 的检验性质来自 HCl。

## 为什么这样

Cl₂ 为什么是强氧化剂？氯原子最外层 **7 个电子，只差 1 个就饱和**——夺得电子的欲望极强（0 → −1 放能明显）。这与钠（1 个电子易失）正好是镜像：**最外层电子数决定金属性/非金属性**，第四章（M1-T3-KP02 起）将从结构上统一解释，这里先积累事实。

HClO 为什么能漂白而干燥的 Cl₂ 不能？漂白的实质是 HClO 的**强氧化性破坏色素分子**。干燥 Cl₂ 没有水就生成不了 HClO——所以**干燥的氯气不漂白**，湿润的才漂白。这个对比是"氯水成分分析"题的钥匙。

与碱反应为什么重要？Cl₂ + H₂O 的可逆反应生成的 HClO/HCl 被 NaOH 中和，**拉动平衡右移**——碱吸收氯气既是尾气处理原理（M1-T1-KP04），也是漂白粉/84 消毒液的制备原理。

## 典型例子与方程式

**Cl₂ + H₂O ⇌ HCl + HClO**：氯水成分的总开关。可逆号必须写——反应进行得不彻底，这正是氯水"七种微粒"并存的原因；HClO 见光分解（2HClO --光照--> 2HCl + O₂↑）会不断拉动平衡右移，所以**氯水久置变成稀盐酸**。

**Cl₂ + 2NaOH = NaCl + NaClO + H₂O**：与碱反应的母版（歧化：Cl 0 → −1 与 +1，M1-T2-KP08 规律）。把 NaOH 换成石灰乳就是漂白粉制备（Cl₂ + 2Ca(OH)₂ 换成 Ca(ClO)₂ 与 CaCl₂ 的混合物，有效成分 Ca(ClO)₂）。它说明"氯气+碱"是一族反应，背一条会一族。

**Cl₂ + H₂ --光照--> 2HCl**：光照混合会**爆炸**——工业上用点燃（合成盐酸）。它说明同一反应的条件控制决定安全形态。

## 常见易错点

- **"氯水就是液态氯"**：错。液氯是**纯净物**（液化的 Cl₂ 分子）；氯水是**混合物**（七种微粒并存）。错因是名字像就当一样。
- **"干燥的 Cl₂ 有漂白性"**：错。漂白的是它与水反应生成的 HClO；无水则无 HClO。红布条在干燥氯气中不褪色、在氯水中褪色，正是教材对比实验。错因是把"氯能漂白"当成了氯气单质的属性。
- **"Fe 与 Cl₂ 反应生成 FeCl₂"**：错。强氧化剂把变价金属**氧化到最高价**——产物 FeCl₃。错因是套用 Fe 与盐酸生成 FeCl₂ 的经验（盐酸中 H⁺ 是弱氧化剂，只能到 +2）。"强弱氧化剂决定产物价态"在这里立规矩。
- **"氯气尾气用水吸收"**：低效。Cl₂ 在水中溶解度有限且反应可逆——**用 NaOH 溶液吸收**才能拉平衡、除干净。错因是看到"能溶于水"就当能除尽。
- **"HClO 是强酸"**：错。HClO 是**弱酸**（酸性比碳酸还弱），但强氧化性。酸性与氧化性是两回事。错因是"能漂白=强"的直觉迁移。
