# 碳酸钠与碳酸氢钠

> 一句话定位：本篇是"钠盐两兄弟"的对比篇——Na₂CO₃（纯碱/苏打）与 NaHCO₃（小苏打）四方面差异 + 相互转化，是第二章实验设计题的题库重镇。

## 是什么

两种白色易溶于水的钠盐，俗称与性质四维对比：

| | Na₂CO₃（纯碱、苏打） | NaHCO₃（小苏打） |
|---|---|---|
| 溶解度 | **较大** | 较小（同温下） |
| 热稳定性 | **稳定**（受热不分解） | **不稳定**（受热分解） |
| 与等浓度盐酸反应 | 慢（分步：先 CO₃²⁻→HCO₃⁻） | **快**（一步放 CO₂） |
| 与 NaOH | 不反应 | → Na₂CO₃ + H₂O |

**鉴别**（考试高频）：加热看是否分解（放 CO₂ 的是 NaHCO₃）、滴盐酸看出泡快慢（快的是 NaHCO₃）、**滴加 BaCl₂/CaCl₂ 溶液**——出白色沉淀的是 Na₂CO₃，NaHCO₃ 不反应（最可靠，因为另两法要看对比）。

**相互转化**：Na₂CO₃ → NaHCO₃ 通 CO₂ 加水；NaHCO₃ → Na₂CO₃ 加热**或**加 NaOH。正逆两条路都考。

## 为什么这样

热稳定性为什么差这么多？NaHCO₃ 里的 HCO₃⁻ 内部有"自带的酸"（H），受热时 H 转移到邻近的 O 上生成 H₂O，同时放出 CO₂——**含 H 的碳酸氢盐受热都分解，正盐稳定**。这个规律推广到 Ca(HCO₃)₂ 等一族。

与盐酸反应速率为什么差一倍？CO₃²⁻ 结合 H⁺ 是**分步**的：先 CO₃²⁻ + H⁺ = HCO₃⁻（不放气），再 HCO₃⁻ + H⁺ = H₂O + CO₂↑（才放气）；HCO₃⁻ 直接收第二个 H⁺一步放气。所以同浓度盐酸，NaHCO₃ 立刻冒泡、Na₂CO₃ 先"吞"一个 H⁺——这也解释了为什么滴加顺序影响现象（盐酸滴入 Na₂CO₃：先无气泡后有；Na₂CO₃ 滴入足量盐酸：立刻有）。

溶解度差异（Na₂CO₃ > NaHCO₃）看似反直觉（通常酸式盐更溶），成因在离子间作用力细节，高中阶段作为事实记住并用于**饱和石灰水中通 CO₂ 变浑浊**（生成难溶的 CaCO₃）与侯氏制碱（M1-T5-KP02）的析晶原理。

## 典型例子与方程式

**2NaHCO₃ --Δ--> Na₂CO₃ + H₂O + CO₂↑**：热稳定性差异的核心方程式，鉴别法一的依据。它说明"受热分解"本身就是一种化学性质——固固加热试管口向下倾斜（M1-T1-KP02 规范）。

**Na₂CO₃ + 2HCl 与 NaHCO₃ + HCl**：两式并排看分步与一步。它们说明等量酸时 Na₂CO₃ 耗酸**加倍**——"与酸反应放出 CO₂ 的量"计算题的坑就在耗酸比。

**Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃**：正向转化。它说明 Na₂CO₃ 溶液吸收 CO₂ 会"变纯碱为小苏打"，同时因 NaHCO₃ 溶解度较小可能析出晶体（侯氏制碱的原理种子）。

## 常见易错点

- **"Na₂CO₃ 与盐酸反应一定立即放气"**：分滴加方向。盐酸**滴入** Na₂CO₃ 溶液：开始酸不足，CO₃²⁻ 先变 HCO₃⁻，**无气泡**；酸过量才放气。反过来滴则一开始就冒泡。错因是没把"分步结合 H⁺"落到滴加顺序上。
- **"鉴别两兄弟用酚酞"**：不可靠。两者溶液都显碱性（水解，后续学习），都变红只是深浅不同——不能作为鉴别依据。可靠的是 BaCl₂ 沉淀法或加热法。错因是把"碱性不同"当成了"有/无碱性"。
- **"NaHCO₃ 与 NaOH 不反应"**：错。HCO₃⁻ + OH⁻ = CO₃²⁻ + H₂O——这正是"NaHCO₃ → Na₂CO₃"转化的一条路。错因是只记了与酸的反应忘了与碱的。
- **"等质量两盐与足量盐酸反应放 CO₂ 一样多"**：错。等质量时 NaHCO₃（84 g/mol）物质的量更多，放气**更多**（Na₂CO₃ 106 g/mol）。错因是只看碳原子没看摩尔质量。
