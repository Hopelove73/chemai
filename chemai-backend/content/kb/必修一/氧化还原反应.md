# 氧化还原反应

> 一句话定位：本篇是必修一第一章第三节的核心概念，建立在初中"得氧失氧"直觉和本册"物质的分类"（M1-T2-KP01）之上，是后续学习氯、钠、铁各元素性质的主线工具。

## 是什么

氧化还原反应是**有电子转移（化合价升降）的反应**。判断标准只有一条：反应前后有元素化合价发生变化。这一口径覆盖了初中"得氧失氧"的定义——初中学的 C + O₂、H₂ + CuO 只是氧化还原的特例；没有氧参与的反应（如 2Na + Cl₂）同样是氧化还原反应。

与之相对，没有化合价变化的反应叫非氧化还原反应（如复分解反应 NaOH + HCl = NaCl + H₂O）。

四种基本概念成对出现，抓住"谁失电子谁被氧化"：

| 概念 | 定义 | 记法 |
|---|---|---|
| 氧化反应 | 失电子、化合价**升**高 | 升、失、氧 |
| 还原反应 | 得电子、化合价**降**低 | 降、得、还 |
| 氧化剂 | **得**电子的物质（被还原，生成还原产物） | 得电子者 |
| 还原剂 | **失**电子的物质（被氧化，生成氧化产物） | 失电子者 |

电子转移用**双线桥**表示：箭头从反应物中失电子的元素指向同一反应物中降价的元素，桥上标注"得/失 e⁻ × 个数"。注意双线桥的起止都在**反应物一侧**。

## 为什么这样

电子为什么转移？因为不同元素的原子**束缚电子的能力不同**。活泼金属（Na、Fe）原子核对外层电子束缚弱，容易失去电子；活泼非金属（Cl₂、O₂）束缚强，容易夺得电子。两者相遇，电子从束缚弱的一方流向强的一方——这就是氧化还原的微观图景。

化合价之所以能当"探测器"，是因为电子带负电：原子失去电子后带正电、化合价升高；得到电子则相反。化合价变化是电子转移的**外在表现**，电子转移才是**本质**。这也解释了为什么同素异形体之间的转化（如 O₂ 与 O₃）化合价都是 0 价、没有升降，就不是氧化还原反应。

## 典型例子与方程式

**2Na + Cl₂ --点燃--> 2NaCl**：钠失去 2×e⁻（0 → +1）作还原剂，氯夺得 2×e⁻（0 → −1）作氧化剂。它说明没有氧参加的反应也能是氧化还原反应——判断依据是化合价，不是有没有氧。

**Fe + CuSO₄ = FeSO₄ + Cu**：铁失去 2×e⁻（0 → +2）作还原剂，Cu²⁺ 得到 2×e⁻（+2 → 0）作氧化剂。它说明氧化还原反应同时生成了两种产物：氧化产物（FeSO₄ 中的 Fe²⁺）和还原产物（Cu）。

**MnO₂ + 4HCl(浓) --Δ--> MnCl₂ + Cl₂↑ + 2H₂O**：只有**部分**氯（−1 → 0，生成 Cl₂）被氧化，另一部分氯保持 −1（生成 MnCl₂）没有变价。它说明同一物质中的同种元素可以"部分参与"氧化还原——这也是守恒法配平时最容易算错的情形。

## 常见易错点

- **"有氧参加才是氧化还原"**：错。判断标准是化合价是否变化，2Na + Cl₂ 没有氧但剧烈升降。错因是把初中的阶段性定义当成了本质定义。
- **"氧化剂发生氧化反应"**：错。氧化剂**得到**电子、被还原、发生还原反应。记忆口诀"升失氧、降得还"指的是**还原剂那一侧**。错因是望文生义。
- **"同种元素反应前后化合价没变就不可能参与氧化还原"**：对 MnO₂ 与浓盐酸的反应不成立——HCl 中的氯一部分变价、一部分不变，同种元素可以"部分被氧化"。错因是把"整物质"当成了"整元素"看。
- **双线桥箭头跨到生成物一侧**：双线桥起止都在反应物一侧，跨到生成物的是"单线桥"的画法（箭头从失电子元素直接指向得电子元素）。错因是两种桥混用。
