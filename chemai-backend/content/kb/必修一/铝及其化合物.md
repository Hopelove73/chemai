# 铝及其化合物

> 一句话定位：铝是"既能与酸又能与碱反应"的两性代表——单质、氧化物、氢氧化物一条线，全部围绕"两性"二字展开。

## 是什么

**铝单质**：银白色轻金属，活泼（还原性强）。常温下遇浓硫酸、浓硝酸**钝化**（同铁）；与氧气反应生成致密氧化铝薄膜，所以抗腐蚀性好。

**两性主线**：

- 铝：与酸反应放氢气（2Al + 6HCl = 2AlCl3 + 3H2↑），**也与强碱反应放氢气**（2Al + 2NaOH + 2H2O = 2NaAlO2 + 3H2↑）；点燃时 4Al + 3O2 --点燃--> 2Al2O3；
- 氧化铝 Al2O3：**两性氧化物**——与强酸生成铝盐（Al2O3 + 6HCl = 2AlCl3 + 3H2O），与强碱生成偏铝酸盐（Al2O3 + 2NaOH = 2NaAlO2 + H2O）；
- 氢氧化铝 Al(OH)3：**两性氢氧化物**——与强酸、强碱都反应，但**不与氨水反应**（弱碱不溶它），所以实验室用氨水制 Al(OH)3。

**铝盐与偏铝酸盐的转化**：Al3+ 加适量强碱 → Al(OH)3 → 再加强碱 → AlO2⁻（偏铝酸根）；反向 AlO2⁻ 加酸 → Al(OH)3 → 加过量酸 → Al3+。**氢氧化铝只沉淀在"适量"区间**。

**明矾** KAl(SO4)2·12H2O：净水剂（水解生成 Al(OH)3 胶体吸附悬浮物，M2-T4-KP09 顺承）。

## 为什么这样

为什么铝能与强碱反应？表面看"金属只与酸反应"，实质是：Al 先与水反应生成 Al(OH)3 与 H2，NaOH 溶解掉 Al(OH)3（两性），暴露新铝面让反应持续——**两性是"能与碱反应"的根本原因**。这也是铝制餐具不能长期盛放酸性或碱性食物的原因。

为什么用氨水而不用 NaOH 制氢氧化铝？Al(OH)3 两性：NaOH 一过量就把它溶成 AlO2⁻，用量难控；氨水是弱碱，**不能溶解 Al(OH)3**，沉淀完全且不怕过量——"弱碱制两性氢氧化物"是最优选择。

## 典型例子与方程式

**2Al + 2NaOH + 2H2O = 2NaAlO2 + 3H2↑**：铝与强碱。它说明两性的单质行为；电子转移上 Al 仍是还原剂（0 → +3），水是氧化剂。

**Al(OH)3 + NaOH = NaAlO2 + 2H2O**：两性氢氧化物与碱。它说明 Al(OH)3 "既能当碱被酸溶、又能当酸被碱溶"。

**铝三角**（Al3+ ⇌ Al(OH)3 ⇌ AlO2⁻）：Al3+ 与 AlO2⁻ **直接相遇也生成 Al(OH)3**（双水解式互促：Al3+ + 3AlO2⁻ + 6H2O = 4Al(OH)3↓）。它说明"适量区沉淀、两端溶解"的图像题基础。

## 常见易错点

- **"铝与盐酸、与 NaOH 反应的氧化剂都是酸或碱"**：错。两反应的氧化剂都是**水**（H 被还原为 H2）；酸或碱只是溶解产物的"助攻"。
- **"Al(OH)3 能溶于氨水"**：错。氨水碱性弱，不能溶解两性氢氧化物；这正是用它制 Al(OH)3 的原因。
- **"Al2O3 与水反应生成 Al(OH)3"**：错。Al2O3 难溶于水、不与水反应；制 Al(OH)3 要走盐溶液路线。
- **"铝比铁活泼，所以铝制品更易腐蚀"**：错。铝表面致密 Al2O3 薄膜自我保护；这层膜被破坏（如接触 NaCl 长期、或刮擦后遇酸碱）才腐蚀加速。
- **"明矾净水是杀菌消毒"**：错。Al(OH)3 胶体只吸附悬浮物沉降，无杀菌作用。
