# 氧化还原方程式的配平与规律

> 一句话定位：本篇解决氧化还原的两个进阶问题——系数怎么配（电子守恒法）与产物怎么判（价态规律），是氧还工具箱（M1-T2-KP06/07）的计算与预测层。

## 是什么

**配平的核心原则只有一条：得失电子总数相等（电子守恒）**。它与原子守恒、电荷守恒并列，但电子守恒是氧化还原配平的"骨架"——先按升降配出氧化剂/还原剂与其产物的系数，再用观察法配平其余（通常是 H₂O、酸/碱）。

**价态三条规律**：

1. **最高价态——只有氧化性**：元素处于最高价（如 Fe³⁺、MnO₄⁻ 中的 +7、浓硫酸中的 +6）不能再失电子，只能得电子作氧化剂；
2. **最低价态——只有还原性**：元素处于最低价（如金属单质、S²⁻、Cl⁻）不能再得电子，只能失电子作还原剂；
3. **中间价态——兼有氧化性与还原性**：遇强氧化剂显还原性、遇强还原剂显氧化性（如 Fe²⁺、SO₂、H₂O₂）。

**同价态归中、歧化两条走向**：同种元素高低价态反应，产物价态"向中间靠拢"（归中反应），**价态不交叉**；中间价态一分为二走向高低（歧化反应，如 Cl₂ 遇碱）。

## 为什么这样

为什么电子守恒能当配平骨架？一个电子从还原剂转移到氧化剂，失与得必然一一对应——化合价升降总数是同一次转移的两面，所以"升降总数相等"不是巧合而是**记账必须**。配平时先让"升价总数 = 降价总数"定下双方系数，其余原子观察补齐，最后 H、O 用水收尾——这个顺序保证了最大的骨架先稳住，避免凑数。

为什么价态不交叉？归中反应里高价降到中间价、低价升到中间价，若发生"交叉"（高变到比低价还低），意味着同一个电子转移路径上产物价态违背能量趋势——教材阶段把它作为事实规律记住，本质解释在后续学习。

## 典型例子与方程式

**2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O**：电子守恒配平的标准示范。Mn 从 +7 降到 +2 得 5e⁻，Cl 从 −1 升到 0 失 1e⁻，最小公倍数 5——但 HCl 系数是 16 不是 5：被氧化的 Cl 只有 **10 个**（生成 5Cl₂），另外 **6 个** Cl 保持 −1 与 K⁺、Mn²⁺ 结成盐。"部分参与氧化还原"的计算正是这里最易错的一步。

**Cl₂ + 2NaOH = NaCl + NaClO + H₂O**：氯的歧化。Cl 从 0 价一半降到 −1、一半升到 +1，升降都在**自身**上发生。它说明歧化反应里氧化剂与还原剂是**同一种物质**。

**3S + 6NaOH --Δ--> 2Na₂S + Na₂SO₃ + 3H₂O**：硫的歧化（0 → −2 与 +4）。与上例同构，它说明"同种中间价态元素遇碱"是歧化的常见场景，产物两种价态都来自该元素。

## 常见易错点

- **"HCl 的系数按被氧化部分配"**：错。MnO₂/浓盐酸、KMnO₄/浓盐酸这类"部分参与"反应里，HCl 同时扮演还原剂（变 Cl₂）与酸（成盐）两个角色，系数 = 被氧化部分 + 成盐部分。KMnO₄ 反应里 16 = 10（被氧化）+ 6（成盐）。错因是把 5 直接抄成 HCl 系数。
- **"归中反应价态可以交叉互换"**：错。H₂S（−2）与 SO₂（+4）反应生成 S（0）和 H₂O，−2 升到 0、+4 降到 0，各自向中间靠拢；不存在 −2 降到 −4、+4 升到 +6 的"交叉产物"。错因是没把"向中间靠拢"当成约束条件。
- **"歧化与归中可能同时出现在同一个反应里"**：对同一元素同一反应，两种走向只能占其一—— Cl₂ 遇碱是纯歧化，产物 Cl（−1）与 Cl（+1）不是 Cl₂ 之间"归中"来的。错因是规律背串了。
- **"配平只查原子守恒"**：氧化还原方程式配完要三查——**电子守恒（升降总数相等）+ 原子守恒 + 电荷守恒（若是离子方程式）**。缺一都可能是配错的信号。错因是沿用非氧化还原的检查习惯。
