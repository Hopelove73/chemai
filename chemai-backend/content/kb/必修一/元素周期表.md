# 元素周期表

> 一句话定位：本篇把 100 多种元素排成一张"按规律生长的地图"——周期与族的划分逻辑 + 碱金属、卤素两大家族的性质递变实证。

## 是什么

**排列原则**：按**原子序数（质子数）递增**从左到右排列；**电子层数相同**的元素同处一**周期**（7 个横行）；**最外层电子数相同**的元素同处一**族**（18 个纵列，主族标 A、副族标 B）。

**位置规律**：周期序数 = 电子层数；主族序数 = 最外层电子数。如 Na（2,8,1）→ 第三周期 ⅠA 族。

**两大代表家族**（教材重点实验素材）：

**碱金属族（ⅠA：Li Na K Rb Cs）**——最外层都 1 个电子：
- 都是与水剧烈反应的活泼金属（产物都是碱 + H₂）；
- 自上而下**活泼性递增**：Li 与水缓和漂浮，K 与水**燃烧甚至爆炸**；
- 密度总体增大（Li Na K 浮于水，Rb Cs 沉底）。

**卤族元素（ⅦA：F Cl Br I）**——最外层都 7 个电子：
- 都是非金属、易得 1 电子，单质有氧化性；
- 自上而下**氧化性递减**：Cl₂ 能把 Br⁻、I⁻ 从盐溶液里置换出来（溴水橙色、碘水黄色/淀粉变蓝）。

## 为什么这样

为什么"同族性质相似"？同族最外层电子数相同——化学反应的主角就是最外层电子，主角相同则"戏路"相同。碱金属都易失 1 电子、卤素都易得 1 电子，所以分别表现为"都像强还原剂"与"都像强氧化剂"。

为什么自上而下递变？电子层数递增 → 最外层电子离核更远 → 核对它的束缚变弱。对碱金属：失电子越来越容易 → 金属性增强；对卤素：得电子越来越难 → 非金属性（氧化性）减弱。**"层数增加 = 束缚变弱"是所有递变的统一解释**。

## 典型例子与方程式

**2Na + 2H₂O = 2NaOH + H₂↑ 与 2K + 2H₂O = 2KOH + H₂↑**：同族对照实验。K 与水反应比 Na 更剧烈（燃烧/爆炸）。它们说明同族相似（同产物类型）+ 递变（剧烈程度）——一条实验证据链同时钉住"相似"与"递变"。

**Cl₂ + 2NaBr = 2NaCl + Br₂；Cl₂ + 2KI = 2KI 变换 → 2NaCl + I₂**：置换实验证明氧化性 Cl₂ > Br₂ > I₂。它说明族内递变不是背出来的，是**置换实验做出来的**——"强换弱"的证据链。

## 常见易错点

- **"周期序数 = 最外层电子数"或"族序数 = 电子层数"**：两句话正好说反。正确：**周期 = 电子层数；主族序数 = 最外层电子数**。错因是两个"排表依据"背串。
- **"同族元素性质完全相同"**：错。是**相似**且有**规律性递变**——Na 与 K 相似但 K 更活泼。错因是把"相似"绝对化。
- **"卤素单质与水反应都生成强酸"**：错。F₂ 与水剧烈反应放出 O₂（产物是 HF 和 O₂），与 Cl₂/Br₂/I₂ 的行为完全不同——F 太活泼是"例外担当"。错因是递变规律推到了极端元素身上。
- **"稀有气体不反应所以不在周期表规律内"**：错。稀有气体是 0 族，最外层稳定结构本身就是"递变的终点参照物"。错因是把"不活泼"当"不参与规律"。
