# 合金与金属材料

> 一句话定位：本篇从单质走向材料——合金为什么比纯金属更"好用"，以及"性质决定用途"的选材逻辑。

## 是什么

**合金**：由一种金属跟其他金属（或非金属）熔合形成的具有**金属特性**的物质。本质是**混合物**（不是化合物！）。

**合金 vs 纯金属的性质差异**（都是结构决定）：

1. **硬度一般更大**：异种原子嵌入使原子层间滑动困难；
2. **熔点一般更低**：如焊锡（Sn-Pb）熔点远低于锡或铅；
3. **密度、导电性等随之改变**。

**常见合金**：

- **铁合金**：生铁（含 C 2%~4.3%，硬而脆）与钢（含 C 0.03%~2%，坚韧可锻）——差别只在**含碳量**；
- **铝合金**：密度小、强度高（门窗、飞机骨架）；
- **不锈钢**：Fe-Cr-Ni 合金，Cr 形成致密氧化膜防锈；
- **铜合金**：青铜（Cu-Sn）、黄铜（Cu-Zn）。

**选材逻辑**：性质决定用途——轻→铝合金（航空）、耐腐蚀→不锈钢（厨具/化工）、导电→纯铜（导线，纯金属导电性优于合金）。

## 为什么这样

为什么合金硬度更大？纯金属的原子"大小一致、排列整齐"，受外力时原子层可以**滑动**（所以纯金属软、易变形）；合金中异种原子大小不同，破坏了整齐排列，**层间滑动被卡住**——宏观就是变硬变脆。这个模型同时解释了硬度升高与延展性下降。

为什么导电性下降？纯金属靠自由电子定向移动导电；异种原子的电子环境不同，对电子流动的阻碍更大。所以**高压输电线用铝（或铜），绝不用合金**——导电性优先。

不锈钢为什么不锈？Cr 在表面形成致密 Cr₂O₃ 氧化膜（与铝的 Al₂O₃ 同理），隔绝氧气与水——"钝化防锈"思路的合金化应用。

## 典型例子与方程式

本篇为材料性质单元，无新方程式；与铁单质（M1-T2-KP17）的锈蚀反应、钝化原理直接关联。最值得展开的判断：**生铁与钢的差别是含碳量而不是"是不是铁"**——含碳量降低（炼钢去碳）是"生铁变钢"的全部秘密，高炉与转炉的化学都围绕碳做文章。

## 常见易错点

- **"合金是化合物"**：错。合金是**混合物**——各成分保持各自的化学性质，只是物理性质（硬度/熔点/导电性）改变。错因是"熔合"二字让人以为是化合。
- **"合金的熔点一定比成分金属高"**：反了。**一般更低**（焊锡低于锡和铅）。错因是"混合后更强"的直觉外溢到熔点。
- **"不锈钢永远不会生锈"**：不准确。Cr₂O₃ 膜在特定环境（含氯离子如盐水长期浸泡）会被破坏——不锈钢"难锈"而非"永不锈"。错因是把商业名当成了化学承诺。
- **"导线用铝合金更划算所以普及"**：导电性纯金属更优；输电线选铝是"导电性够用 + 密度小"的综合权衡，不是合金导电更好。错因是单因素归因。
