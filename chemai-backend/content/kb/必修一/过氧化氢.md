# 过氧化氢

> 一句话定位：-1 价氧"居中"的最好样本——既能当氧化剂又能当还原剂，分解只生成水与氧气，是绿色氧化剂与实验室制氧的双料选手。

## 是什么

过氧化氢（H2O2），俗称双氧水：无色液体，水溶液显**弱酸性**。分子中氧为 **-1 价**（0 与 -2 之间），所以：

- **遇更强氧化剂显还原性**：-1 → 0（放 O2）；
- **遇还原剂显氧化性**：-1 → -2（得电子变 H2O/OH⁻）；
- **催化分解**：MnO2 等催化下 2H2O2 = 2H2O + O2↑（自身既是氧化剂又是还原剂，歧化）。

**用途**：医疗消毒（3% 稀溶液）、漂白（氧化型漂白，不像 SO2 可逆）、火箭推进剂（高浓度）、**实验室快速制氧气**（MnO2 催化分解——装置不用加热）。

## 为什么这样

为什么 H2O2 能"绿色氧化"？它的还原产物是**水**、氧化产物是**氧气**——不给体系引入新杂质，这是它与 Cl2、KMnO4 等氧化剂的本质差别（那些会引入 Cl⁻、K⁺/Mn²⁺）。工艺流程题偏爱 H2O2 做氧化剂，理由就是"不引入杂质离子"。

为什么 -1 价氧既升又降？0 价是氧的最高价、-2 是最低价，-1 居中——与硫（M2-T2-KP01）同一条价态规律：**中间价态兼有氧化性与还原性**，遇强显弱（价态向两侧靠）。

## 典型例子与方程式

**2H2O2 --MnO2--> 2H2O + O2↑**：催化分解（歧化：-1 → -2 与 0）。它说明实验室制氧气的"液固不加热"装置来源；MnO2 质量与性质不变（M1-T3-KP09 催化剂）。

**H2O2 + 2KI = I2 + 2KOH**：H2O2 把 I⁻ 氧化为 I2（氧化性）。它说明-1 → -2 得电子；淀粉变蓝可检验。

**H2O2 + Cl2 = 2HCl + O2**：H2O2 使氯水褪色（还原性，-1 → 0）。它说明遇到强氧化剂 Cl2 时 H2O2 让位——与 SO2 还原氯水（M2-T2-KP02）同型对照。

**H2O2 + H2S = S↓ + 2H2O**：氧化 H2S 析出硫。它说明氧化性的"干净"：产物除硫外只有水。

## 常见易错点

- **"H2O2 只有氧化性"**：错。-1 价居中，遇 KMnO4、Cl2 显还原性；遇 KI、H2S、Fe2+ 显氧化性。
- **"双氧水漂白与 SO2 漂白原理相同"**：错。H2O2 是氧化型漂白（不可逆，同 HClO）；SO2 是化合型（可逆）。
- **"MnO2 与 H2O2 反应是 MnO2 被氧化"**：错。MnO2 是催化剂，反应前后不变；变了的是 H2O2 的价态。
- **"H2O2 是强酸"**：错。弱酸性，比碳酸还弱得多；酸性只是它的次要性质。
- **"保存双氧水用铁桶"**：错。金属离子催化其分解，应用棕色玻璃瓶、避光阴凉处，并加稳定剂。

## 与其他知识的联系

先修：氧化还原反应（M1-T2-KP06）提供中间价态判据；分散系与胶体（M1-T2-KP02）的催化剂对照实验用过 H2O2 分解。

后继：硫单质（M2-T2-KP01）的价态规律同源；影响化学反应速率的因素（M3-T2-KP02）用 H2O2-MnO2 讲活化能；电离常数（M3-T3-KP02）比较弱酸性时 H2O2 常作参照。
