# 气体摩尔体积

> 一句话定位：本篇给物质的量添第三条换算腿——气体的体积换算，核心是"标准状况 22.4 L/mol"的条件限定与阿伏加德罗定律的推论。

## 是什么

**气体摩尔体积 Vm**：单位物质的量气体所占的体积。**标准状况**（0 ℃、101 kPa）下，**任何气体的摩尔体积都约为 22.4 L/mol**。

换算：n = V / Vm（V 是**气体**在标况下的体积，单位 L）。

条件限定是本题型的生命线，"22.4"成立的**两个前提**：①气体；②标准状况。缺一即错。

**阿伏加德罗定律**：同温同压下，相同体积的任何气体含**相同数目的分子**——这是定律的内容。由此得出两条推论：同温同压下，体积比 = 分子数比 = 物质的量比——**气体反应方程式的系数比就是体积比**（如 H₂ + Cl₂ = 2HCl，1 体积 H₂ 恰与 1 体积 Cl₂ 完全反应，生成 2 体积 HCl）；同温同体积下，气体的压强之比 = 分子数之比。

为什么固液没有这个"22.4"？微粒间距：气体分子间距大（约为分子直径的十倍量级），体积主要由**间距**决定——同温同压下同分子数的气体体积必然相同；固液微粒紧密堆积，体积由**微粒本身大小**决定——1 mol 不同固液体积极不相同（1 mol Fe 约 7.1 cm³，1 mol H₂O 约 18 cm³，1 mol 蔗糖更大）。

## 为什么这样

为什么标况下都一样？气体的可压缩性意味着"体积"主要是分子活动空间的度量。同温同压下，分子平均间距由温度与压强共同决定——与是什么气体无关。于是"同温同压 + 同分子数 ⇒ 同体积"，取比例常数就是 Vm。22.4 L/mol 是把这条普适规律在标况下的取值，**不是气体的属性而是状态的属性**。

非标况下 Vm 变不变？变。温度升高/压强降低，Vm 增大；反之减小。所以"22.4"必须带着"标况"两个字才有意义——这也是正误判断题的第一排查点。

## 典型例子与方程式

先把要用的工具摆在桌面上——定律的内容：同温同压下，相同体积的任何气体含相同数目的分子；推论一（同温同压）：体积比 = 分子数比 = 系数比；推论二（同温同体积）：压强比 = 分子数比。下面三条是典型用法。

**标况下 11.2 L CO₂ 是多少摩尔？** n = 11.2 / 22.4 = 0.5 mol。最基础的一条腿换算。

**标况下 22.4 L H₂ 与 22.4 L Cl₂ 恰好完全反应，生成多少体积 HCl？** 系数比 1:1:2 → 体积比 1:1:2 → 44.8 L。它说明阿伏加德罗定律让化学方程式可以直接按体积算——气体反应的计算 shortcut。

**同温同压下，同体积的 CO 与 N₂**：分子数相同（M=28 相同是巧合，不是依据）。它说明"分子数相同"的判据是**同温同压同体积**，与摩尔质量无关——但由此可推二者密度相同。

## 常见易错点

- **"1 mol 气体的体积一定是 22.4 L"**：错。只有**标准状况**才是 22.4 L；25 ℃ 101 kPa 下约 24.5 L。错因是把 22.4 当成了气体的固有属性。
- **"标况下 22.4 L 水是 1 mol"**：错。标况下水是**液态**（0 ℃ 结冰），"气体摩尔体积"只对气体有效。同族陷阱：标况下 SO₃ 是固态、CCl₄ 是液态——它们的 22.4 L 不对应 1 mol。错因是只查了"标况"没查"是否气体"。
- **"22.4 L/mol 适用于任何气体混合物之外的场合"**：对混合气体同样成立——只要都是气体，Vm 按混合体系算，22.4 L 混合气体也是 1 mol（分子数意义）。错因是以为定律只管纯净物。
- **"同温同压下密度之比等于摩尔质量之比"记反成"体积比"**：同温同压同体积时**分子数相同**；密度 ρ = m/V，同体积时 ρ 比 = m 比 = M 比（阿伏加德罗定律推论）。错因是推论记串。
