# 钠的氧化物

> 一句话定位：本篇是"同种元素两种氧化物性质对比"的第一个样本——Na₂O 普通碱性氧化物 vs Na₂O₂ 特殊供氧剂，对比法贯穿整章。

## 是什么

**Na₂O（氧化钠）**：白色固体，典型的**碱性氧化物**——与水化合成碱（NaOH）、与酸反应生成盐和水，所有反应都**没有电子转移**（Na 恒为 +1，O 恒为 −2）。

**Na₂O₂（过氧化钠）**：**淡黄色**固体，不是碱性氧化物。氧是 **−1 价**（介于 0 与 −2 之间的中间价态），所以它**遇水、遇 CO₂ 都放出氧气**，同时自身发生歧化（−1 价的氧一半升到 0、一半降到 −2）。

| | Na₂O | Na₂O₂ |
|---|---|---|
| 颜色 | 白色 | **淡黄色** |
| 氧的价态 | −2 | **−1** |
| 与水 | → NaOH | → NaOH + **O₂↑** |
| 与 CO₂ | 不反应 | → Na₂CO₃ + **O₂** |
| 类别 | 碱性氧化物 | **过氧化物**（供氧剂） |

**用途**：Na₂O₂ 用作呼吸面具和潜水艇里的**供氧剂**——恰好把人呼出的 CO₂ 和水蒸气变成 O₂。

## 为什么这样

Na₂O₂ 里的氧为什么是 −1 价？过氧根离子 O₂²⁻ 中两个氧原子共用一对电子、每个氧各分到 −1。−1 是中间价态——**既能升（→0，放 O₂）也能降（→−2，成 NaOH/Na₂CO₃）**，这正是它与水和 CO₂ 反应的实质（歧化，用 M1-T2-KP08 的规律解读）。

供氧反应为什么"一举两得"？2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂：把密闭环境里**人呼出的废气（CO₂）直接转化成人需要的氧气**，还顺带除掉了 CO₂。一个方程式同时解决两个生命维持问题——这是化学选材的经典案例。

用 Na₂O₂ 与 CO₂ 反应做电子守恒计算时的关系式：**2Na₂O₂ ~ O₂**（每 2 mol Na₂O₂ 放出 1 mol O₂，转移 2 mol e⁻）；与水同理。这个"2:1"是计算题的抓手。

## 典型例子与方程式

**2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂**：供氧剂的核心方程式。它说明 Na₂O₂ 与 CO₂ 的反应是**氧化还原反应**（歧化）——CO₂ 通常不做氧化剂也不做还原剂，这里只是反应物环境。

**2Na₂O₂ + 2H₂O = 4NaOH + O₂↑**：与水也放氧。滴加酚酞**先变红后褪色**——先变红因生成 NaOH，后褪色因 Na₂O₂ 的强氧化性漂白了色素（连接 HClO 的漂白逻辑，M1-T2-KP13）。

**Na₂O + H₂O = 2NaOH**：普通碱性氧化物的规矩。与上式对照，它说明"同是钠的氧化物、行为完全不同"——差别全在氧的价态。

**2Na₂O₂ + 4HCl = 4NaCl + 2H₂O + O₂↑**：与酸反应不放"只有盐和水"——所以 Na₂O₂ 不是碱性氧化物（M1-T2-KP01 的定义在这里落地检验）。

## 常见易错点

- **"Na₂O₂ 是碱性氧化物"**：错。与酸反应多出 O₂，不符合"生成盐**和**水"的定义。错因是金属氧化物=碱性氧化物的刻板印象（M1-T2-KP01 易错点的再现）。
- **"Na₂O₂ 与 CO₂ 反应不是氧化还原反应"**：错。氧从 −1 歧化到 0 和 −2，是教科书级的歧化样本。错因是只盯着 C 和 Na 的价态没看 O。
- **"供氧计算按 Na₂O₂ ~ O₂ = 1:1"**：错。正确关系是 **2:1**。错因是配平时没数氧原子。
- **"Na₂O₂ 滴酚酞只变红"**：先红后褪。只答一半不得分——褪色恰恰是 Na₂O₂ 氧化性的证据。错因是类比 NaOH 时忘了 Na₂O₂ 的漂白性。

## 与其他知识的联系

先修：钠单质（M1-T2-KP09）——两种氧化物都来自钠的氧化（条件不同产物不同）；氧化还原方程式的配平与规律（M1-T2-KP08）——歧化规律是本篇反应的解读工具。

后继：**碳酸钠与碳酸氢钠**（M1-T2-KP11）延续对比法；HClO 漂白（M1-T2-KP13）与 Na₂O₂ 漂白同源（强氧化性）；选择性必修的电化学中 Na₂O₂ 的过氧根结构还会回归（高中后续学习）。
