# 物质的量浓度

> 一句话定位：本篇给物质的量添第四条换算腿——溶液视角的浓度表达，cB = nB/V 是溶液反应计算的通用语言。

## 是什么

**物质的量浓度**：单位体积溶液中所含溶质 B 的物质的量，符号 cB，常用单位 **mol/L**。

**定义式：cB = nB / V**。三个铁律：
1. V 是**溶液**的体积，不是溶剂的体积（1 mol 固体溶于 1 L 水所得溶液体积 ≠ 1 L）；
2. nB 是**溶质**的物质的量（从溶液中取出任意体积，浓度不变，n 随体积等比变）；
3. 带结晶水的物质按**无水物**计浓度（胆矾 CuSO₄·5H₂O 溶于水，浓度按 CuSO₄ 算）。

**稀释定律**：稀释前后溶质的 n 不变 → **c₁V₁ = c₂V₂**。

从浓溶液取出任意体积 V，c 不变、n = cV；溶液混合（稀溶液近似体积相加）时 n 守恒。

## 为什么这样

为什么不用"质量分数"就够了？化学反应按**微粒个数比**进行——方程式系数是微粒比，直接换成物质的量比。质量分数要先除摩尔质量转一道弯；cB 直接给出"每升溶液里有多少摩尔溶质"，**与方程式系数同语言**。这就是为什么实验室试剂瓶上标注的是 mol/L 而不是百分比。

取出任意体积浓度不变的原因：溶液是**均一**的（M1-T2-KP02 分散系里溶液的均一性）——任意部分的组成与整体相同。变的是 n（随体积缩放），不变的是"每升多少摩尔"这个比值。

## 典型例子与方程式

**将 58.5 g NaCl 溶于水配成 1 L 溶液，c(NaCl) = ?** n = 58.5/58.5 = 1 mol → c = 1 mol/L。质量→n→c 的标准链。

**从 500 mL 0.2 mol/L 的 Na₂CO₃ 溶液中取出 50 mL，c 和 n 各多少？** c 仍 0.2 mol/L（均一性）；n = 0.2 × 0.05 = 0.01 mol。它说明"取出一部分"只改 n 不改 c——分装试剂瓶不改变浓度。

**把 0.5 mol/L 的溶液 100 mL 稀释到 500 mL，c = ?** c₂ = c₁V₁/V₂ = 0.5×100/500 = 0.1 mol/L。稀释四倍浓度四分之一，n 守恒。

**c(Na⁺) 与 c(Na₂CO₃) 的关系**：1 mol Na₂CO₃ 电离出 2 mol Na⁺ → c(Na⁺) = 2c(Na₂CO₃)。它说明离子浓度要乘"每分子含几个该离子"的系数——溶液中离子反应计算的高频陷阱。

## 常见易错点

- **"1 mol 溶质溶于 1 L 水，浓度是 1 mol/L"**：错。1 L 是**溶剂**体积；溶液体积会变（通常小于两者简单和）。正确做法是**配成 1 L 溶液**（容量瓶定容）。错因是没分清溶剂与溶液。
- **"取出 100 mL 后浓度减半"**：错。均一性决定浓度不变，只是 n 变小。错因是把"变少"等同于"变稀"。
- **"胆矾 0.1 mol 配成 1 L 溶液，c(CuSO₄·5H₂O) 是标注对象"**：错。溶液里没有结晶水合物这个物种——浓度按 **c(CuSO₄)** 计 = 0.1 mol/L；结晶水进入溶剂。错因是没理解"溶解即电离/水合，带的水归水"。
- **"稀释后 n 变了"**：稀释只加水，溶质 n 恒定——c₁V₁ = c₂V₂ 的全部依据。错因是把"浓度变"外溢成"量变"。
- **"c(Na⁺) = c(Na₂SO₄)"**：错，差系数 2。错因是离子系数没乘。
