# 化学反应的限度

> 一句话定位：本篇揭示"反应物不一定全部变产物"——可逆反应与化学平衡状态（逆等动定四特征），是合成氨等工业反应的原理底座。

## 是什么

**可逆反应**：在**同一条件**下，既能向正反应方向进行、又能向逆反应方向进行的反应。记号"⇌"。典型：Cl₂ + H₂O ⇌ HCl + HClO；N₂ + 3H₂ ⇌ 2NH₃。

**化学平衡状态**：可逆反应进行到一定程度，正反应速率与逆反应速率**相等**，反应物与生成物的浓度**不再改变**——反应"停"在这里，但不是真停（微观仍在双向进行）。

**平衡四特征（逆等动定）**：

- **逆**：研究对象必须是可逆反应；
- **等**：v正 = v逆（微观上双向速率相等）；
- **动**：动态平衡，正逆反应仍在进行；
- **定**：各组分浓度/百分含量保持恒定。

**反应的限度**：平衡时反应物的转化率 <100%——"限度"就是平衡时反应进行的最大程度。可逆反应不可能"完全反应"，这是与不可逆反应的本质区别。

## 为什么这样

为什么会有可逆反应？正反应消耗反应物 → 反应物浓度下降、正速率变慢；生成物积累 → 逆速率变快。**两条速率曲线必然相交**——交点即平衡。所以只要正逆反应同条件共存，平衡的到来是**数学必然**，不是某些反应的特例。

为什么工业合成氨要循环利用原料？N₂ + 3H₂ ⇌ 2NH₃ 的限度决定了单程转化率有限（约 10%~20%）——未反应的 N₂/H₂ 分离后**送回反应塔再反应**，循环往复提高总转化率。"限度"不是终点，是工程设计的起点。

如何判断"达到平衡"？看标志：**变量不变**——某个随反应进行而变化的量（如颜色、总压、平均摩尔质量）保持恒定时即平衡；恒定不变的量（如任意时刻都相等的量）不能作标志。

## 典型例子与方程式

**Cl₂ + H₂O ⇌ HCl + HClO**：氯水的"七种微粒并存"（M1-T2-KP12）就是平衡共存的直接证据。它说明平衡态下反应物与生成物**同时存在**——这也是为什么氯水既显酸性又有漂白性。

**N₂ + 3H₂ ⇌ 2NH₃**：工业合成氨。它说明可逆反应的限度逼出了工程对策（循环、加压、催化剂、控温）——化学原理与工程设计的接口。

**判断例**：恒温恒容下，2SO₂ + O₂ ⇌ 2SO₃，"SO₂ 与 SO₃ 浓度之比不变"是否平衡？——比值不变 ≠ 各自浓度不变（可能同比例变化中）→ **不能**作为标志。它说明"变量不变"的"变量"二字必须抠准。

## 常见易错点

- **"可逆反应就是既能正着来也能反着来的反应"**：不准确。必须**同一条件**下双向进行——H₂ 在 O₂ 中点燃生成水、水电解生成 H₂/O₂ 是不同条件，**不是**可逆反应。错因是漏掉"同一条件"。
- **"达到平衡时反应停止了"**：错。是**动态**平衡，正逆速率相等但不为零。错因是把"宏观不变"当成"微观停止"。
- **"平衡时反应物与生成物浓度相等"**：错。是**不再变化**，不是相等——相等只是特殊情况（恰好起始配比合适）。错因是把"定"理解为"等"。
- **"加入催化剂可以提高转化率"**：错。催化剂**同等倍数**加快正逆速率，只缩短到达平衡的时间，**不改变限度**。错因是把"加得快"当成"加得多"。
