# 次氯酸与漂白粉

> 一句话定位：本篇把氯气性质篇里埋下的 HClO（M1-T2-KP12）展开成三条性质 + 漂白粉的制备/使用/失效闭环，是"性质→用途→保存"链条的完整样本。

## 是什么

**HClO（次氯酸）三条性质**：

1. **弱酸性**：酸性弱于碳酸——所以 Ca(ClO)₂ + CO₂ + H₂O 能"强酸换弱酸"式地产出 HClO；
2. **不稳定性**：见光分解（2HClO --光照--> 2HCl + O₂↑）——所以氯水、漂白液要**避光保存**；
3. **强氧化性**：能氧化色素分子而漂白、能杀菌消毒——漂白的实质。

**漂白粉**：Cl₂ 通入**石灰乳**制得，成分是 Ca(ClO)₂ 与 CaCl₂ 的混合物，**有效成分 Ca(ClO)₂**。使用时遇空气中的 CO₂ 和水蒸气转化为 HClO 发挥漂白/消毒作用；同样因为 HClO 不稳定（分解成无漂白力的 HCl），漂白粉**久置失效**——密封避光保存。

## 为什么这样

为什么"强酸制弱酸"在 here 反过来用了？常规是强酸置换弱酸，而 Ca(ClO)₂ + CO₂ + H₂O 反应里"弱"的 HClO 被制了出来——因为驱动力不是酸性强弱，而是**CaCO₃ 沉淀的生成**把离子拉出了溶液。反应方向 = 离子浓度下降的方向（M1-T2-KP04 的条件在这里显形）。

为什么漂白粉在潮湿空气里失效而干燥环境慢？失效链条是 Ca(ClO)₂ →（CO₂+H₂O）→ HClO →（光照）→ HCl + O₂，两步都**需要水参与**（第一步要水、第二步见光）。干燥避光就是切断链条。

为什么 HClO 的氧化性能漂白却不能漂得无限久？HClO 氧化色素是**不可逆地破坏色素分子结构**——所以漂白过的东西不会恢复颜色；但 HClO 自己被消耗掉就没了，这正是"漂白液要现用现配/密封保存"的原因。

## 典型例子与方程式

**Cl₂ + 2Ca(OH)₂ = Ca(ClO)₂ + CaCl₂ + 2H₂O**：漂白粉制备（Cl₂ 与**石灰乳**，不是澄清石灰水——工业量大用悬浊液）。与 Cl₂ + 2NaOH 对照：同是"氯气+碱"歧化族，碱换成谁产物就换成谁的盐。它说明"背一条母版换碱推一族"的学法。

**Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO**：漂白粉"生效"方程式——放进水里（洗衣服时）就是这个反应在放 HClO。它说明漂白粉本身不漂白，**转出来的 HClO 才漂白**。

**2HClO --光照--> 2HCl + O₂↑**：失效方程式。HCl 歧化的逆路？不是——这是 HClO 分解，Cl 从 +1 降到 −1、O 从 −2 升到 0，**氯被还原、氧被氧化**。它说明"不稳定"要落到具体分解反应上。

## 常见易错点

- **"漂白粉的有效成分是 CaCl₂"**：错。CaCl₂ 是副产物；**有效成分是 Ca(ClO)₂**（能转出 HClO 的那一份）。错因是看到"成分是混合物"就没分主次。
- **"漂白粉漂白原理与活性炭相同"**：完全不同。活性炭是**吸附**（物理，色素没被破坏，可逆）；HClO 是**氧化**（化学，色素被破坏，不可逆）。错因是把"变白"当成一种现象。
- **"Ca(ClO)₂ + CO₂ + H₂O 是弱酸制强酸"**：方向说反了。这是"强酸（碳酸的酸性比 HClO 强）制弱酸"且**沉淀推动**；产物 HClO 是更弱的酸。错因是只看名字"次氯酸"没比较酸性序列。
- **"氯水、漂白粉密封保存是为了防止挥发"**：漂白粉不是挥发问题，是 **HClO 分解失效**；氯水才是既防挥发（Cl₂ 逸出）又防分解。错因是两类试剂的失效机理混为一谈。

## 与其他知识的联系

先修：氯气的性质（M1-T2-KP12）——HClO 从氯水成分中来，"氯气+碱"母版是漂白粉制备的模板；氧化还原方程式的配平与规律（M1-T2-KP08）——分解反应的价态分析。

后继：Na₂O₂ 的漂白（M1-T2-KP10）与本篇同属"强氧化性漂白"家族；离子反应（M1-T2-KP04）的"沉淀推动反应方向"在本篇的 CaCO₃↓ 处再现；选择性必修的电化学与消毒化学把 HClO 的氧化性定量化（高中后续学习）。
