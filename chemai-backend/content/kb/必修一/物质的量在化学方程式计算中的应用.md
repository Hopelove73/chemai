# 物质的量在化学方程式计算中的应用

> 一句话定位：本篇把物质的量四条换算腿拧成一股——以 n 为桥梁的方程式计算、过量判断与多步反应守恒，是必修一计算的收官篇。

## 是什么

**核心方法：把一切已知量先换成 n，按方程式系数比列比例，再把 n 换回要求的量**。方程式系数比 = 微粒数比 = **物质的量之比**（同一反应中气体还=体积比）。

三条换算腿（M1-T2-KP14/15/16）：n = m/M、n = V/Vm（标况气体）、n = cV（溶液）。

**过量判断**：两反应物都给了量 → 先算谁的 n 按系数比"更少"（不足量），**以不足量为基准**计算。口诀：**谁少按谁算**。

**多步反应守恒法**：连续反应不必步步列式——**抓住关键元素（或电子）的守恒关系一步到位**。如 CO₂ 全程被 Na₂O₂ 吸收：2Na₂O₂ ~ O₂ 与 C 守恒连用。

## 为什么这样

为什么系数比就是物质的量比？方程式的本质是微粒个数比（2 个 Na₂O₂ 对 1 个 O₂），而 1 mol 就是打包好的 N_A 个微粒——**打包单位换成 mol，比例不变**。这就是物质的量作为"计算通用货币"的意义：质量、气体体积、溶液浓度三条腿先归一到 n，系数比直接用，算完再换回去。

为什么必须"谁少按谁算"？产物量由**先耗尽**的反应物决定——足量那边还有剩余，多余的量不参与反应。拿足量一方做基准会把产物算多。经典陷阱：标况 22.4 L H₂ 与 1 mol Cl₂ 反应，H₂ 1 mol、Cl₂ 1 mol 恰好完全（1:1）；若 H₂ 给 2 mol，则 Cl₂ 不足，HCl 只能按 Cl₂ 算。

## 典型例子与方程式

**2.6 g Zn 与 100 mL 2 mol/L 盐酸反应，放 H₂ 多少升（标况）？** n(Zn)=0.04，n(HCl)=0.2；系数比 Zn:HCl:H₂=1:2:1 → HCl 最多支持 0.1 mol Zn > 0.04 → **Zn 不足，按 Zn 算**：n(H₂)=0.04 mol，V=0.896 L。它演示"过量判断三步：换 n → 比系数 → 按不足"。

**2.6 g Na₂O₂ 投入足量水，放 O₂ 多少（标况）？** n(Na₂O₂)=2.6/78=1/30 mol；系数 2Na₂O₂~O₂ → n(O₂)=1/60 mol，V≈0.37 L。它演示"关系式"直接从系数比拿比例，不必写完整过程。

**多步守恒**：足量 Na₂O₂ 分别与 0.1 mol CO₂、0.1 mol H₂O(g) 完全反应，共放 O₂ 0.1 mol——两种反应 2Na₂O₂~O₂ 系数关系相同，n(O₂)=n(原料)/2 相加即可。它说明守恒/关系式把多步合成一步。

## 常见易错点

- **"给两个量就相加或任选其一"**：错。必须**先比系数定不足**。错因是跳过判断直接拿第一个已知量算。
- **"溶液体积当溶剂体积用"**：n(HCl)=cV 里的 V 是**盐酸溶液**的体积（M1-T2-KP16 铁律）。错因是见数就用。
- **"22.4 L 忘了查标况与气态"**：非标况、或标况下非气态（SO₃ 固态、水液态），n=V/22.4 一律非法。错因是四条腿里这条腿条件最多。
- **"多步计算步步为营算错系数"**：会算但繁，且中途舍入误差累积。**守恒/关系式**是正解。错因是不知道"中间量可以跳过"。
- **"单位不统一就列比例"**：mL 与 L、g 与 kg 混用直接错。计算前**统一单位**是硬纪律。错因是心算跳步。
