# 铁单质

> 一句话定位：本篇是变价金属的代表样本——铁与不同强度氧化剂反应生成不同价态产物，"强氧化剂到高价、弱氧化剂到低价"在此立规。

## 是什么

纯铁是银白色金属（粉末黑色），有铁磁性、可导热导电，熔点较高。化学性质：**中等活泼金属**，比 Na/Mg/Al 弱、比 Cu 强。

与氧化剂反应按强弱分两档：

- **弱氧化剂**（S、H⁺、CuSO₄ 溶液等）→ 生成 **+2 价**（Fe²⁺）：与盐酸、稀硫酸反应生成亚铁盐和 H₂；
- **强氧化剂**（Cl₂、Br₂、HNO₃ 等）→ 生成 **+3 价**（Fe³⁺）：与 Cl₂ 点燃生成棕褐色烟 FeCl₃。

**与水蒸气**（教材实验：灼热的铁与水蒸气在高温下反应）：生成 Fe₃O₄（其中既有 +2 又有 +3 价，可看作 FeO·Fe₂O₃）和 H₂——铁在**高温下也不与液态水反应**，只与水蒸气反应。

**常温钝化**：遇冷浓硫酸、浓硝酸表面生成致密氧化膜，阻止反应继续——所以可用铁（铝）容器**冷**储运浓硫酸。

## 为什么这样

为什么氧化剂强弱决定价态？Fe²⁺ 与 Fe³⁺ 的区别是第二个电子的失去——弱氧化剂（如 H⁺）只够夺走最外层的第一个电子（到 +2），强氧化剂（如 Cl₂）能连第二关一起攻破（到 +3）。**产物价态是氧化剂强弱的标尺**——反过来，看到产物价态就能比较氧化剂强弱。

为什么与水蒸气反应需要高温而钠与冷水就剧烈？金属活泼性差距：Na 失电子极易（常温即可从水中夺 H⁺），Fe 失电子较难，需要高温破坏结构、提供能量。金属活动性顺序表（M1-T2-KP07）就是这条"反应剧烈程度 ladder"的总结。

钝化为什么是"保护"而不是"腐蚀"？致密氧化膜（Fe₃O₄ 薄层）**紧密覆盖表面**，把内部金属与氧化剂隔开——与疏松的 rust 不同。这也解释了为什么冷浓硫酸可用铁罐运输、一旦稀释反而危险（膜被破坏）。

## 典型例子与方程式

**3Fe + 4H₂O(g) --高温--> Fe₃O₄ + 4H₂**：教材实验（湿棉花提供水蒸气、铁粉高温）。它说明两点：铁与水反应的产物是 Fe₃O₄ 而非 FeO/Fe₂O₃；产物中的 H₂ 用点燃或肥皂泡检验。

**Fe + 2HCl = FeCl₂ + H₂↑**：与稀酸生成**浅绿色** FeCl₂ 溶液。它说明 H⁺ 是弱氧化剂，只能把铁氧化到 +2——与氯气生成 FeCl₃ 对比记忆。

**Fe + CuSO₄ = FeSO₄ + Cu**：湿法炼铜的原理（初中已学）。它说明铁作还原剂置换不活泼金属——"铁器时代能取代铜器时代"的化学解释。

## 常见易错点

- **"Fe 与 Cl₂ 反应生成 FeCl₂"**：错。Cl₂ 强氧化，产物 **FeCl₃**（棕褐色烟）；FeCl₂ 只在与弱氧化剂（盐酸、稀硫酸、CuSO₄）反应时出现。错因是套用与酸反应的经验。
- **"铁与冷水/热水反应"**：不反应。铁只与**水蒸气**在高温下反应。错因是把钠的行为平移到铁。
- **"Fe₃O₄ 中铁是 +2 价"或"+3 价"**：都不对。Fe₃O₄ 可看作 FeO·Fe₂O₃，铁**既有 +2 又有 +3**（1 个 +2、2 个 +3）。错因是习惯性写单一价态。
- **"铁能和冷的浓硫酸反应"**：常温**钝化**不反应；加热才反应。错因是忘了"冷"这个条件限定。
