# 离子反应

> 一句话定位：本篇是电解质在水溶液中行为的"动力学"——电解质（M1-T2-KP03）解决"谁会变成离子"，本篇解决"离子之间怎么反应"，离子方程式（M1-T2-KP05）解决"怎么写下来"。

## 是什么

电解质在水溶液中电离出离子，反应物混合时若离子之间发生作用使某些离子**数目减少**，就叫**离子反应**。

发生的条件（与复分解反应条件一致，但视角从"物质"换成了"离子"）：

1. **生成沉淀**：Ag⁺ 与 Cl⁻ 结合成 AgCl；
2. **生成气体**：H⁺ 与 CO₃²⁻ 结合成 H₂O 和 CO₂↑；
3. **生成弱电解质**：H⁺ 与 OH⁻ 结合成难电离的水。

三类条件的共同本质是：**某些离子的浓度下降**。溶液中离子"escaping"出反应体系（沉下去、飞出去、被束缚住），反应就往这个方向进行。

离子反应不限于复分解：溶液中的氧化还原反应（如 Fe 与 CuSO₄ 溶液）同样是离子反应——条件是"发生电子转移"。本篇先掌握复分解型，氧化还原型在学完氧化还原反应（M1-T2-KP06）后补全。

## 为什么这样

为什么换个视角重要？因为**电解质溶液中的反应根本不是"物质对物质"，而是"离子对离子"**。把 NaOH 溶液与盐酸混合，Na⁺、Cl⁻ 前后没变，真正反应的只有 OH⁻ 和 H⁺——按化学方程式写四种物质，反而把没参与反应的"旁观离子"写进了主角位。

这个视角立刻带来两个实用判断：**换无关电解质反应实质不变**（KOH 代替 NaOH、硝酸代替盐酸，实质仍是 H⁺ + OH⁻ = H₂O）；**离子浓度下降的方向就是反应方向**（判断溶液中离子能否大量共存的第一依据，见 M1-T2-KP23）。

## 典型例子与方程式

**NaOH + HCl = NaCl + H₂O，实质 H⁺ + OH⁻ = H₂O**：中和反应的"实质式"。它说明化学方程式会随着改用 KOH、KNO₃ 而变，离子方程式只有一个——这正是"实质"的含义。

**Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑，实质 CO₃²⁻ + 2H⁺ = H₂O + CO₂↑**：生成气体的离子反应。它说明离子方程式不仅要配平原子，**两边电荷也要守恒**（左 −2+2=0，右 0）——电荷守恒是离子方程式独有的检查项。

## 常见易错点

- **"离子反应的实质是复分解反应"**：反了。离子反应的**条件**借用了复分解的三个条件，但离子反应还包括溶液中的氧化还原型（如 Zn + 2H⁺ = Zn²⁺ + H₂↑）。错因是把"初学阶段见到的样本"当成了全集。
- **"易溶易电离的物质写离子，难溶的写化学式"记反了方向**：离子方程式的拆写原则是"**强电解质拆**（易溶的强酸、强碱、可溶盐），沉淀、气体、弱电解质、非电解质保留化学式"——例如石灰乳中的 Ca(OH)₂ 写化学式，澄清石灰水中的写 OH⁻。错因是只背了"拆"字没背"谁不拆"。
- **"两种电解质溶液混合就一定发生离子反应"**：错。NaCl 溶液与 KNO₃ 溶液混合，四种离子谁也不满足三个条件中的任何一条，不反应——这正是"大量共存"的情形。错因是把"混合"当成了"反应"。
- **"离子方程式两边电荷可以不守恒，只要原子守恒"**：错。电荷守恒是离子方程式的**硬约束**，CO₃²⁻ + H⁺ = H₂O + CO₂↑ 这类"看着像回事"的写法就是败在电荷（−2+1 ≠ 0）。错因是沿用化学方程式的检查习惯。

## 与其他知识的联系

先修：电解质与非电解质（M1-T2-KP03）——先知道谁电离出什么离子，才谈得上离子之间的反应。
