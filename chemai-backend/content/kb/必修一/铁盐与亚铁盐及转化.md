# 铁盐与亚铁盐及转化

> 一句话定位：本篇是第二章的核心网络——Fe²⁺ 与 Fe³⁺ 的相互转化（"铁三角"），检验方法与保存方法全部从氧化还原推出，是氧化还原知识的最大应用场景。

## 是什么

**Fe³⁺ 与 Fe²⁺ 的检验**（考试必考）：

| 离子 | 颜色 | 检验方法 |
|---|---|---|
| Fe³⁺ | 黄色 | 滴 KSCN 溶液 → **变红色**；或滴 NaOH → 红褐色沉淀 |
| Fe²⁺ | 浅绿色 | 先滴 KSCN **不变色**，再加氯水 → 变红色 |

**转化网络（铁三角）**：

- Fe²⁺ → Fe³⁺：加**强氧化剂**（Cl₂、HNO₃、H₂O₂）；
- Fe³⁺ → Fe²⁺：加**还原剂**（Fe、Cu、KI）；
- 最经典的两个方向各有一条"专属方程式"：**2FeCl₃ + Fe = 3FeCl₂**（加铁保亚铁）与 **2FeCl₂ + Cl₂ = 2FeCl₃**（通氯升铁）。

**保存与配制**：FeCl₂ 溶液保存加**少量铁粉**（防止被 O₂ 氧化：多余的 Fe 把混入的 Fe³⁺ 拉回 Fe²⁺）；FeCl₃ 溶液保存加**少量盐酸**（抑制水解，水解机理后续学习）。

## 为什么这样

为什么 KSCN 法要"先不变色、再加氯水变红"？这是**两步串联检验 Fe²⁺**的设计：第一步 KSCN 不变色证明原溶液**没有 Fe³⁺**；第二步加氯水（强氧化剂）把 Fe²⁺ 氧化成 Fe³⁺、遇 KSCN 变红——证明原溶液**有 Fe²⁺**。只做第二步无法区分"本来就是 Fe³⁺"和"Fe²⁺ 被氧化出来的 Fe³⁺"。设计的严谨性全在排除干扰。

为什么加铁粉能"保亚铁"？2FeCl₃ + Fe = 3FeCl₂：即使部分 Fe²⁺ 被 O₂ 氧化成了 Fe³⁺，铁粉立即把它还原回来——铁粉是**自愈式抗氧化剂**。同理 FeCl₃ 溶液中加铁会褪黄。

## 典型例子与方程式

**2FeCl₃ + Fe = 3FeCl₂**：铁三角"降"方向。它说明 Fe³⁺ 作氧化剂、Fe 作还原剂、产物同归 Fe²⁺——价态"向中间归中"（M1-T2-KP08 规律的应用）。

**2FeCl₂ + Cl₂ = 2FeCl₃**：铁三角"升"方向。它说明 Cl₂ 能把 Fe²⁺ 推到最高价——所以含 Fe²⁺ 的溶液**不能接触氯气环境**。

**2FeCl₃ + Cu = 2FeCl₂ + CuCl₂**：湿法蚀刻电路板的原理（Fe³⁺ 腐蚀铜）。它说明 Fe³⁺ 的氧化性强于 Cu²⁺——工业应用直接出自这条性质。

**Fe³⁺ + 3SCN⁻ = Fe(SCN)₃**：红色络合物（不是沉淀）。它说明 KSCN 检验的灵敏度来源——极少量的 Fe³⁺ 也能显色。

## 常见易错点

- **"Fe²⁺ 检验直接滴 KSCN 变红"**：错。变红只能证明 Fe³⁺；Fe²⁺ 的检验必须**两步**（先证明无 Fe³⁺，再氧化后变红）。错因是把 Fe³⁺ 的检验法照搬。
- **"FeCl₂ 溶液蒸干灼烧得无水 FeCl₂"**：错。蒸干过程中 Fe²⁺ 被氧化、且水解——最终主要得 Fe₂O₃ 和 FeCl₃。错因是忽略"溶液操作 ≠ 固体产物"。
- **"Fe 与足量 Cl₂/盐酸都生成 FeCl₃"**：与 Cl₂ 生成 FeCl₃（强氧化剂），与盐酸生成 **FeCl₂**（弱氧化剂 H⁺）。错因是忘了氧化剂强弱定价态。
- **"FeCl₃ 溶液保存在无色瓶中敞口即可"**：Fe³⁺ 相对稳定不惧 O₂，但要**加少量盐酸抑制水解**、避光保存；与 FeCl₂（加铁粉）的保存方法不同不能混。错因是两兄弟的保存方法背串。
