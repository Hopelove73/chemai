# 一定物质的量浓度溶液的配制

> 一句话定位：本篇是物质的量浓度（M1-T2-KP16）的实验落地——容量瓶定容法七步流程与误差分析，是全书实验考频最高的单点。

## 是什么

**仪器：容量瓶**——细颈梨形平底瓶，**只有一个刻度线**（标线），瓶身标有规格（如 500 mL）与使用温度（20 ℃）。它**只用来定容**，不能溶解、不能加热、不能长期存放、不能反应。

**七步流程**（以配 500 mL 0.1 mol/L Na₂CO₃ 溶液为例）：

1. **计算**：n = 0.1 × 0.5 = 0.05 mol，m = 0.05 × 106 = **5.3 g**；
2. **称量**：托盘天平（左物右码）；
3. **溶解**：烧杯中加适量蒸馏水搅拌溶解，**冷却至室温**（很多溶解过程热效应明显）；
4. **转移**：用**玻璃棒引流**入容量瓶（玻璃棒下端靠瓶内壁、上端靠烧杯嘴）；
5. **洗涤**：烧杯与玻璃棒**洗涤 2~3 次**，洗液全部转入容量瓶（溶质不残留）；
6. **定容**：加水至接近标线 1~2 cm 改用**胶头滴管**，**凹液面最低点与标线相切**；
7. **摇匀**：盖塞反复颠倒。

## 为什么这样

为什么每一步都不能省？误差分析的全部逻辑：**c = n/V，凡使 n 偏小或 V 偏大的操作都使 c 偏低**，反之偏高。逐条还原：

- 洗涤 2~3 次——烧杯壁残留溶质 → n 小 → c 偏低；
- 冷却至室温再转移——热溶液定容后冷缩，V 小 → c 偏高；且容量瓶是 20 ℃ 校准的；
- 定容俯视刻度线——视线俯视使实际液面**低于**标线 → V 小 → c 偏高；仰视相反；
- 摇匀后液面低于标线是**正常现象**（部分溶液挂在瓶塞与瓶颈）——**不能再加水**，加水则 V 大 → c 偏低。

常见追问：摇匀后液面低于标线，需要再加水吗？**不需要**——挂液是正常现象，再加水等于定容过头，c 偏低；下次用量直接从标线读，不受这次液面影响。

误差分析的统一公式记忆法：所有操作归到"n 怎么变、V 怎么变"两个问号上，不用背结论表。

## 典型例子与方程式

**俯视定容**：视线从上向下，视线—标线—液面三点关系决定实际加水量**不足**（液面低于标线才"看起来"相切）→ V 小 → c 偏高。它说明误差分析必须画光路图而不是背"俯高仰低"——仰视时方向正好相反，背反了全错。

**用 NaOH 配制**：NaOH **不能在纸上称量**（易潮解且腐蚀纸张/天平）——小烧杯中快速称量；且溶解放热明显，**必须冷却后转移**。它说明流程纪律在特殊溶质面前要"性质决定操作"。

## 常见易错点

- **"容量瓶可以溶解药品"**：错。容量瓶只做定容——溶解常有热效应，影响容积精度甚至炸裂。溶解在烧杯、转移用玻璃棒。错因是嫌麻烦想一步到位。
- **"摇匀后液面低于标线，需再加水至标线"**：错。摇匀降面是瓶塞颈部挂液的正常现象，再加水 c 偏低。错因是把正常现象当操作失误。
- **"洗涤烧杯可以省"**：不能。不洗则溶质残留 → n 小 → c **偏低**。这是"偏低类"误差里考得最多的一条。
- **"俯视定容 c 偏低"**：反了。俯视 → 实际液面低于标线 → V 小 → **c 偏高**。错因是背结论不画图，仰视俯视背反。
- **"配制 500 mL 溶液选 1000 mL 容量瓶量两次"**：错。容量瓶**只有整规格**，要 500 mL 就选 500 mL 规格；一个容量瓶一种容积，不存在"量两次"的操作。错因是用烧杯思维套容量瓶。
