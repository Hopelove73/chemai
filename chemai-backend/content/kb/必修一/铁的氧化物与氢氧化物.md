# 铁的氧化物与氢氧化物

> 一句话定位：本篇盘点铁的"颜色家族"——三种氧化物、两种氢氧化物的颜色/与酸反应/转化，颜色是铁系鉴别的主线。

## 是什么

**三种氧化物**：

| | FeO | Fe₂O₃ | Fe₃O₄ |
|---|---|---|---|
| 俗称 | — | 铁红（颜料） | 磁性氧化铁 |
| 颜色 | 黑色粉末 | **红棕色** | 黑色晶体 |
| 铁价态 | +2 | +3 | +2 和 +3 |
| 与盐酸 | → FeCl₂ | → FeCl₃ | → FeCl₂ 和 FeCl₃ 混合 |

三者都不与水反应，都是与酸反应生成盐和水——FeO/Fe₂O₃ 是碱性氧化物，Fe₃O₄ 特殊（不是严格的碱性氧化物）。

**两种氢氧化物**：

- **Fe(OH)₂**：**白色**沉淀，极易被氧化——白色迅速变灰绿色、最终变**红褐色**；
- **Fe(OH)₃**：**红褐色**沉淀，受热分解为 Fe₂O₃ 和水。

**Fe(OH)₂ 的制备**是实验难点：用**不含 Fe³⁺** 的亚铁盐溶液 + 煮沸除氧的 NaOH 溶液，滴管**插入液面以下**挤出——全流程防氧化，才能看到白色沉淀。

## 为什么这样

Fe(OH)₂ 为什么"白变灰绿最后红褐"？Fe(OH)₂ 极易与空气中 O₂ 和 H₂O 反应生成 Fe(OH)₃——白（未氧化）→ 灰绿（混合态）→ 红褐（完全氧化）。这个颜色序列本身就是"Fe²⁺ 被氧化为 Fe³⁺"的**可视化证据**，也是实验题最爱考的现象描述。

Fe(OH)₂ 制备为什么要全流程防氧？O₂ 会把 Fe(OH)₂ 氧化——任何一个环节带入 O₂（溶液中溶解的 O₂、滴管带出的空气），白色就瞬间变色，"制备出白色沉淀"的实验目的就失败了。**防氧三招：煮沸除氧、液面下滴加、胶头滴管尖嘴油封（可选）**。

Fe(OH)₃ 为什么受热分解？不溶性碱受热分解是通性：2Fe(OH)₃ --Δ--> Fe₂O₃ + 3H₂O——红褐色固体变为红棕色粉末。

## 典型例子与方程式

**Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O**：铁红与盐酸。它说明 +3 价铁的氧化物与酸反应得到 Fe³⁺ 盐——除锈反应的原理（铁锈主要成分 Fe₂O₃）。

**Fe²⁺ + 2OH⁻ = Fe(OH)₂↓**：白色沉淀的离子方程式。它说明制备的关键是"原料纯 + 防氧"——任何 Fe³⁺ 混入都会看到红褐色。

**4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃**：白色到红褐色的转化。它说明 O₂ 和 H₂O **共同**参与氧化——这也是这个方程式的配平难点（原子和电子双守恒）。

## 常见易错点

- **"Fe(OH)₂ 是红褐色沉淀"**：反了。Fe(OH)₂ **白色**、Fe(OH)₃ 才是红褐色。错因是只记住了实验的"终点颜色"。
- **"FeO 与盐酸反应生成 FeCl₃"**：错。FeO 中铁是 +2 价、没有变价，产物 **FeCl₂**。错因是"铁的化合物都是 +3"的错觉。
- **"Fe₃O₄ 与盐酸反应只生成一种铁盐"**：错。+2 和 +3 价共存，产物是 FeCl₂ 与 FeCl₃ 的**混合物**。错因是单一价态思维。
- **"制 Fe(OH)₂ 直接把 NaOH 溶液滴到液面上"**：错。液面以上全是空气，瞬间氧化；**滴管插入液面以下**是关键操作。错因是不知道氧化的快速性。
