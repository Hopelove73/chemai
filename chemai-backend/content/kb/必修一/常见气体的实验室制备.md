# 常见气体的实验室制备

> 一句话定位：本篇把 O₂/CO₂/Cl₂ 的制备统一成"发生装置—净化—收集—尾气"四件套，装置选择的依据只有两条：反应物状态与反应条件。

## 是什么

**发生装置三型**（看反应物状态与是否加热）：

| 类型 | 适用 | 代表 |
|---|---|---|
| 固+固加热型 | 加热固体混合物 | O₂（KMnO₄/KClO₃） |
| 固+液不加热型 | 块状固体+液体 | CO₂（大理石+稀盐酸）、H₂ |
| 固+液加热型 | 固体+液体且需加热 | **Cl₂（MnO₂+浓盐酸）** |

**收集两法**：排水法（不溶于水且不与水反应：O₂、H₂）；向上排空气法（密度比空气大：CO₂、Cl₂）；向下排空气法（密度小：H₂、NH₃）。

**净化与干燥**：制得的气体常带水蒸气/挥发酸——干燥剂选择：浓硫酸（酸性干燥剂，不能干燥碱性气体 NH₃）、碱石灰（碱性，不能干燥酸性气体）。

**尾气处理**：有毒气体（Cl₂）必须用 NaOH 溶液吸收，不能直排。

**Cl₂ 制备全流程**（必修一集大成）：MnO₂+浓盐酸加热 → 饱和食盐水（除 HCl）→ 浓硫酸（除水）→ **向上排空气**收集 → NaOH 溶液吸收尾气。

## 为什么这样

装置选择的本质是**反应物性质 + 生成物性质**两条线的决策：

发生装置看"状态+条件"——MnO₂ 是固体、浓盐酸是液体且需要加热，所以选固液加热型（分液漏斗控酸量，圆底烧瓶加热）。

净化顺序"先除杂质后干燥"——若先干燥再过饱和食盐水，气体又带出水蒸气，干燥白做。

收集方法看"密度与溶解性"——Cl₂ 密度比空气大且能与水部分反应，所以向上排空气而**不**用排水法。

尾气处理的必要性——Cl₂ 有毒（M1-T2-KP12），直排违反实验室安全规范（M1-T1-KP02）；NaOH 能把 Cl₂ 拉进歧化反应（M1-T2-KP12）吸收干净。

## 典型例子与方程式

**MnO₂ + 4HCl(浓) --Δ--> MnCl₂ + Cl₂↑ + 2H₂O**：氯气制备。三个细节常考：必须**浓**盐酸（稀盐酸不反应——M1-T2-KP12 的"部分参与"规律）；必须**加热**；随温度升高 HCl 挥发加剧所以产物带 HCl 杂质。它说明"制备流程的每一步都能从方程式推出"。

**CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑**：CO₂ 制备。不用稀硫酸——生成的 CaSO₄ 微溶覆盖在大理石表面让反应停止。它说明"试剂选择要考虑产物副作用"。

**2KMnO₄ --Δ--> K₂MnO₄ + MnO₂ + O₂↑**：O₂ 制备（固固加热型），试管口塞棉花防 KMnO₄ 粉末进入导管。

## 常见易错点

- **"制 Cl₂ 用稀盐酸"**：错。MnO₂ 只氧化**浓**盐酸；稀盐酸的还原性不足。错因是只记方程式没记条件。
- **"Cl₂ 用排水法收集"**：错。Cl₂ 能溶于水（1:2）且与水反应——用向上排空气法或排**饱和食盐水**法（抑制溶解）。错因是忽略气体溶解性。
- **"温度计插进反应液里测 Cl₂ 制备温度"**：错。测的是**蒸气温度**才能控制馏分——插到液面下测的是釜液。错因是把蒸馏的温度计位置经验平移（此处位置在支管口/液面上方视具体装置）。
- **"尾气用水吸收"**：Cl₂ 溶解度有限且反应可逆——NaOH 溶液才能吸收完全。错因是低估了有毒气体的直排风险。
