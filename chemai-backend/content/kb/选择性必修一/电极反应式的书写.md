# 电极反应式的书写

> 一句话定位：把电极上发生的事写成带电子计数的半反应——得失电子守恒、原子守恒、电荷守恒三查，介质（酸/碱）用 H+、OH-、H2O 补齐。

## 是什么

**电极反应式**：电极上氧化或还原半反应的离子方程式，电子写在反应式一侧（失电子写"− ne-"，得电子写"+ ne-"）。

**书写步骤**：

1. 确定电极与反应物（负极：还原剂失电子；正极：氧化剂得电子）；
2. 写出主要产物与电子转移数；
3. 用介质配平：酸性介质用 **H+ 与 H2O**，碱性介质用 **OH- 与 H2O**，缺什么补什么；
4. 三查：电子守恒（得失相等）、原子守恒、电荷守恒。

**常见正极反应**（酸性与碱性介质对比）：

- 酸性：O2 + 4H+ + 4e- = 2H2O；2H+ + 2e- = H2↑
- 碱性/中性：O2 + 2H2O + 4e- = 4OH-

## 为什么这样

为什么介质要补 H+ 或 OH-？半反应必须在**实际溶液环境**中守恒：氢氧元素在电极反应前后往往不平衡，酸性溶液里只能用 H+/H2O 补（没有大量 OH-），碱性溶液里只能用 OH-/H2O 补（没有大量 H+）。**介质参与反应**是电化学与普通离子方程式的最大区别。

为什么电荷守恒是硬约束？电极反应式一侧带 ne- 电荷，另一侧离子电荷总和必须与之相等——Zn − 2e- = Zn2+：左边失去 2 个负电荷等价于 +2，右边 Zn2+ 也是 +2，闭合。

## 典型例子与方程式

**Zn - 2e- = Zn2+**：负极氧化。它说明电子写在减号侧；查电荷：右边 +2 = 左边失去 2e-。

**2H+ + 2e- = H2↑**：酸性介质的析氢正极。它说明 H+ 是反应物时写在左侧，产物气体标 ↑。

**O2 + 4H+ + 4e- = 2H2O**：酸性介质中的吸氧正极。它说明酸性环境用 H+ 配平氢、用 H2O 配平氧；四电子转移来自 O2 的 0 → −2。

**O2 + 2H2O + 4e- = 4OH-**：碱性/中性介质的吸氧正极。它说明同一反应在碱性下改用 H2O/OH- 配平；两条式子对比是考试高频。

## 常见易错点

- **"碱性介质中写 H+"**：错。碱性溶液无大量 H+，用 OH-/H2O 配平；酸性反之。
- **"电子写在一侧带正负号就完了，不用查电荷"**：错。三查缺一不可；电荷不守恒的式子等于没写。
- **"负极反应中电子写在右侧"**：错。失电子写"− ne-"（左侧减去电子）；得电子写"+ ne-"。
- **"燃料电池正极都是 O2 + 2H2O + 4e- = 4OH-"**：不严谨。介质决定写法：酸性用 H+，熔融碳酸盐用 CO3^2-，固体氧化物用 O^2-。

## 与其他知识的联系

先修：原电池的工作原理（M3-T1-KP05）提供两极分工；氧化还原反应（M1-T2-KP06）提供电子转移与守恒框架。

后继：化学电源（M3-T1-KP07）与电解的应用（M3-T1-KP09）都要求先写对电极反应式；金属的腐蚀与防护（M3-T1-KP10）的吸氧腐蚀就是这个正极反应。
