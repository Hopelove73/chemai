# 化学平衡的移动

> 一句话定位：平衡是"动中的定"——条件一变 Qc 偏离 K，体系就朝削弱改变的方向重建平衡，这就是勒夏特列原理。

## 是什么

**化学平衡的移动**：条件改变使原平衡被破坏（Qc ≠ K），体系在新条件下重新建立平衡的过程。

**勒夏特列原理**：改变影响平衡的一个条件，平衡就向**能够减弱这种改变**的方向移动。

| 条件改变 | 移动方向 | 备注 |
|---|---|---|
| 增大反应物浓度 | 正向 | 消耗掉部分加入量（不能完全抵消） |
| 增大压强（压缩） | 向气体分子数**减小**的方向 | 分子数不变的反应不移动 |
| 升高温度 | 向**吸热**方向 | 升温同时改变 K |
| 催化剂 | 不移动 | 同倍加快正逆，Qc 仍等于 K |

**v-t 图读法**：条件改变瞬间，某一侧速率跳变、另一侧不变（或同倍变化），两条线重新相交即新平衡。

## 为什么这样

为什么"减弱而不能抵消"？增大反应物浓度瞬间 Qc < K，反应正向进行消耗加入物——但新平衡时该物质浓度仍比原平衡**高**，只是没有加进来的那么多。移动的本质是"部分削弱"，这决定了"新平衡浓度比较"类题的答案。

为什么只有温度改变 K？浓度、压强只改变 Qc 使体系偏离平衡（分子还在、K 未变）；温度改变的是反应本身的"倾向"（放热反应升温 K 减小、吸热反应升温 K 增大）。所以**升降温是唯一能改变 K 的条件**——也是图像题判断吸放热的依据。

**2NO2 ⇌ N2O4** 是颜色判移动的经典体系：NO2 红棕色、N2O4 无色，加压颜色先深后浅（最终仍比原来深——弱化而非抵消）。

## 典型例子与方程式

**N2(g) + 3H2(g) ⇌ 2NH3(g)  ΔH < 0**：加压正向（分子数 4→2）、升温逆向（放热反应）。它说明合成氨的两个条件矛盾（高压利平衡、高温利速率），工业取折中。

**2NO2(g) ⇌ N2O4(g)  ΔH < 0**：热水中红棕色加深（升温向吸热的逆方向移动），冰水中变浅。它说明颜色变化是判断温度移动方向的直观实验。

**恒容充入惰性气体**：各组分浓度不变 → Qc 不变 → **不移动**。它说明压强影响的实质是浓度影响——总压变了但"分压"没变。

## 常见易错点

- **"增大压强平衡正向移动"**：错。必须看气体分子数哪边小；分子数不变（如 H2 + I2 ⇌ 2HI）加压不移动。
- **"升温总是加快正反应"**：错。升温同倍加快正**和**逆；"移动"是因为逆（吸热侧）加快得更多。
- **"移动可以完全抵消条件的改变"**：错。只能减弱；新平衡时加入物浓度仍高于原平衡。
- **"恒容充惰性气体平衡移动"**：错。各组分浓度不变，不移动；恒**压**充惰性气体相当于稀释，平衡向分子数增大的方向移动。
- **"催化剂移动平衡"**：错。同倍加快正逆，Qc = K 依旧，不移动。
