# 化学平衡状态

> 一句话定位：把必修二"逆等动定"升级为一套可操作的判断术——本质标志是"正逆速率相等"，等价标志是"变量不再变"。

## 是什么

**化学平衡状态**：可逆反应在一定条件下，正反应速率与逆反应速率相等，各组分浓度保持不变的状态。

**判断标志**分两类：

1. **本质标志**（直接证明 v正 = v逆）：同一物质的消耗速率与生成速率之比等于系数比（如 v消耗(N2) = v生成(N2)；v消耗(N2)∶v生成(H2) = 1∶3 也行）；组分的"断裂键数 = 生成键数"；
2. **等价标志**（变量不变才是平衡）：各组分浓度、百分含量、颜色不再变化；**恒容恒温下总压强不再变**（仅当反应前后气体分子数不等时）；**密度不再变**（仅当恒容 + 有非气体组分或总质量变时）；平均相对分子质量不再变（同样有条件）。

**关键区别**：如果某个量**本来就是恒量**（如 H2 + I2 ⇌ 2HI 反应前后气体分子数相等，恒容总压始终不变），它"不再变"**不能**作为平衡标志。

## 为什么这样

为什么"本质标志"最可靠？v正 = v逆 是平衡的定义本身，无论什么反应都成立。等价标志则要从"变量"出发：只有随反应进行**一直在变**的量，"停止变化"才能说明反应到达限度；天生不变的量没有信息量——这就是判断题的全部逻辑：先问"这个量变不变"，再问"不变了吗"。

为什么 v消耗 = v生成 要按系数比？随便说"v消耗(N2) = v生成(H2)"没有意义——不同物质的速率本来就差系数倍；只有折算到**同一物质**（或按系数比配平）的相等才是 v正 = v逆。

## 典型例子与方程式

**N2 + 3H2 ⇌ 2NH3**（气体分子数减小的反应）：恒容恒温下，总压强随反应进行减小——**压强不再变 = 平衡**。它说明"变量不变"是有效标志。

**H2(g) + I2(g) ⇌ 2HI(g)**（气体分子数不变的反应）：恒容总压始终不变——压强"不变"**不能**判断平衡；但碘蒸气的颜色不再变化可以判断。它说明标志必须逐反应甄别。

**本质标志示例**：v消耗(N2) = v生成(N2)（同一物质双向速率相等）——它说明这是定义本身，永远是可靠标志。

## 常见易错点

- **"各组分浓度相等就是平衡"**：错。平衡时浓度**不变**而非**相等**；比例由初始投料与限度决定。
- **"v正 = v逆 就是数值上相等"**：错。必须折算到同一物质或按系数比换算后再比。
- **"密度不变即平衡"**：不严谨。恒容 + 全气相反应，总质量与体积都不变，密度恒是恒量，不能作标志；有固体参与或恒压体系才行。
- **"反应达到平衡后停止"**：错。动态平衡，正逆反应仍在进行，只是速率相等。
- **"催化剂使平衡移动"**：错。催化剂同倍加快正逆，缩短到达平衡的时间，不改变平衡状态本身。
