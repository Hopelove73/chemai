# 水的电离与水的离子积

> 一句话定位：水自己也是弱电解质——Kw 是水溶液世界的"交通规则"，酸碱抑制水的电离、水解盐促进它。

## 是什么

水是极弱的电解质：**H2O ⇌ H+ + OH-**。

**水的离子积**：一定温度下，**任何**稀水溶液中 c(H+)·c(OH-) = **Kw**。25 ℃ 时 Kw = 1×10⁻¹⁴（纯水中 c(H+) = c(OH-) = 1×10⁻⁷ mol/L）。

**对水电离的影响**：

- **加酸、加碱 → 抑制**：c(H+) 或 c(OH-) 增大，水的电离平衡逆移——但 Kw 不变（温度没变）；
- **水解盐（如 NH4Cl、Na2CO3）→ 促进**：离子"消耗"水电离的 H+ 或 OH-，拉动平衡正移；
- **升温 → 促进**：电离吸热，Kw 随温度升高增大（100 ℃ 时 Kw ≈ 1×10⁻¹²，纯水仍中性但 c(H+) = 10⁻⁶）。

**中性 ≠ pH = 7**：中性指 c(H+) = c(OH-)；只有 25 ℃ 时才恰好 pH = 7。

## 为什么这样

为什么酸碱抑制而水解盐促进？加酸直接给 H+（Qc 变大 → 逆移，水自己的电离被压回去）；水解盐的离子把水电离出的 H+（或 OH-）**抓走**（生成弱电解质），Qc 变小 → 正移——水被迫多电离。抑制剂与促进剂的差别在于：外来离子是"添堵"还是"抽水"。

为什么 Kw 与溶液酸碱性无关？Kw 是水电离平衡的平衡常数，只与温度有关——不管溶液里加了多少酸碱，c(H+) 与 c(OH-) 的乘积恒等于该温度下的 Kw。酸碱改变的只是"分配比例"（一方大另一方就小）。

## 典型例子与方程式

**Kw = c(H+)·c(OH-) = 1×10^-14（25 ℃）**：万能换算器。它说明知道 c(H+) 就知道 c(OH-)——0.1 mol/L 盐酸中 c(OH-) = 10⁻¹³ mol/L，不是 0（酸里也有水电离的 OH-）。

**100 ℃ 纯水 c(H+) = 10^-6 mol/L**：Kw 增大到 10⁻¹²。它说明升温促进水的电离；此时纯水 pH = 6 但仍中性（c(H+) = c(OH-)）。

**酸碱抑制对比**：0.1 mol/L 盐酸中水的电离程度 = c(OH-)（全部来自水）= 10⁻¹³，比纯水的 10⁻⁷ 小 10⁶ 倍。它说明"抑制"可以定量表达——用对方离子的浓度充当"水电离贡献"的度量。

## 常见易错点

- **"酸溶液中 OH- 浓度为 0"**：错。水电离永不停；c(OH-) = Kw/c(H+)，只是很小。
- **"pH = 7 一定是中性"**：错。中性是 c(H+) = c(OH-)；100 ℃ 中性是 pH = 6。先看温度再谈中性。
- **"水解盐降低水的电离程度"**：反了。水解促进水的电离（这是"促进"类唯一的常客）；酸、碱是抑制类。
- **"Kw 随浓度变化"**：错。Kw 只随温度变；升温 Kw 增大（电离吸热）。
