# 盖斯定律与反应热的计算

> 一句话定位：反应热只看始末态、不管路径——方程式能加减，ΔH 就同步加减，这是求"测不出来的反应热"的唯一通用办法。

## 是什么

**盖斯定律**：化学反应的反应热只与反应的**始态和终态**有关，与**途径**无关。

推论：若一个反应可以由其他几个反应**加减**得到，则其 ΔH 也按同样方式**加减**——方程式乘系数，ΔH 同乘；方程式相加，ΔH 相加；方程式相减，ΔH 相减；方程式倒过来写，ΔH 变号。

**解题套路**：目标反应 → 找含相同物质的已知反应 → 通过"某物质只在目标式一边出现"锁定加减关系 → 得目标式与 ΔH。

## 为什么这样

为什么与途径无关？能量是**状态函数**：山的高度差取决于起点和终点，不取决于你走缓坡还是陡坡。化学反应的 ΔH 同理——C 燃烧生成 CO2，可以一步完成，也可以先变成 CO 再继续燃烧，两条路径的总放热必然相等，否则就能"凭空制造能量"（造出第一类永动机），违反能量守恒。

为什么这条定律有用？有些反应热**无法直接测量**：C + 1/2O2 = CO 在实验中不可避免地伴生 CO2，测不到纯 CO 的生成热——盖斯定律用两步可测的反应把它间接算出来。

## 典型例子与方程式

**C(s) + O2(g) = CO2(g)  ΔH1 = -393.5 kJ/mol**：碳完全燃烧，可直接测。它说明这条路径的放热是"总账"。

**CO(g) + 1/2O2(g) = CO2(g)  ΔH3 = -283.0 kJ/mol**：CO 继续燃烧，可直接测。它说明第二步的放热可测。

**C(s) + 1/2O2(g) = CO(g)  ΔH2 = -110.5 kJ/mol**：目标反应 = 总反应 − 第二步（ΔH2 = ΔH1 − ΔH3）。它说明盖斯定律求出"测不出来"的 CO 生成热；验证 ΔH2 + ΔH3 = −393.5 kJ/mol 与 ΔH1 相等，两条路径闭合。

## 常见易错点

- **"方程式相加减时 ΔH 不用动"**：错。方程式怎么加减，ΔH 就怎么加减；方程式倒写，ΔH 变号。
- **"盖斯定律说明反应速率与路径无关"**：错。盖斯定律只讲能量（焓变）与途径无关；速率与路径（活化能）强相关。
- **"ΔH 数值大小直接比较放热多少"**：错。比较放热多少看 |ΔH|；ΔH = −571.6 kJ/mol 比 −285.8 kJ/mol 放热多（不是"小"）。
- **"中间物质随便消去"**：错。消去要求该物质在组合式中**系数与位置完全匹配**，否则先统一系数再加减。
