# 反应热与焓变

> 一句话定位：把必修二"断键吸热、成键放热"的定性结论升级为可计算的量——焓变 ΔH，放热为负、吸热为正，符号定错全盘皆错。

## 是什么

**反应热**：化学反应过程中吸收或放出的热量。恒压条件下，反应热等于**焓变（ΔH）**。

- **放热反应 ΔH < 0**（体系能量降低，如燃烧、中和）；
- **吸热反应 ΔH > 0**（体系能量升高，如大多数分解反应）；
- 单位：kJ/mol——"每 mol"指按所写方程式进行 1 mol 反应（系数是物质的量，可以是分数）。

**键能与焓变**：ΔH = 反应物键能总和 − 生成物键能总和（断键吸热、成键放热）。ΔH < 0 说明成键放出的能量多于断键吸收的能量。

## 为什么这样

为什么放热 ΔH 反而为负？ΔH = 生成物总能量 − 反应物总能量。生成物能量低时差值为负——放热反应"掉能量"，所以 ΔH < 0。这个符号约定是热力学的通用约定，与直觉（"放热"听起来是"正"）相反，必须死记。

为什么单位是 kJ/mol 而不是 kJ？同一个反应方程式可以写成不同系数：H2 + Cl2 = 2HCl 的 ΔH 是 −184.6 kJ/mol；写成 1/2H2 + 1/2Cl2 = HCl 时 ΔH 减半。"每 mol"锚定的是**方程式**而不是某一种物质——这就是为什么热化学方程式的系数与 ΔH 必须成对出现。

## 典型例子与方程式

**H2(g) + Cl2(g) = 2HCl(g)  ΔH = -184.6 kJ/mol**：H—H 键键能 436 kJ/mol、Cl—Cl 键 243 kJ/mol、H—Cl 键 431 kJ/mol。ΔH = (436 + 243) − 2×431 = −183 kJ/mol，与实测值一致。它说明键能计算与实验反应热互相印证；也说明"算准每个键、数对每个键"是焓变计算的基本功。

## 常见易错点

- **"放热反应 ΔH > 0"**：错。符号约定放热为负。错因是拿日常语言的"放"当正号。
- **"ΔH 的单位 kJ/mol 里 mol 指某种物质"**：错。指按方程式整体进行 1 mol 反应；方程式系数变了 ΔH 同步变。
- **"键能越大反应放热越多"**：错。放热多少取决于**反应物与生成物键能的差**，不是任何一侧的绝对值。错因是只看一半。
- **"吸热反应不需要加热就能判断错了"**：错。焓变是始末态能量差，与反应条件（是否加热）无关。
