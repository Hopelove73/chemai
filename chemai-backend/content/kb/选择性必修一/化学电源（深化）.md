# 化学电源（深化）

> 一句话定位：把原电池原理读进三类实用电池——铅蓄电池的充放电对称、燃料电池的连续供料、锂离子电池的嵌入化学，全部用"写电极反应式"打通。

## 是什么

**一次电池**：锌锰干电池，放电不可逆，用完即弃。
**二次电池**：可充放电。铅蓄电池、锂离子电池——放电是原电池，充电接外电源变电解池，反应逆向进行。
**燃料电池**：连续通入燃料（H2、CH4、CH3OH）与氧化剂（O2），电极本身不消耗，能量转化率高。

**铅蓄电池**：负极 Pb、正极 PbO2、电解液 H2SO4。放电时两极都生成 PbSO4，硫酸被消耗（密度下降）；充电时逆向进行，硫酸再生。**放电与充电互为逆反应**。

**氢氧燃料电池**：负极通 H2、正极通 O2；介质决定电极反应式写法（酸性 H+、碱性 OH-），总反应都是 2H2 + O2 = 2H2O。

## 为什么这样

铅蓄电池为什么放电时电解液密度下降？放电消耗 H2SO4 生成 PbSO4（固体）与水——硫酸浓度降低，密度变小。**测密度就能估判充放电状态**，这是铅蓄电池独有的"液位计"。

燃料电池为什么能量转化率高？不经过"燃烧→热→机械"的多级转化，化学能直接变电能，减少热损失；且电极不消耗、燃料随用随加，不受电池容量限制。

锂离子电池为什么轻？锂是最轻的金属元素，Li+ 在正负极间嵌入/脱出（摇椅式），能量密度远高于铅蓄电池。

## 典型例子与方程式

**Pb + PbO2 + 2H2SO4 = 2PbSO4 + 2H2O（放电）**：铅蓄电池总反应。它说明放电消耗硫酸、两极同变 PbSO4；充电时逆向写。

**Pb - 2e- + SO4^2- = PbSO4（放电负极）**：Pb 被氧化并与 SO4^2- 结合。它说明介质离子（SO4^2-）直接参与电极反应。

**PbO2 + 2e- + 4H+ + SO4^2- = PbSO4 + 2H2O（放电正极）**：PbO2 被还原。它说明酸性介质用 H+ 配平；两式相加正好是总反应。

**2H2 + O2 = 2H2O**：氢氧燃料电池总反应。它说明电极反应式随介质变、总反应不变——考题常给介质考写法。

## 常见易错点

- **"充电时化学能转化为电能"**：错。充电是电能→化学能（电解池过程）；放电才是化学能→电能。
- **"铅蓄电池放电时密度上升"**：反了。消耗硫酸生成水，密度下降；充电回升。
- **"燃料电池的电极材料参加反应"**：错。电极只作载体与催化剂，消耗的是外部供给的燃料与氧化剂。
- **"氢氧燃料电池在酸性介质下正极写 O2 + 2H2O + 4e- = 4OH-"**：错。那是碱性写法；酸性用 O2 + 4H+ + 4e- = 2H2O。
