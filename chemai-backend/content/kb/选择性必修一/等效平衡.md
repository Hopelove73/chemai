# 等效平衡

> 一句话定位：不同的起始投料，只要"折算归零"后完全相同（或成比例），就能到达同一个（或成比例的）平衡——判断标准只有恒温恒容与恒温恒压两条。

## 是什么

**等效平衡**：相同条件下，同一可逆反应从不同起始状态出发，达到**相同**（各组分含量完全相同）或**比例相同**（含量成比例）的平衡状态。

**判断两定律**：

1. **恒温恒容**：
   - 反应前后气体分子数**改变**：极限转化（把生成物按系数全部折回反应物）后**完全相同** → 全等平衡；
   - 反应前后气体分子数**不变**（如 H2 + I2 ⇌ 2HI）：极限转化后**成比例**即可（因为按比例缩放投料时各浓度同比变化，Qc 不变，平衡含量相同）；
2. **恒温恒压**：极限转化后**成比例**即可（恒压下按比例投料，体积同步缩放，浓度相同，是全等的平衡）。

**极限转化（归零法）**：把所有生成物按方程式系数**完全折算回反应物**，与参照投料比较。

## 为什么这样

为什么恒容 + 分子数变要求"完全相同"？这类反应的平衡组成由浓度**绝对值**决定（K 用浓度表达）；投料按比例缩放时浓度不同，Qc ≠ K 的偏离程度不同，平衡百分含量就不同。只有折算后一模一样，才是同一个平衡。

为什么分子数不变的反应放宽到"成比例"？这类反应加压不移动：投料整体乘以系数 k 时，若容器同步放大 k 倍则浓度不变；恒容下虽然浓度都变为 k 倍，但 Qc = (k·cC)(k·cD)/[(k·cA)(k·cB)] = Qc——分子分母的 k 约掉，平衡"浓度含量"不变。

为什么恒压放宽到"成比例"？恒压下投料按比例缩放，体积自动同步缩放，**浓度完全相同**——物理上就是同一个平衡。

## 典型例子与方程式

**N2(g) + 3H2(g) ⇌ 2NH3(g)**（分子数变）：恒温恒容，起始 1 mol N2 + 3 mol H2 与起始 0.5 mol N2 + 1.5 mol H2 + 1 mol NH3——后者归零（1 mol NH3 → 0.5 N2 + 1.5 H2）合计 1 mol N2 + 3 mol H2，**完全相同** → 全等平衡。它说明归零法是唯一的比较工具。

**H2(g) + I2(g) ⇌ 2HI(g)**（分子数不变）：恒温恒容，起始 1 mol H2 + 1 mol I2 与 2 mol H2 + 2 mol I2——成比例 → 各组分百分含量相同的等效平衡。它说明分子数不变型放宽一档。

**恒温恒压示例**：同上合成氨体系在恒温恒容下不等效的两组投料，改到恒温恒压下按比例投料即等效。它说明条件（恒容 vs 恒压）决定定律档位。

## 常见易错点

- **"等效平衡就是平衡浓度相等"**：错。可能是"含量（百分数/体积分数）相同"而浓度不同（分子数不变型恒容）；两种等效要分清。
- **"归零时把生成物折成分子而不是按系数折"**：错。必须按系数折回反应物（2NH3 → N2 + 3H2 是 1∶1∶2 的逆运算）。
- **"恒温恒压也要完全相同才等效"**：错。恒压只要求成比例。
- **"加催化剂能达到等效"**：错。催化剂不改变平衡组成；等效讨论的对象是不同投料。
