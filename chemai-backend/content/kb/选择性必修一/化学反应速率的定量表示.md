# 化学反应速率的定量表示

> 一句话定位：把"反应快慢"从定性比较升级为带单位的数——v = Δc/Δt，同一反应不同物质速率比等于系数比。

## 是什么

**化学反应速率**：单位时间内反应物浓度的减少或生成物浓度的增加，v = Δc/Δt，常用单位 mol/(L·s) 或 mol/(L·min)。

三条性质：

1. **平均速率**：计算的是一段时间内的平均值，不是瞬时值；
2. **一律取正值**：反应物浓度减少，取减小的量；不写负号；
3. **速率比 = 系数比**：同一反应中各物质的速率之比等于化学计量数之比（N2 + 3H2 ⇌ 2NH3 中 v(N2)∶v(H2)∶v(NH3) = 1∶3∶2）。

**速率的测定**：跟踪任一与浓度线性相关的可测性质随时间的变化——气体体积/压强、颜色深浅（分光光度法）、导电性等，最终都换算成浓度变化。

## 为什么这样

为什么速率比等于系数比？同一时间 Δt 内，各物质浓度的变化量之比等于方程式系数比（Δc = Δn/V，Δn 按系数生成与消耗）——这是方程式计量关系的直接体现，也是"用一种物质的速率换算另一种"的依据。

为什么是平均速率？反应过程中浓度不断变化，速率本身随时间改变（通常越来越慢）；在一段时间区间上只能定义平均值。瞬时速率要用微积分处理，高中不要求。

## 典型例子与方程式

**N2 + 3H2 ⇌ 2NH3**：若 2 s 内 c(N2) 从 2 mol/L 降到 1 mol/L，则 v(N2) = 0.5 mol/(L·s)，v(H2) = 1.5 mol/(L·s)，v(NH3) = 1 mol/(L·s)。它说明"用任一物质表示、按系数换算"是速率计算的全部技巧。

**速率测定示例**：测定 Zn 与稀硫酸反应的速率，量筒收集 H2，记录单位时间气体体积。它说明"可测性质 → 浓度变化"的换算思路；对照实验要求只有温度（或浓度）一个变量。

## 常见易错点

- **"速率可以是负值"**：错。一律取正值表示快慢；方向（消耗/生成）由物质角色表达。
- **"不同物质的速率数值可直接比大小"**：错。必须先换算成同一物质的等效速率（按系数比折算），否则系数不同会误判。
- **"速率单位 mol/L"**：错。是 mol/(L·s) 或 mol/(L·min)——单位里必须含时间。
- **"固体或纯液体的浓度可以改变速率"**：错。它们的"浓度"是常数；改变的是接触面积，不算浓度影响。
