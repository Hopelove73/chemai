# 化学平衡常数

> 一句话定位：平衡状态的定量身份证——K 只认温度，固体与纯液体不进表达式，Qc 与 K 比大小就能判断反应往哪走。

## 是什么

对可逆反应 mA(g) + nB(g) ⇌ pC(g) + qD(g)，在一定温度下达到平衡时：

**K = c^p(C) · c^q(D) / c^m(A) · c^n(B)**

三条性质：

1. **K 只与温度有关**：温度不变，K 不变；改变浓度、压强、催化剂都不改变 K；
2. **固体与纯液体浓度是常数**，不写入 K 的表达式；
3. **K 越大，反应正向进行得越彻底**（限度越大）。

**浓度商 Qc**：把任意时刻（未平衡）的浓度代入 K 的表达式所得的值。

- Qc < K → 反应正向进行；
- Qc = K → 已达平衡；
- Qc > K → 反应逆向进行。

## 为什么这样

为什么固体不写入 K？固体的"浓度"（密度）是常数，写进去也是常数，合并进 K 后表达式更简洁——所以约定直接不写。CaCO3 ⇌ CaO + CO2 的 K 就等于 c(CO2)。

为什么 K 只与温度有关？K 反映正逆反应"本性"（与活化能、焓变相联系的本征量）；浓度压强只是改变 Qc 让体系偏离平衡，最终 Qc 回到 K——拉动平衡但 K 值纹丝不动。

为什么 Qc 与 K 比较能判方向？平衡要求 Qc = K：Qc 小了说明产物"少得还没到账"，反应正向补足；Qc 大了反向消耗。这是勒夏特列原理的定量版本。

## 典型例子与方程式

**N2(g) + 3H2(g) ⇌ 2NH3(g)**：K = c²(NH3) / [c(N2) · c³(H2)]。它说明表达式由**生成物在上、反应物在下、系数作指数**——写错指数是最常见的失分点。

**CaCO3(s) ⇌ CaO(s) + CO2(g)**：K = c(CO2)。它说明固体不进表达式；恒温下 CO2 的平衡浓度是定值，与固体量多少无关。

**Qc 判据示例**：某温度下 K = 4，此刻 c(A) = c(B) = c(C) = c(D) = 1 mol/L 的反应 A + B ⇌ C + D，Qc = 1 < 4 → 正向进行。它说明 Qc 与 K 的比较是"任意时刻判方向"的通用方法。

## 常见易错点

- **"K 表达式写成系数在分子分母颠倒"**：错。生成物乘积在分子、反应物乘积在分母、系数为指数。
- **"加催化剂使 K 增大"**：错。K 只与温度有关；催化剂不改 K 也不改平衡组成。
- **"固体质量改变影响 K"**：错。固体不进表达式；只要固体还存在，K 与 c(CO2) 都不变。
- **"K 大的反应速率快"**：错。K 描述限度，速率由活化能决定，二者互不相干。
- **"稀水溶液反应把 c(H2O) 写进 K"**：错。稀溶液中水（溶剂）的浓度近似常数，不写入；K 常写作 c(C)·c(D)/c(A)·c(B) 省略水。
