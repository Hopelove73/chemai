# 电解的应用

> 一句话定位：电解原理的四大工业落点——氯碱、电镀、精炼、冶炼，外加一个通用的电化学计算（电量守恒）。

## 是什么

**氯碱工业**：电解饱和食盐水。阳极出 Cl2、阴极出 H2 与 NaOH（阴极区）。产物是烧碱、氯气、氢气三大化工原料。

**电镀**：待镀件作**阴极**，镀层金属作**阳极**，含镀层离子的溶液作电镀液。阳极溶解补充镀层离子，电解液浓度基本不变。

**电解精炼铜**：**粗铜作阳极**（溶解，Zn、Fe、Ni 等活泼杂质一同溶解成离子），**纯铜作阴极**（Cu2+ 析出；比铜活泼的杂质留在液中，不活泼的 Au、Ag 沉为阳极泥）。

**电冶炼**：电解熔融电解质制活泼金属。铝：电解熔融 Al2O3（加冰晶石降熔点）。

**电化学计算**：串联电路中各电极**得失电子数相等**——以电子为桥梁：n(e-) → n(产物)，跨池跨极统一算。

## 为什么这样

电镀时电解液浓度为什么不变？阳极溶解的镀层金属 = 阴极析出的镀层金属，两边收支平衡——这正是"用可溶性阳极"的设计目的。对比电解精炼：粗铜阳极中杂质也溶解，但只有 Cu2+ 在阴极优先析出，所以溶液中 Cu2+ 浓度缓慢下降、杂质离子累积，需定期净化。

为什么炼铝不用电解 AlCl3 溶液或熔融 AlCl3？水溶液中 H+ 先于 Al3+ 放电出 H2；AlCl3 是共价化合物，熔融不导电。所以必须电解熔融 Al2O3，并用冰晶石把 2050 ℃ 的熔点降到约 950 ℃。

## 典型例子与方程式

**2NaCl + 2H2O --电解--> 2NaOH + H2↑ + Cl2↑**：氯碱工业。它说明放电顺序下 Cl- 先于 OH-、H+ 先于 Na+；产物分区（阴区碱）要用隔膜防 Cl2 与 NaOH 反应。

**Cu2+ + 2e- = Cu（精炼阴极）** 与 **Cu - 2e- = Cu2+（精炼阳极）**：电解精炼铜的两极。它说明"粗溶解、纯析出"，阳极泥富集贵金属。

**2Al2O3(熔融) --电解、冰晶石--> 4Al + 3O2↑**：工业炼铝。它说明活泼金属只能电冶炼；阳极产生的 O2 会消耗石墨电极，需定期更换。

**电化学计算示例**：串联电解 CuSO4 与 AgNO3 溶液各 1 mol 金属析出时，两池通过电子数相同——Cu 需 2 mol e-，Ag 只需 1 mol e-，故析出 Ag 2 mol。它说明"以电子为桥梁"是电化学计算的统一方法。

## 常见易错点

- **"电镀时镀件作阳极"**：反了。镀件作**阴极**（要长上镀层），镀层金属作阳极。
- **"电解精炼铜时 Fe、Zn 也在阴极析出"**：错。Fe2+、Zn2+ 在 Cu2+ 之后放电，留在溶液中；阴极只出 Cu。
- **"电解熔融 AlCl3 制铝"**：错。AlCl3 熔融不导电；用熔融 Al2O3 加冰晶石。
- **"串联电路中各极析出物质的量相等"**：错。相等的是**电子数**；物质的量按电极反应的电子系数换算。
- **"氯碱工业不需要隔膜"**：错。Cl2 会与 NaOH 反应（歧化），必须用隔膜（离子交换膜）分区。
