# 酸碱中和滴定

> 一句话定位：用已知浓度"量"出未知浓度——滴定管读数、终点判断、误差分析三件事，核心是 c待测 = c标准·V标准/V待测。

## 是什么

**中和滴定**：用已知浓度的标准液滴加到待测液中，以指示剂变色判断**恰好完全反应**（终点），由消耗体积求待测浓度。

**仪器**：酸式滴定管（玻璃活塞，装酸/氧化性溶液）、碱式滴定管（橡胶管+玻璃珠，装碱）。刻度**上小下大**，读数到 0.01 mL。

**操作流程**：

1. 查漏、水洗、**润洗**（标准液润洗 2~3 次——不润洗会被残留水稀释）；
2. 装液、排气泡、调液面、记录初读数；
3. 锥形瓶装待测液（**只水洗、不润洗**——量是定量的）+ 指示剂；
4. 左手控活塞、右手摇瓶、眼睛看**锥形瓶内颜色**；
5. 终点：最后一滴使颜色变化且半分钟不恢复，记录终读数。

**计算**：c(待测) = c(标准)·V(标准)/V(待测)（一元对一元；多元按系数比）。

## 为什么这样

为什么标准液要润洗而锥形瓶不润洗？滴定管里若残留蒸馏水，装进去的标准液被稀释、浓度失真——必须润洗；锥形瓶里的待测液**物质的量**才是参与计算的量，瓶壁上的水只稀释不减少 n(H+)，滴定消耗的标准液体积不变——洗了反而多带试剂。

为什么读数到 0.01 mL？滴定管每大格 1 mL、每小格 0.1 mL，读数要**估读一位**——体积是四位数有效数字的计算才能保证浓度三位有效。

终点为什么看锥形瓶而不是滴定管？变色发生在瓶内溶液达到终点 pH 的瞬间——观察对象是"反应体系"，滴定管刻度只是计量工具。

## 典型例子与方程式

**c(待测) = c(标准)·V(标准)/V(待测)（一元酸碱）**：用 0.1000 mol/L NaOH 滴定 20.00 mL 未知盐酸，消耗 18.50 mL → c(HCl) = 0.0925 mol/L。它说明滴定计算本质就是 n(H+) = n(OH-)。

**HCl + NaOH = NaCl + H2O**：一元对一元的基准反应。它说明多元酸碱要乘系数（如用 NaOH 滴 H2SO4，n(NaOH) = 2n(H2SO4)）。

**终点现象（酚酞，碱滴酸）**：最后一滴 NaOH 使锥形瓶内溶液由无色变粉红且半分钟不褪。它说明"最后一滴 + 半分钟"是终点的标准表述——褪色说明未到，深红说明过量。

## 常见易错点

- **"滴定管用水洗后直接装液"**：错。残留水稀释标准液 → V(标准) 偏大 → 结果偏高；必须润洗。
- **"锥形瓶也要用待测液润洗"**：错。润洗增加 n(待测) → V(标准) 偏大 → 结果偏高。
- **"滴定管初读数仰视、终读数俯视"**：误差视具体方向而定——通用口诀是画图分析：读数误差 = 终 − 初，一仰一俯的组合会把 V 偏大或偏小，不能死记"偏高"。
- **"尖嘴有气泡，反应后消失"**：气泡体积被计入"消耗体积"但未进瓶 → V(标准) 虚大 → 结果偏高；装液后必须排气泡。
- **"指示剂加得越多越好"**：错。指示剂本身是弱酸弱碱，过量会消耗滴定剂且颜色失真；2~3 滴即可。
