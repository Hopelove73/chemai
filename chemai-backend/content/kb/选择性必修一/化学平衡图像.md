# 化学平衡图像

> 一句话定位：把速率与平衡的全部规律读成图——横纵坐标定体系、"先拐先平"定温压、走势定吸放热与分子数变化。

## 是什么

**三类高频图像**：

1. **v-t 图**（速率-时间）：条件改变瞬间谁跳变、往哪变，读出移动方向与原因；
2. **转化率（或含量）-温度/压强曲线**：不同温度或压强下的平衡转化率曲线族；
3. **速率（或转化率）-温度/压强双曲线族**："先拐先平数值大"定条件高低。

**读图三步法**：

1. **定轴**：横纵坐标是什么、单位是什么、是否恒容恒压；
2. **定特殊点**：起点、拐点（转折 = 平衡点）、平台（平衡后）；交点两侧谁是平衡态；
3. **定规律**：用"先拐先平"（曲线先转折 = 温度更高/压强更大/有催化剂 → 反应更快）与走势（升温转化率降 → 放热；加压转化率升 → 正向分子数减小）反推反应特征。

## 为什么这样

为什么"先拐先平数值大"？到达平衡的**时间短**（拐点来得早）意味着速率快——对温度曲线，先拐的是高温线；对压强曲线，先拐的是高压线；加了催化剂的线拐点最早但平衡位置不变（平台重合）。这是图像题反推条件的核心口诀。

为什么升温转化率下降能判断放热？升温平衡向吸热方向移动：转化率随温度下降 → 正向是放热方向 → ΔH < 0。图像把"温度对 K 的影响"画成了单调曲线——纵轴是转化率还是产物百分含量，逻辑相同。

为什么有的曲线断开跳变？条件改变瞬间速率突跳（温度或浓度突变），而转化率是累积量连续变化——v-t 图有跳变、转化率-时间图只有渐变，两类图不能混读。

## 典型例子与方程式

**N2(g) + 3H2(g) ⇌ 2NH3(g)  ΔH < 0**：转化率-温度曲线族中，高温线在下方且先拐。它说明"先拐先平"（高温快）与"高温转化率低"（放热反应）同时成立——两条信息一张图。

**A(g) + B(g) ⇌ C(g)  ΔH < 0** 的 v-t 图：t1 时刻缩小体积（加压），正逆速率同时跳升且正 > 逆（正向分子数减小）。它说明 v-t 图的跳变细节：两侧都变 = 温度/催化剂类条件；只变一侧 = 浓度类条件。

**催化剂线**：与原平衡线相比，拐点提前、平台完全重合。它说明催化剂只改时间不改限度——图像上"平台重合"是其签名。

## 常见易错点

- **"先拐先平的曲线对应的温度低"**：反了。先拐 = 快 = 温度更高（或压强更大/有催化剂）。
- **"转化率-时间图的平衡点也突然跳变"**：错。累积量连续；跳变只出现在速率类纵轴。
- **"曲线平台高低直接比 K 大小"**：跨图比较需小心。同一温度下平台高 = K 大；不同温度要结合移动方向判断 K 变化。
- **"图像题不用看坐标轴标签"**：错。横轴是温度还是时间、纵轴是转化率还是百分含量，读错轴全错。
