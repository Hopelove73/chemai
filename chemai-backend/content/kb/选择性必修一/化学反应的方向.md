# 化学反应的方向

> 一句话定位：光"放热"不够解释所有自发反应——还要看体系走向混乱（熵增）的倾向，复合判据 ΔH − TΔS 给出最终裁决。

## 是什么

**自发反应**：在一定条件下无需外力帮助就能自动进行的反应。

**两条自然倾向**：

1. **能量最低倾向（焓判据）**：体系倾向于从高能到低能——放热反应（ΔH < 0）多数自发；
2. **混乱度增大倾向（熵判据）**：体系倾向于从有序到无序——**熵（S）**是度量混乱度的状态函数，熵增（ΔS > 0）利于自发。

**复合判据**：ΔH − TΔS < 0 → 能自发；ΔH − TΔS > 0 → 不能自发；= 0 → 平衡状态。

- ΔH < 0 且 ΔS > 0：任何温度都自发；
- ΔH > 0 且 ΔS < 0：任何温度都不自发；
- ΔH < 0 且 ΔS < 0：低温自发、高温不自发；
- ΔH > 0 且 ΔS > 0：高温自发、低温不自发。

## 为什么这样

为什么吸热反应也能自发？NH4NO3 溶于水吸热却自发——因为固体晶格解体成自由离子的**熵增**非常大，熵的驱动足以补偿能量上升。"自发"不是"放热"的同义词，能量与混乱度是两股独立的力，温度 T 是它们之间的汇率：T 越高，熵项（TΔS）的权重越大——这解释了为什么低温与高温下同一反应的自发性可以相反。

为什么判据只讲"可能性"不讲"快慢"？ΔH − TΔS < 0 只说明反应有热力学驱动力；驱动力大的反应可能因活化能极高而速率极慢（如常温下氢氧混合气）。**方向与速率是两个维度**——热力学判据管"能不能"，动力学管"快不快"。

## 典型例子与方程式

**2Na(s) + Cl2(g) = 2NaCl(s)  ΔH < 0**：放热但熵减（气体变固体）——低温下焓项主导，自发。它说明放热反应大多自发，但"大多"不是"全部"。

**NH4NO3(s) = NH4+(aq) + NO3-(aq)  ΔH > 0（吸热但自发）**：熵增主导的自发过程。它说明熵判据独立于焓判据存在；冰融化、水蒸发同理。

**碳酸钙分解 CaCO3 = CaO + CO2（ΔH > 0、ΔS > 0）**：高温自发（煅烧石灰石需 900 ℃ 以上）、低温不自发。它说明"高温自发型"的 T 阈值由 ΔH/TΔS 的交点决定。

## 常见易错点

- **"放热反应一定自发，吸热一定不自发"**：错。熵项可以翻转结论；四象限里有两类是"看温度"的。
- **"自发反应一定快"**：错。方向判据与速率无关；自发而极慢的反应比比皆是。
- **"熵就是混乱度，混乱就是杂乱无章"**：不严谨。熵的统计意义是微观状态数（可能性的多少），"混乱度增大"是形象说法。
- **"非自发反应永远不能发生"**：错。借助外力（电解、持续加热耦合其他反应）可以实现；"自发"仅指无外力条件。
