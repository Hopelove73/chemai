# 沉淀溶解平衡与溶度积

> 一句话定位："难溶"不是"不溶"——沉淀与溶液里的离子之间有动态平衡，Ksp 只认温度，Qc 与 Ksp 比大小判生成或溶解。

## 是什么

**沉淀溶解平衡**：难溶电解质（如 AgCl）在水中少量溶解，溶解与沉淀速率相等的动态平衡：AgCl(s) ⇌ Ag⁺ + Cl⁻。

**溶度积 Ksp**：平衡时离子浓度幂的乘积（系数为指数），固体不写入：Ksp(AgCl) = c(Ag+)·c(Cl⁻)；Ksp(Fe(OH)3) = c(Fe³⁺)·c³(OH⁻)。

**离子积 Qc 与 Ksp 的比较**（判断铁三角）：

- Qc > Ksp：过饱和，析出沉淀；
- Qc = Ksp：饱和，平衡；
- Qc < Ksp：不饱和，沉淀可继续溶解。

**"难溶"的相对性**：Ksp 从 10⁻⁴（CaSO4）到 10⁻⁵⁰（Fe(OH)3 等）都叫难溶；绝对不溶的电解质不存在——"沉淀完全"也只是 Qc 降到 Ksp 以下、离子浓度 < 10⁻⁵ mol/L 的工程判据。

## 为什么这样

为什么固体不进 Ksp 表达式？与化学平衡常数同理（M3-T2-KP04）：固体的"浓度"是常数，合并进 Ksp。所以**加更多 AgCl 固体不会改变 c(Ag⁺) 或 c(Cl⁻)**——饱和溶液的离子浓度由温度唯一决定。

为什么加 Cl⁻ 能让 Ag⁺ 沉得更干净？增大 c(Cl⁻) 使 Qc > Ksp，平衡左移析出沉淀、消耗 Ag⁺——同离子效应在沉淀平衡的版本。这就是"检验 Cl⁻ 用足量 AgNO₃""沉淀完全用过量沉淀剂"的原理。

为什么升温一般促进溶解？多数沉淀的溶解吸热，升温 Ksp 增大；少数（如 Ca(OH)2）溶解放热，升温反而析出——"冷石灰热水"现象的根源。

## 典型例子与方程式

**Ksp(AgCl) = c(Ag+)·c(Cl-)**：25 ℃ 时约 1.8×10⁻¹⁰，饱和液中 c(Ag⁺) = c(Cl⁻) ≈ 1.3×10⁻⁵ mol/L。它说明"不溶"的真相——每升水仍溶着万分之几摩尔的离子。

**Fe(OH)3(s) ⇌ Fe3+ + 3OH-**：Ksp(Fe(OH)3) = c(Fe³⁺)·c³(OH⁻)，数值 ~10⁻³⁹。它说明幂次按系数写；极小 Ksp 意味着极低的 Fe³⁺ 就能沉淀——除铁杂质常用调 pH 法。

**Qc 判据示例**：向 2 mL AgNO₃ 溶液滴 1 滴 NaCl 稀溶液——若 c(Ag⁺)·c(Cl⁻) < Ksp 则无沉淀，恰好超过才出现浑浊。它说明"有浑浊"的瞬间就是 Qc 越过 Ksp 的时刻，是滴定/检验灵敏度的定量边界。

## 常见易错点

- **"难溶电解质在水里离子浓度为 0"**：错。溶解的极少部分完全电离；Ksp 恒存在。
- **"Ksp 越小的沉淀越难溶（不同类型直接比）"**：错。Ksp 量纲与幂次不同（AB 型与 AB2 型不可直接比）；同型（都是 1:1）才可比，异型要算溶解度再比。
- **"加更多固体提高饱和液中离子浓度"**：错。固体不进表达式；离子浓度只由温度定。
- **"Ksp 只与浓度有关"**：错。Ksp 与温度相关（多数随升温增大）。
- **"沉淀完全 = 该离子没了"**：错。是降到 10⁻⁵ mol/L 以下；后续的沉淀转化正建立在这个"残留"上。
