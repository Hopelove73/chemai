# 盐类水解的原理与规律

> 一句话定位：盐的离子"拆"水的电离平衡——有弱才水解、谁强显谁性、越弱越水解，三大口诀覆盖全部判断题。

## 是什么

**盐类水解**：盐的离子与水电离出的 H+ 或 OH- 结合生成弱电解质，打破水的电离平衡、使溶液显酸碱性的反应。**水解是中和反应的逆过程**（弱）。

**判断口诀**：

1. **有弱才水解，都强不水解**：强酸强碱盐（NaCl）不水解，显中性；
2. **谁强显谁性**：强酸弱碱盐（NH4Cl）显酸性、强碱弱酸盐（CH3COONa）显碱性；弱酸弱碱盐看相对强弱（CH3COONH4 近中性）；
3. **越弱越水解**：对应弱电解质越弱，其离子水解程度越大（Na2CO3 碱性强于 NaHCO3，因 CO3²⁻ 对应的 HCO3⁻ 更弱）。

**书写规范**：水解方程式用可逆号、**一般不标 ↑↓**、多元弱酸根分步水解（以第一步为主）；多元弱碱阳离子一步写成（简化）。

## 为什么这样

为什么 NH4Cl 显酸性？NH4⁺ 与水电离出的 OH⁻ 结合成弱电解质 NH3·H2O——抽走了 OH⁻，水的电离右移补位，c(H+) 超过 c(OH⁻)。本质：**盐的离子是"水电离平衡的外来抽水者"**，抽谁溶液就显谁的反面。

为什么越弱越水解？弱电解质越弱（Ka/Kb 越小），其离子结合 H⁺/OH⁻ 的能力越强——"抓住水的电离产物"的欲望越强，水解程度越大。CO3²⁻ 的"母酸"HCO3⁻ 比醋酸弱得多，所以 CO3²⁻ 水解远强于 CH3COO⁻。

为什么水解一般不标 ↑↓？水解程度通常极小（K的水解 ≈ Kw/Ka，量级 10⁻⁵ 以下），不会产生气体或大量沉淀；特例（如 Al2S3 完全双水解）才标注。

## 典型例子与方程式

**NH4+ + H2O ⇌ NH3·H2O + H+**：强酸弱碱盐的水解，显酸性。它说明水解的"抽 OH⁻"模型；also 铵态氮肥不能与碱混用的离子级解释。

**CH3COO- + H2O ⇌ CH3COOH + OH-**：强碱弱酸盐的水解，显碱性。它说明"谁强显谁性"里弱酸盐一侧。

**CO3^2- + H2O ⇌ HCO3- + OH-** 与 **HCO3- + H2O ⇌ H2CO3 + OH-**：碳酸钠的分级水解。它说明第一步主导（第二步更弱），Na2CO3 碱性 > NaHCO3 的根源。

## 常见易错点

- **"NaCl 溶液显中性是因为不水解"**：对——但表述"因为 NaOH 与 HCl 都是强电解质，无弱可水解"更准确。
- **"水解方程式写等号、标气体符号"**：错。可逆号 + 不标 ↑↓（完全双水解除外）。
- **"NaHCO3 显碱性说明碳酸氢根只水解不电离"**：错。HCO3⁻ 既水解（显碱）又电离（显酸），水解强于电离所以整体显碱——两套平衡并存。
- **"加热促进水解所以水解是吸热的，但方程式不标 ΔH"**：对，但考试要求记住"加热促进水解"用于配制防浑浊。
- **"弱酸弱碱盐水解显中性"**：错。显性与"更弱的一方"相反（如醋酸铵近中性、甲酸铵偏酸）。
