# 热化学方程式的书写

> 一句话定位：普通化学方程式加上 ΔH 和聚集状态就是热化学方程式——四条规范缺一条就是错的。

## 是什么

**热化学方程式**：标明反应热（ΔH）与物质聚集状态的化学方程式。书写规范四条：

1. **标 ΔH**：放热 ΔH < 0、吸热 ΔH > 0，单位 kJ/mol；
2. **标聚集状态**：g（气）、l（液）、s（固）、aq（水溶液）——状态不同，焓变不同；
3. **系数是物质的量**：可以是整数或分数，与 ΔH 一一对应；
4. **注明温度压强**：默认 25 ℃、101 kPa；不同条件需注明。

**同一反应的不同写法**：系数翻倍，ΔH 同步翻倍；系数减半，ΔH 减半。

## 为什么这样

为什么必须标聚集状态？H2(g) + 1/2O2(g) = H2O(l) 的 ΔH = −285.8 kJ/mol，写成 H2O(g) 则为 −241.8 kJ/mol——差值 44 kJ/mol 正是 1 mol 水的汽化热。气态水能量比液态水高，液化放热，所以生成液态水放热更多。**状态不同，始末态不同，ΔH 就不同**——不标状态，ΔH 就没有确定值。

为什么系数可以是分数？热化学方程式的系数表示物质的量（mol），不是"微粒个数"——1/2 mol O2 是完全合法的量，所以 1/2O2(g) 合法。

## 典型例子与方程式

**H2(g) + 1/2O2(g) = H2O(l)  ΔH = -285.8 kJ/mol**：液态水的标准写法。它说明燃烧热（M3-T1-KP03）规定产物必须是稳定氧化物——氢的稳定氧化物是液态水。

**H2(g) + 1/2O2(g) = H2O(g)  ΔH = -241.8 kJ/mol**：气态水写法。它与上一条对比，说明状态标注不可省——两条都"配平正确"，但 ΔH 不同。

**2H2(g) + O2(g) = 2H2O(l)  ΔH = -571.6 kJ/mol**：系数翻倍版。它说明系数与 ΔH 的线性关系：方程式乘 2，ΔH 也乘 2。

## 常见易错点

- **"不标聚集状态也算对"**：错。状态不同 ΔH 不同，不标则 ΔH 无确定值。
- **"ΔH = +285.8 kJ/mol 表示氢气燃烧放热"**：错。正号是吸热；氢气燃烧放热必须写 ΔH < 0。
- **"热化学方程式的系数必须是最简整数比"**：错。系数是物质的量，可分数；ΔH 随之变化。
- **"ΔH 的正负看反应是否需要加热"**：错。看始末态能量差；燃烧需点燃却是放热（ΔH < 0）。
