# 滴定曲线与指示剂选择

> 一句话定位：滴定曲线是 pH 随滴加量的一条 S 形——化学计量点前后 pH 突然跳变（突跃），指示剂的变色范围必须落在突跃之内。

## 是什么

**滴定曲线**：以滴入标准液体积（或百分数）为横轴、pH 为纵轴的曲线。

**四个关键点**（以 NaOH 滴定 HCl 为例）：

1. 起点：pH = 待测酸的初始 pH；
2. 半中和点：滴入 50%，pH 变化平缓；
3. **化学计量点**：恰好完全反应——强酸强碱滴定时 pH = 7（25 ℃）；
4. **突跃**：计量点前后 ±0.1% 的滴加量使 pH 骤变（如从 4.3 跳到 9.7）。

**指示剂选择原则**：指示剂的**变色范围全部或部分落在突跃范围内**——强酸强碱互滴：酚酞（8.2~10.0）或甲基橙（3.1~4.4）都可以。

**弱酸弱碱滴定的特殊性**：NaOH 滴 CH3COOH，计量点因生成 CH3COONa 水解而 **pH > 7**（约 8.7）——碱性区突跃，只能选**酚酞**；甲基橙的变色区（酸性）不在突跃内，会提前变色误判。

## 为什么这样

为什么会有突跃？计量点附近一滴标准液（约 0.05 mL）就能让剩余 H+ 与 OH- 的比值翻转几个数量级——c(H+) 从 10⁻⁴ 直落到 10⁻¹⁰，取负对数后 pH 跳 5~6 个单位。突跃是"对数标尺 + 精确中和"共同造成的。

为什么弱酸滴定的计量点偏碱？恰好中和时溶质是 CH3COONa——醋酸根水解使溶液显碱性（M3-T3-KP08）。计量点的 pH 由**产物水解**决定，不由"酸碱刚好等量"决定——所以强弱组合不同，计量点 pH 不同（强酸滴弱碱则 < 7）。

## 典型例子与方程式

**HCl + NaOH = NaCl + H2O**：强酸强碱滴定，计量点 pH = 7，突跃宽（4.3~9.7），酚酞与甲基橙皆可。它说明突跃越宽、指示剂选择余地越大。

**CH3COOH + NaOH = CH3COONa + H2O**：弱酸被强碱滴定，计量点 pH ≈ 8.7，突跃在碱性区（约 7.7~9.7），**只能选酚酞**。它说明"计量点在哪，指示剂就往哪找"——甲基橙在 pH 4.4 就变色，那时醋酸还剩一半没反应。

**由曲线判强弱**：起点 pH 相同的 0.1 mol/L 盐酸与醋酸，盐酸曲线整体更低（完全电离）、突跃起点更靠前。它说明滴定曲线还能反推"待测酸是强是弱"。

## 常见易错点

- **"计量点就是 pH = 7"**：错。只有强酸强碱互滴才是 7；弱酸被强碱滴 > 7、弱碱被强酸滴 < 7。
- **"指示剂变色点 = 计量点"**：错。指示剂只是变色范围与突跃重叠，变色点与计量点有偏差；选对指示剂是把偏差压进允许误差。
- **"酚酞可以用于任何滴定"**：错。强酸滴弱碱（如盐酸滴氨水）计量点偏酸，酚酞的变色区在碱性侧根本不经过——选甲基橙。
- **"突跃越窄越好"**：错。突跃越宽，指示剂选择越从容；窄突跃（如弱弱滴定）甚至无法用指示剂准确判断。
