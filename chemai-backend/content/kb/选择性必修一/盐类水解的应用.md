# 盐类水解的应用

> 一句话定位：水解规律落地成操作——抑制它配溶液、利用它做灭火器、净水、除锅垢，加热促水解贯穿所有"加热变浑"现象。

## 是什么

**抑制水解**（不让它发生）：

- 配制 FeCl3 溶液：Fe3⁺ 水解会浑浊，**先溶于浓盐酸再稀释**（加 H⁺ 抑制水解）；
- 配制 FeSO4 溶液：加铁粉防氧化 + 加稀硫酸防水解；
- 加热蒸发 FeCl3/AlCl3 溶液得不到无水盐——水解加剧，HCl 逸出，最终得 Fe(OH)3/Al(OH)3（甚至氧化物）；制无水盐用**在 HCl 气流中加热**。

**利用水解**（让它发生）：

- **明矾净水**：Al3⁺ 水解生成 Al(OH)3 胶体吸附悬浮物；
- **泡沫灭火器**：Al2(SO4)3 与 NaHCO3 溶液混合，Al3⁺ 与 HCO3⁻ **互相促进水解**（双水解），剧烈放出 CO2；
- **热碱液除油污**：CO3²⁻ 水解出的 OH⁻ 去油，升温促进水解、碱性增强；
- **TiCl4/ZnCl2 作焊接助焊剂**：水解呈酸性除氧化膜。

## 为什么这样

为什么 FeCl3 蒸干得不到 FeCl3？加热促进水解（吸热方向），Fe3⁺ + 3H2O ⇌ Fe(OH)3 + 3H⁺ 右移；同时 HCl 挥发带走 H⁺——**产物离开体系，水解被推向完全**。这是勒夏特列原理在"挥发性酸"上的极限版：想让水解停，就得让 H⁺ 留（HCl 气流保护）。

为什么 Al3⁺ 与 HCO3⁻ 是"完全双水解"？Al3⁺ 水解显酸性、HCO3⁻ 水解显碱性——混合后各自的产物（H⁺ 与 OH⁻）被对方消耗，两个平衡互相"抽台"，加上生成物 Al(OH)3 沉淀脱离体系、CO2 逸出——**水解被推到完全**，净结果写成 Al3⁺ + 3HCO3⁻ = Al(OH)3↓ + 3CO2↑（这才是用等号、标符号的场合）。

## 典型例子与方程式

**Fe3+ + 3H2O ⇌ Fe(OH)3 + 3H+**：FeCl3 溶液浑浊的元凶。它说明"配液加盐酸"是向平衡左边加 H⁺ 抑制水解。

**Al3+ + 3HCO3- = Al(OH)3↓ + 3CO2↑**：泡沫灭火器的净反应。它说明双水解达到完全才用等号与符号；对比单水解的可逆写法。

**CO3^2- + H2O ⇌ HCO3- + OH-**：热碱液去油的活性来源。它说明"碱性的来源是水解的 OH⁻"，升温强化。

**明矾净水**：Al3+ + 3H2O ⇌ Al(OH)3 + 3H+，胶体吸附沉降。它说明水解产物不一定"有害"——胶体正是有用的形态。

## 常见易错点

- **"加热蒸发 FeCl3 溶液可制无水 FeCl3"**：错。水解被推向完全得 Fe(OH)3；无水盐要在 HCl 气流中加热。
- **"泡沫灭火器用 Al2(SO4)3 与 Na2CO3"**：教材版本用 NaHCO3；Na2CO3 碱性过强产气 slower——写方程式时 Al3⁺ 与 HCO3⁻ 按 1∶3。
- **"双水解都用等号"**：错。只有互相促进且产物脱离体系（沉淀+气体）的完全双水解才用等号；单水解一律可逆号。
- **"明矾净水是杀菌消毒"**：错。Al(OH)3 胶体只吸附悬浮物沉降，不杀菌；杀菌要靠 HClO 等氧化剂。
