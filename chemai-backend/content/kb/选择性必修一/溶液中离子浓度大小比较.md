# 溶液中离子浓度大小比较

> 一句话定位：水解世界的"户口盘点"——电荷守恒定总账、物料守恒定母量、质子守恒定水流，三大守恒比较离子浓度。

## 是什么

**三大守恒**（以 0.1 mol/L CH3COONa 溶液为例）：

1. **电荷守恒**（阳离子正电荷 = 阴离子负电荷）：
   c(Na+) + c(H+) = c(CH3COO-) + c(OH-)；
2. **物料守恒**（各形态含同一元素的总量 = 投料量）：
   c(Na+) = c(CH3COO-) + c(CH3COOH)；
3. **质子守恒**（水电离的 H+ 去向守恒；可由前两式相减导出）：
   c(OH-) = c(H+) + c(CH3COOH)。

**比较思路**：

- 先定性（水解使谁多谁少）排出主序：如 CH3COONa 中 c(Na+) > c(CH3COO-) > c(OH-) > c(H+)；
- 再用守恒式校验与定序（找"一定大于""可能等于"）；
- 混合溶液先判断反应（过量与产物），再按生成体系排。

## 为什么这样

为什么电荷守恒永远成立？溶液整体电中性——正电荷总量必须等于负电荷总量，不管离子从哪里来（电离、水解、外加）。它是"万能校验器"：任何浓度排序若与电荷守恒矛盾，排序必错。

为什么物料守恒只数"母元素"？CH3COONa 投入的 Na 与醋酸根一一对应，水解只改"醋酸根的形态"（COO⁻ 还是 COOH），不改总量——所以 Na 的浓度 = 醋酸各形态浓度之和。

为什么质子守恒能由两式相减导出？电荷守恒 − 物料守恒（消去 Na⁺）剩下的正是"水电离出的 H⁺ 与 OH⁻ 的去向平衡"——它不是新定律，是前两者的推论，但独立写出更快捷。

## 典型例子与方程式

**c(Na+) + c(H+) = c(CH3COO-) + c(OH-)**：CH3COONa 的电荷守恒。它说明四种离子参与总账；比较时先用它排除"两个都最大"的荒唐选项。

**c(Na+) = c(CH3COO-) + c(CH3COOH)**：物料守恒。它说明部分 CH3COO⁻ 水解变成 CH3COOH——所以 c(Na+) > c(CH3COO-)，差距正好是水解掉的那部分。

**c(OH-) = c(H+) + c(CH3COOH)**：质子守恒。它说明溶液的 OH⁻ 比裸 H⁺ 多出的量 = 被醋酸根"抓走"变成弱酸的量——碱性来源一目了然。

**NH4Cl 溶液**：c(Cl⁻) > c(NH4⁺) > c(H⁺) > c(OH⁻)。它说明酸性体系主序同型（阴离子最多），只是酸碱离子对调。

## 常见易错点

- **"水解了所以 c(Na+) 也变"**：错。Na⁺ 不水解，c(Na+) 是"基准量"；变的是醋酸根的形态分配。
- **"质子守恒要另起炉灶推导"**：不必。电荷守恒与物料守恒相减即得；考场上现场减最快。
- **"c(CH3COO-) 一定大于 c(OH-)"**：对（0.1 mol/L）——但极稀时接近中性，c(OH-) 可能逼近 c(CH3COO-)；浓度极端要重排。
- **"混合体系直接套单一盐排序"**：错。先写反应（中和/沉淀）判断剩余与产物，再对**最终体系**用三守恒。
- **"电荷守恒里的离子可漏写"**：错。漏写任何一个离子（包括 H⁺、OH⁻）守恒式就废了。
