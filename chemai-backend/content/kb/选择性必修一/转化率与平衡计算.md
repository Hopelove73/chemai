# 转化率与平衡计算

> 一句话定位：平衡计算的通用格式是"三段式"——起始、转化、平衡三行一列，转化率与 K 都从这三行读出。

## 是什么

**转化率 α = 已转化的量 / 初始量 × 100%**（对某反应物而言）。
**产率 = 实际产量 / 理论产量 × 100%**（对产物而言）。

**三段式**解题模板（以 N2 + 3H2 ⇌ 2NH3 为例，设容器体积 V）：

```
            N2        +   3H2      ⇌   2NH3
起始(mol)    a             b             0
转化(mol)    x             3x            2x
平衡(mol)   a-x           b-3x          2x
```

转化行按**系数比**写（这是三段式的灵魂），平衡行 = 起始 + 转化（对反应物是 −）。浓度 = 物质的量 / V；把平衡浓度代入 K 表达式即可解出未知数。

**气体分子数变化型**还要结合总压、平均摩尔质量等辅助条件建立第二个方程。

## 为什么这样

为什么转化行必须按系数比？转化的量是"实际发生的反应量"，它天然服从方程式计量关系——N2 转化 x 则 H2 必转化 3x、NH3 生成 2x。这是三段式唯一需要"想"的地方，其余都是代数。

为什么恒容时可用物质的量直接代替浓度进 K？K 的表达式用浓度；恒容下浓度比 = 物质的量比，体积 V 在分子分母间约去——但**气体分子数改变的反应**，K 表达式的 V 不会完全约去，需保留体积。写 K 时始终提醒自己"进去的是浓度"。

## 典型例子与方程式

**N2(g) + 3H2(g) ⇌ 2NH3(g)**：某温度下向 2 L 恒容容器充入 2 mol N2 与 6 mol H2，平衡时 NH3 为 2 mol → 转化 N2 1 mol、H2 3 mol → 平衡 N2 1 mol、H2 3 mol → c(N2) = 0.5、c(H2) = 1.5、c(NH3) = 1 mol/L，K = 1²/(0.5×1.5³) ≈ 0.59。它说明三段式 + K 表达式是平衡计算的标准链路；N2 转化率 = 1/2 = 50%。

**产率示例**：理论产量 2 mol NH3，实际得 1.4 mol → 产率 70%。它说明产率衡量的是"实际与理论的差距"，与转化率（投料的转化比例）是两个指标。

## 常见易错点

- **"转化率 = 平衡时剩余量/初始量"**：反了。转化率用**已转化**的量；剩余量算出的是"剩余率"。
- **"三段式转化行自己设数不按系数比"**：错。转化行必须严格按系数比，否则后续全错。
- **"平衡时各组分浓度之比等于系数比"**：错。**转化**的浓度之比才等于系数比；平衡浓度之比由初始投料与限度共同决定。
- **"恒压体系也用同一体积算浓度"**：错。恒压下体积随反应变（气体分子数变时），要先由气态方程或比例求出平衡体积。
- **"产率可以超过 100%"**：错。超过说明理论值算错或产品含杂质。
