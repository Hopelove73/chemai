# 影响化学反应速率的因素（深化）

> 一句话定位：用有效碰撞与活化能给必修二的三大因素"装上发动机"——升温和催化剂都是提高"有效碰撞比例"，但机理完全不同。

## 是什么

**有效碰撞理论**：化学反应发生的条件是反应物微粒发生**有效碰撞**——既要有足够的**能量**（达到活化能门槛），又要有合适的**取向**。

**活化能**：活化分子的最低能量与分子平均能量的差。活化能越低，普通分子越容易跨过门槛，反应越快。

**各因素的影响机理**：

1. **浓度**：增大浓度 → 单位体积内分子总数增多 → 有效碰撞**频率**增大（分子能量分布不变）；
2. **温度**：升温 → 分子能量普遍提高 → **活化分子百分数**大幅增大（这是主因，同时碰撞频率也略增）；
3. **压强**：只对气体有效，恒容加压 = 压缩体积 = 增大浓度（机理同浓度）；
4. **催化剂**：改变反应路径、**降低活化能** → 活化分子百分数大增；不改变化学平衡。

## 为什么这样

为什么升温对速率的影响远大于浓度？浓度增加只线性增加碰撞次数（例如分子数翻倍、碰撞约翻倍）；而升温使能量超过门槛的分子比例**指数级**增长——每升 10 ℃ 速率约增 2~4 倍。两种机理的"杠杆长度"不同。

催化剂为什么不影响平衡？它同等程度加快正、逆反应（降低两侧活化能），只缩短到达平衡的时间，不改变平衡点。催化剂也不能改变 ΔH——路径变了，始末态没变（盖斯定律）。

## 典型例子与方程式

**2H2O2 --MnO2--> 2H2O + O2↑**：MnO2 作催化剂降低分解的活化能。它说明催化剂的"改变路径"本质：用两步低门槛反应替代一步高门槛反应。

**活化能图像**（反应进程-能量图）：催化剂降低活化能，但反应物与生成物的能量差（ΔH）不变。它说明"催化剂加快反应但不改变放热多少"——两条论断都从同一张图读出。

**温度对比实验**：两支试管同浓度 H2O2，一支加热——加热的气泡明显更快。它说明升温提高活化分子比例；对比实验只允许一个变量。

## 常见易错点

- **"升温使活化能降低"**：错。活化能是反应固有属性，升温不改变门槛，只是更多的分子跨过了门槛。
- **"催化剂降低活化能所以放热更多"**：错。ΔH 与路径无关；催化剂既不改变 ΔH 也不改变平衡。
- **"加压对任何反应都加速"**：错。只对有气体参与的反应有效；恒容充入惰性气体各组分浓度不变，速率不变。
- **"增大活化分子百分数与增大分子总数是一回事"**：错。浓度增大改变的是总数（百分数不变），升温改变的是百分数（总数不变）。
