# 沉淀的生成、溶解与转化

> 一句话定位：Ksp 的三大操作——加沉淀剂"生成"、酸/络合剂"溶解"、Ksp 大变小"转化"，方向永远朝更难溶。

## 是什么

**沉淀的生成**：加过量沉淀剂，使 Qc > Ksp；"沉淀完全"判据：残留离子浓度 < 10⁻⁵ mol/L。

**沉淀的溶解**：降低平衡中的离子浓度使 Qc < Ksp——三条路径：

1. **酸溶**：加酸消耗 OH⁻/S²⁻/CO3²⁻（生成弱电解质），如 Mg(OH)2 溶于盐酸；
2. **络合溶解**：加氨水溶 AgCl（生成 [Ag(NH3)2]⁺）；
3. **氧化还原溶解**：把离子变价脱离平衡。

**沉淀的转化**：向含沉淀 A 的悬浊液加沉淀剂 B，若 B 的 Ksp 更小（同型），则 A 逐渐转化为 B：**转化方向 = 由 Ksp 大到 Ksp 小（更难溶）**。AgCl → AgI（白→黄）、CaSO4 → CaCO3（锅垢处理）、FeS → CuS 都成立；反方向（AgI → AgCl）不发生。

## 为什么这样

为什么转化总是"Ksp 大变小"？悬浊液中存在微量自由离子（如 AgCl ⇌ Ag⁺ + Cl⁻ 的 c(Ag⁺) ≈ 10⁻⁵），加入 I⁻ 后 c(Ag⁺)·c(I⁻) 远超 Ksp(AgI)——AgI 立即析出，又拉动 AgCl 溶解补充 Ag⁺……循环往复直到 AgCl 耗尽。**"更难溶"的沉淀是离子浓度的更深渊**，溶解平衡自然流向它。

为什么酸能溶解 Mg(OH)2 却几乎不溶 AgCl？酸溶的本质是 H⁺ 消耗 OH⁻ 使 Qc < Ksp——含 OH⁻/CO3²⁻/S²⁻ 的沉淀可酸溶；AgCl 电离不产 H⁺ 可抓的离子，加硝酸不溶解（这正是"不溶于稀硝酸"作为 Cl⁻ 检验特征的原理）。

为什么锅垢（CaSO4）能用碳酸钠处理？CaCO3 的 Ksp 比 CaSO4 小三个量级，Na2CO3 溶液把 CaSO4 转成疏松的 CaCO3，再用盐酸轻松清除——**先转化再酸溶**是流程题的经典组合拳。

## 典型例子与方程式

**AgCl + I- ⇌ AgI + Cl-**：白色沉淀变黄色。它说明转化方向由 Ksp（AgCl 1.8×10⁻¹⁰ > AgI 8.5×10⁻¹⁷）决定——与"谁先沉淀"的判据同源。

**CaSO4 + CO3^2- ⇌ CaCO3 + SO4^2-**：锅垢转化。它说明工业除垢两步走：先转化（Ksp 小 3 个量级，可行）再酸溶。

**FeS + Cu2+ = CuS + Fe2+**：Ksp(CuS) 极小，含铜废水用 FeS 沉淀剂净化。它说明"Ksp 越小沉淀剂越灵"，废水除重金属按此选药剂。

**Mg(OH)2 ⇌ Mg2+ + 2OH-**：加盐酸溶解。它说明酸溶是"抽走 OH⁻ 使 Qc < Ksp"。

## 常见易错点

- **"任何沉淀都能用硝酸溶解"**：错。AgCl、BaSO4 等不含易被 H⁺ 消耗的离子，加酸不溶；不溶于稀硝酸正是 Cl⁻/SO4²⁻ 检验的特征。
- **"沉淀转化可以 Ksp 小变大"**：错。一般只能"难溶→更难溶"；反向需极端条件（如高浓度配体），中学阶段认为不发生。
- **"加沉淀剂越多沉淀越完全，越多越好"**：错。过量沉淀剂可能引入新杂质或使部分沉淀溶解（如 AgCl 溶于浓盐酸成络合物）；"适量/稍过量"才是流程规范。
- **"Ksp 小的沉淀一定先析出"**：错。**开始沉淀所需的沉淀剂浓度**小的先析出——不同类型（AB 与 AB2）要用所需 c(沉淀剂) 比较，不是直接比 Ksp。
