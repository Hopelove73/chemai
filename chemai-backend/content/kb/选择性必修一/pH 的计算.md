# pH 的计算

> 一句话定位：强酸强碱的 pH 计算就三条路——直接算、稀释看倍数、混合先换算再合并，弱电解质与极限端另立规矩。

## 是什么

**三类基本计算**：

1. **直接算**：强酸 c(H+) = c（一元强酸全部电离）→ pH = −lg c(H+)；强碱先算 c(OH-)，再用 Kw 换算 c(H+) = Kw/c(OH-)，**不要用 c(OH-) 直接取负对数**（那是 pOH）；
2. **稀释**：25 ℃ 强酸 pH = a 稀释 10ⁿ 倍 → pH = a + n；强碱 pH = b 稀释 10ⁿ 倍 → pH = b − n。**无限稀释趋近 7（不到 7）**；弱酸弱碱稀释 10ⁿ 倍 pH 变化小于 n（电离补充）；
3. **混合**：酸 + 酸：c(H+)混 = (c1V1 + c2V2)/(V1 + V2)；碱 + 碱：先合并 c(OH-) 再换 Kw；**酸 + 碱**：先判断过量——谁过量按过量者算，恰好中和则 25 ℃ 时 pH = 7（强酸强碱）。

**体积近似**：同浓度稀溶液混合，体积可加和（V1 + V2）。

## 为什么这样

为什么强碱要先绕道 Kw？pH 定义在 c(H+) 上：NaOH 溶液里的 H+ 不是 0，而是被 OH- 压到 Kw/c(OH-)——直接对 c(OH-) 取负对数得到的是 pOH，还要再换 pH = 14 − pOH。绕道虽麻烦，但不会把"碱的 pH"算成负数错位。

为什么弱酸稀释 pH 变化小于 n？稀释促电离：浓度降的同时电离程度增大、补出新的 H+，抵消一部分稀释——所以 pH"涨得慢"。这也是"稀释相同倍数后弱酸 pH 更小（仍更酸）"的来源。

为什么酸碱混合先看过量？恰好中和时 H+ 与 OH- 谁也不剩，溶液酸碱性由盐决定（强酸强碱盐中性）；一旦过量，剩余的 H+ 或 OH- 定调——过量判断错了，后面全是白算。

## 典型例子与方程式

**c(H+)混 = (c1V1 + c2V2)/(V1+V2)**：pH = 2 与 pH = 4 的盐酸等体积混合，c(H+) = (10⁻² + 10⁻⁴)/2 ≈ 5×10⁻³ → pH ≈ 2.3。它说明"大吃小"：混合 pH 由浓的决定，两酸混合 pH 介于两者之间且偏向浓的。

**25 ℃ 强酸 pH = a 稀释 10^n 倍 → pH = a + n**：pH = 2 的盐酸稀释 1000 倍 → pH = 5。它说明强酸稀释的整数规律；再稀释下去 pH → 7 封顶。

**pH = 12 的 NaOH 与 pH = 2 的盐酸等体积混合**：c(OH-) = 10⁻² = c(H+) → 恰好中和 → pH = 7。它说明"pH 相加 = 14 的酸碱等体积恰好中和"（25 ℃）——对称性来自 Kw = 10⁻¹⁴。

## 常见易错点

- **"两酸混合 pH = (pH1 + pH2)/2"**：错。pH 是对数，混合要**先回浓度**再合并、再取对数。
- **"强碱稀释 10ⁿ 倍 pH 加 n"**：反了。碱稀释碱性变弱，pH 减小。
- **"pH = 6 的酸稀释 100 倍变 pH = 8（变碱）"**：错。酸稀释无限趋近 7 而不超过；越过 7 是把水也当成"产物"了。
- **"弱酸稀释与强酸稀释 pH 变化相同"**：错。弱酸电离补偿，变化小于 n。
- **"酸碱混合不判断过量直接平均"**：错。先比 n(H+) 与 n(OH-)。
