# 金属的腐蚀与防护

> 一句话定位：金属腐蚀就是自发原电池反应"吃"掉金属——析氢与吸氧两种正极，外加牺牲阳极与外加电流两种保护法，全部用电极反应式说清。

## 是什么

**金属腐蚀**：金属或合金与周围接触的气体或液体发生氧化还原反应而引起损耗的现象。本质：**金属原子失去电子被氧化**（M → M^n+ + ne-）。

- **化学腐蚀**：金属与氧化剂直接反应（无电流），如铁与氯气；
- **电化学腐蚀**：不纯金属与电解质溶液接触构成原电池，**较活泼金属作负极被腐蚀**——腐蚀的主因。

**钢铁的电化学腐蚀**（两种正极反应）：

1. **析氢腐蚀**（酸性较强环境）：正极 2H+ + 2e- = H2↑；
2. **吸氧腐蚀**（中性/弱酸性，最普遍）：正极 O2 + 2H2O + 4e- = 4OH-。生成的 Fe(OH)2 继续被 O2 氧化为 Fe(OH)3，失水成铁锈（Fe2O3·xH2O）。

**防护方法**：

1. **改变结构**：制成合金（不锈钢）；
2. **加保护层**：涂油、刷漆、搪瓷、镀层（镀锌=牺牲保护，镀锡=破损后反加速铁腐蚀）；
3. **电化学保护**：
   - **牺牲阳极法**：接更活泼金属（Zn），Zn 作负极被腐蚀，铁作正极受保护；
   - **外加电流法**：被保护金属接电源**负极**作阴极，废铁接正极作阳极。

## 为什么这样

为什么吸氧腐蚀更普遍？钢铁表面的水膜通常酸性很弱（溶有 CO2），H+ 浓度低；而空气中的 O2 不断溶入水膜，供氧充足——所以中性环境里吸氧反应主导。只有强酸环境才轮到析氢腐蚀。

镀锡铁（马口铁）破损后为什么反而锈得更快？Sn 比 Fe 不活泼，破损处 Fe-Sn-电解液构成原电池，**Fe 作负极**被加速氧化；镀锌铁（白铁皮）相反——Zn 作负极"替死"，Fe 受保护。**保护层的价值取决于镀层与基底的活泼性关系**。

外加电流法为什么接负极？电解池的阴极发生还原、不被氧化；把被保护金属强制接在电源负极，它就"想失电子也失不成"。

## 典型例子与方程式

**Fe - 2e- = Fe2+（腐蚀负极）**：钢铁腐蚀的核心半反应。它说明腐蚀本质是铁被氧化。

**O2 + 2H2O + 4e- = 4OH-（吸氧腐蚀正极）**：中性水膜中的正极反应。它说明吸氧腐蚀消耗 O2——这正是"隔绝空气可防锈"的原理。

**2Fe + O2 + 2H2O = 2Fe(OH)2**：吸氧腐蚀总反应，Fe(OH)2 再氧化失水成铁锈。它说明铁锈的来源链条：Fe → Fe(OH)2 → Fe(OH)3 → Fe2O3·xH2O。

**牺牲阳极法**：Zn - 2e- = Zn2+（Zn 作负极），Fe 作正极受保护。它说明"牺牲"指的是活泼金属被氧化消耗。

## 常见易错点

- **"析氢腐蚀是钢铁腐蚀的主因"**：错。吸氧腐蚀更普遍；析氢只在酸性较强的环境。
- **"镀锡铁比镀锌铁更耐用"**：不严谨。镀层完整时两者都好；一旦破损，镀锡铁的基底铁被加速腐蚀，镀锌铁反而受保护。
- **"牺牲阳极法中铁作阳极"**：错。铁作**正极**（原电池术语）受保护；"牺牲阳极"指被牺牲的活泼金属作负极。该法是原电池原理。
- **"外加电流法把被保护金属接正极"**：反了。接负极作阴极才受保护；接正极会被加速腐蚀。
