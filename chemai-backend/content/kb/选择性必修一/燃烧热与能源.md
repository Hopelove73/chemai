# 燃烧热与能源

> 一句话定位：燃烧热的定义带着三重限定——1 mol 可燃物、完全燃烧、生成稳定氧化物，缺一不可；中和热则固定为生成 1 mol 水的稀溶液反应。

## 是什么

**燃烧热**：在 101 kPa 时，**1 mol 物质完全燃烧**生成**稳定氧化物**所放出的热量（ΔH < 0）。

三重限定：

1. **1 mol 可燃物**：以可燃物为基准（"每 mol"锚定可燃物，不是 O2）；
2. **完全燃烧**：C → CO2（不是 CO）、H → H2O(l)（不是 H2O(g)）、S → SO2；
3. **稳定氧化物**：产物是该元素最稳定的燃烧产物。

**中和热**：稀溶液中，强酸与强碱发生中和反应生成 **1 mol H2O** 所放出的热量，约 **57.3 kJ/mol**。

**能源**：一次能源（煤、石油、天然气、太阳能、风能、核能）与二次能源（电能、氢能、水煤气）；化石能源不可再生，新能源开发的核心指标是能量密度与清洁性。

## 为什么这样

为什么产物必须"稳定氧化物"？燃烧热用于比较燃料的放热能力，基准必须统一：若氢的产物一会儿是 H2O(g)、一会儿是 H2O(l)，数值就差 44 kJ/mol，无法比较。所以人为规定——碳到 CO2、氢到液态水。CO 不算碳的稳定氧化物，所以"1 mol C 燃烧生成 CO 放出的热"不是燃烧热。

为什么中和热是 57.3 kJ/mol 而酸碱不同数值略有差异？稀溶液中强酸强碱的中和实质都是 H+(aq) + OH-(aq) = H2O(l)，本质相同所以数值恒定；弱酸弱碱因电离吸热，实测放热偏小。

## 典型例子与方程式

**C(s) + O2(g) = CO2(g)  ΔH = -393.5 kJ/mol**：碳的燃烧热为 393.5 kJ/mol。它说明产物必须是 CO2——若写生成 CO，就违背"完全燃烧"限定。

**H2(g) + 1/2O2(g) = H2O(l)  ΔH = -285.8 kJ/mol**：氢的燃烧热 285.8 kJ/mol。它说明氢的稳定氧化物是液态水；氢的热值高、产物清洁，是理想能源，但储运是瓶颈。

**HCl(aq) + NaOH(aq) = NaCl(aq) + H2O(l)  ΔH = -57.3 kJ/mol**：强酸强碱稀溶液的中和热。它说明中和热的本质是 H+ 与 OH- 结合成水。

## 常见易错点

- **"1 mol H2 燃烧生成 H2O(g) 放出的热就是氢的燃烧热"**：错。稳定氧化物是 H2O(l)；生成气态水不是完全燃烧定义下的燃烧热。
- **"燃烧热是正值"**：错。放热 ΔH < 0；说"燃烧热为 393.5 kJ/mol"是取绝对值叙述，写 ΔH 时必须带负号。
- **"弱酸与强碱的中和热也是 57.3 kJ/mol"**：错。弱酸电离吸热，实测放热偏小。
- **"能源就是燃料"**：错。能源包括一次与二次、可再生与不可再生；电能是二次能源。
