# Design: knowledge-map

## D1. 边的生成与确认（无外部数据）

- 证据两类：**共现**（同一张卷/同批练习同时出现的知识点对）与**错因迁移**（前置未掌握的学生在后继知识点错误率显著更高——用既有 barrier/正确率数据统计）
- `propose_knowledge_edges`（teacher persona 工具）：LLM 依据证据 + 化学学科常识提议候选边（每条带依据一句话），**走确认门**逐边采纳/驳回；采纳落 `knowledge_edges{from_kp, to_kp, status: active|disabled}`，驳回不留痕（重提议可见历史）
- 边可随时在教师端禁用（status=disabled）——错边立即退出就绪过滤，不等重新生成
- 冷启动：无边班级地图页显示引导态（「老师还没有建立知识点关系」），不对学生开放空图

## D2. 就绪过滤与路径（纯函数）

- 状态机（知识点级）：`锁定`（任一 active 前置 <0.7）→ `就绪`（全部前置 ≥0.7 自身 <0.9）→ `精通`（≥0.9）；阈值 0.7/0.9 与四级映射同源（mastery-visualization 的常量复用）
- 「当前可学」= 全部就绪节点（ALEKS 原则：只呈现准备好了的）；路径展示 = 从已精通节点出发的拓扑序列前 N 步，不做全图布局
- 阈值与遍历写成纯函数 + 单测；环检测（提议出环的边集合在确认门前警告）

## D3. 工件绑定走既有分发契约

- 节点 → 工件只链接**已通过 share_artifact 确认门分享**的版本（工件分发 ADR：学生只见被分享版本，不自动见新版）；绑定记录 `artifact_id` + 分享快照语义由既有 shared 端点保证
- 节点点击：有已分享工件 → 播放入口；无 → 只显示状态与「练习此点」
- 「练习此点」= 批 2 smart-practice 定向会话（指定知识点范围）；依赖注入为可选——地图页在批 2 未落地时降级为跳错题本

## D4. 视图与路由

- 学生端：`/m/map` 新页（移动守卫组内）；节点卡式列表（拓扑分层）而非力导向图——430px 不放复杂 canvas 图
- 教师端：复用桌面 ChatPage 的 navigate 矩阵新增 `map` 页目标（populate/action 语义随页补充）；教师视图含全部节点状态 + 边管理（启用/禁用）
- artifact kind 集合不动（animation/slides 现有 kind 即可承载），契约测试不受影响
