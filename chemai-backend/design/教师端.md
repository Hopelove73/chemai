## 端内规则（总册之外的教师端 MUST/NEVER）

> v2.1（2026-09-14 晚）：应用户验收反馈，「深色 AI 嵌板」与「Oxford Blue 实底侧边栏」废止；恢复 main-bg/nav-bg 品牌底图 + 玻璃拟态分层；主操作按钮升级品牌渐变（学术青→靛蓝，GAP-02 复活）。以下规则按 v2.1 口径书写。

- **R-T-C1** 主操作按钮 MUST Oxford Blue 实底白字；NEVER 用薰衣草蓝或 Teal 做主按钮。
- **R-T-C2** 薰衣草蓝岗位四限：焦点环 / 链接 / 选中态 / 交互动效；NEVER 大面积填充、NEVER AI 元素、NEVER 主按钮。
- **R-T-C3** 页面底 `canvas`、分区 `surface-muted`、卡片 `surface`；文字三级 `text`/`text-secondary`/`text-muted`。
- **R-T-C4** 语义状态一律「浅底深字」标签式（success/warning/error 三对值）。
- **R-T-L1（v2.1 修订）** 原深色 AI 嵌板经用户验收否决废止。AI 工作台 = 氛围底图上的浅色玻璃舱：`bg-white/70~75 + backdrop-blur` 磨砂卡、品牌青 AI 气泡、渐变主按钮。`dark_panel` token 区仅保留备用，NEVER 用于常规页面。
- **R-T-L2** 侧边栏 = `nav-bg` 品牌底图（浅色纹理）+ 深字，激活项 `primary-soft` 底 + 元素符号 tile 渐变，232px，平板折叠图标化。
- **R-T-L4**（v2.3 增）窄屏三档折叠：<1280 内容区自然缩（现状）；<1100 表格次要列收进展开行（ExamPage / StudentsPage / OcrSheetsPage），侧栏收成 56px 图标条；<860 多列队列页（PendingGatesPage）砍至关键列。
- **R-T-L3** KPI 大数字用 JetBrains Mono + tabular-nums，NEVER 用比例数字（对齐跳动）。
- **R-T-F1** 登录页可用 `login_moment` 深色画布一次；登录后的工作台 NEVER 出现大面积深色（AI 嵌板除外）。

## 管理页（admin-shell-v2，2026-11-04 起的形态）

> 取代 admin-console-p0 的「平铺侧栏」形态：管理功能不再是教师侧栏里的若干格，
> 而是**同一侧栏的第二种模式**。

### 双模式侧栏

| | 教学态（默认） | 管理态 |
|---|---|---|
| 触发 | 路由不以 `/admin` 开头 | 路由以 `/admin` 开头（**由路由决定，无额外开关状态**） |
| 侧栏内容 | 8 项教学功能 | 五组折叠：概览 / 组织与账号 / 内容与 RAG / 运营与安全 / 系统 |
| 入口 | 侧栏底部「⚙ 管理中心」（仅 `caps.menus` 含任一 `admin_*` 时渲染） | 侧栏顶部「← 返回教学」 |
| 品牌副标题 | `CHEMAI · 教师端` | `CHEMAI · 管理中心` |

**规则**
- 教学态侧栏 MUST NOT 出现任何管理项（`isAdminKey()` 过滤）——15 项平铺是这一条的反面教材。
- 「返回教学」回到**进入管理态前的最后一个教学页**（`sessionStorage: chemai_last_teach_path`，默认 `/chat`），刷新后仍可返回。
- 分组默认收起；**当前页所在组自动展开**；展开状态在会话内记住（`chemai_admin_expanded`）。
- 分组名与组序是前端常量（`src/lib/admin-nav.ts` 的 `ADMIN_GROUPS`）；后端 `MENUS` 只声明 `group` 字段。权限真源仍在后端矩阵。
- 旧路由 `/admin/users` 重定向到 `/admin/teachers`（书签兼容），不再是一条独立路由的菜单归属。

### 管理概览（八图）

每张图 MUST 有下钻入口（图卡右上角「→」），MUST NOT 只显示数字：

| 图 | 图型 | 下钻 |
|---|---|---|
| 作答趋势（近 12 个月） | 柱（作答量）+ 折线（正确率，双轴） | 班级学情 |
| 家长激活漏斗 | 三段进度条（绑定 → 有账号 → 近 7 天活跃） | —（未采集时显示「未采集」） |
| 班级对比 | 点图（班级点 + 年级基准虚线，标 n） | 班级学情 |
| 学业预警 | 两段 StatCard（已识别 / 已处理） | 班级学情 |
| 知识点掌握热力 | 热力（班 × 知识点，缺样本留灰） | 知识地图 |
| 风险学生散点 | 散点（x=作答量, y=正确率, 大小=作答量） | 学生管理 |
| 薄弱知识点 TOP10 | 横向条形 | 诊断分析 |
| 考试得分率分布 | 直方（每生每场得分率分档） | — |

**小样本纪律（R-ADM-1）**：n≥30 给百分比；10≤n<30 给点+中位数；4≤n<9 只给人数；n<4 只给名单；n=0 不画零值。落地为 `src/lib/overview-charts.ts` 的 `sampleTier()` / `formatPercent()`，新图 MUST 复用。

**诚实空态（R-ADM-2）**：未测（无样本）留灰不填 0；缺数据源显示「未采集」不显示 0；没有闭环数据时明示「闭环未接入」，不画处理率（0% 会被读成"没处理"）。

**分块禁用语义（R-ADM-4）**：KB「文档与分块」页禁用某块后，检索**立即**不再命中（排除表在检索侧生效）；全部候选被禁用时按「知识库未覆盖」拒答，不留空资料。

**色阶归一（R-ADM-3）**：热力图只展示最弱的 N 个知识点，色阶在这 N 个内部归一，并在脚注说明——绝对 0–100% 色阶会让整片饱和成同一种红。

## 管理页（admin-console-p0，2026-11-04 首次交付 —— **已被上一节取代，仅作历史记录**）

管理员（admin / academic_admin / super_admin）与教师共用同一工作台壳与侧栏，
管理页**不是新端、不引入新接缝**——全部沿用本册 token 与组件，仅以下参数登记：

**页面与元素符号（R-T-L2 tile 惯例，`MENU_REGISTRY` 为展示真源）**

| 菜单 key | 路径 | 符号 | 页面 |
|---|---|---|---|
| admin_overview | `/admin` | `Pt` | 管理概览（KPI = P-06，`StatCard`；待办卡可跳对应管理页） |
| admin_users | `/admin/users` | `Mn` | 教师审批 / 教师账号 / 班级管理（三 Tab） |
| admin_school | `/admin/school` | `Pb` | 学校设置（未初始化时为建校表单） |
| admin_logs | `/admin/logs` | `Rn` | 操作日志（只读审计消费） |

**端内规则（管理页补充）**

- 表格用 antd `Table as AntTable`（StudentsPage/ClassPage 同款先例），窄屏按 **R-T-L4** 三档折叠。
- 审批/删除/重置等异步动作 MUST 走 `ActionButton`/`useAsyncAction`（总册 R-I6）；
  批准（不可逆方向）行内两段式（R-I5），驳回必附意见（R-I2）。
- 审批通过后的一次性凭据（教师初始密码）用 Modal 展示，NEVER 出现在列表里。
- 空态用 `EmptyState`（烧杯 + 行动引导）；超管未 break-glass 的空态是**提示性空态**，
  NEVER 用 0 值冒充数据。
- 侧栏高亮匹配为「路径段边界 + 最长路径优先」（`/admin/users` 不亮 `/admin`）；
  `/ocr-sheets → ocr` 的老前缀映射挪进 `NAV_OWNER`，行为不变。
