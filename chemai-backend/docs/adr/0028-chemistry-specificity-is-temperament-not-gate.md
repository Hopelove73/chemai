# ADR-0028: 学科特异性是气质不是关卡——不做化学事实强制校验管线

**Date**: 2026-03-30
**Status**: Accepted（用户裁定：「化学事实先行这个倒没必要……不必特意放大」，能力升级 grilling 第 1 轮对 Q4/Q5 的否决）

## Context

能力升级调研报告曾给出一条"推荐"：动画生成前先经 chempy/RDKit 强制算出配平系数、
平衡常数、物种电荷等参数 JSON（所谓"化学事实先行"管线），硬数值 fail-closed，
以此与通用 agent 拉开"化学正确性有工具兜底"的差距。

用户否决了这条，理由：学科特点要做出来，但**不必特意放大**——它是产品的气质，
不是每条通路上的关卡。

复盘这条否决成立的技术依据：

1. **已有校验已经覆盖真正的风险面**。方程式配平/产物校验（`chemical_balance.py`
   的四维校验）在出题与 `balance_equation` 工具路径上早已存在；动画涉及反应式时，
   agent 的既有习惯就是先调这些工具（Single Agent 靠 docstring 选择）。再造一条
   管线是把同一个校验在动画通路上复制一份。
2. **教学动画的本体是表达不是计算**。微观过程不可见，粒子数量、比例夸张
   （WorkBuddy 产物里 `productCap=2` 配"水解比例已放大便于观察"的诚实标注）
   是教学法的一部分；硬数值关卡挡不住、也不该挡视觉自由度。
3. **管道的隐性成本大于收益**：chempy 新依赖、每次生成的额外延迟、fail 分支的
   用户体验（老师只想看个动画却被"配平失败"拦下）、以及为绕开关卡必然出现的
   例外清单。

## Decision

1. **不引入"化学事实先行"强制管线，chempy 不进依赖**。学科特异性由三层**轻量、
   已有或纯语言**的手段承载：
   - **渲染层**（已有）：聊天消息内方程式走 `\ce{}`（KaTeX+mhchem）、结构式走
     `[SMILES:...]` → RDKit 图；**自包含工件**（教学动画等单文件 HTML，禁外链
     CDN，KaTeX 进不去）里化学式用 `<sub>/<sup>` 或 Unicode 下标/上标——
     化学感直接可见，零新增工程。
   - **语言层**（huashu-design 方法论移植时写进技能 prompt 规范）：教学动线
     （先猜后验、宏观-微观-符号三重表征）、诚实标注约定（视觉夸张必须配文案）。
   - **工具层**（已有，自主调用）：涉及配平/审核时 agent 自行调用既有工具，
     技能模板里提示可用，不做强制。
2. **本 ADR 同时约束未来的相似提议**：任何"为学科正确性再加一道强制关卡"的
   方案（不限于动画）都要先过本 ADR——要么论证已有校验覆盖不了的新风险面，
   要么不做。

## Consequences

- 动画生成链路短、延迟低、失败面小；化学感由渲染与文案自然透出。
- 学科正确性的责任位置不变：留在既有四维校验与配平工具的路径上（题目、
  讲评稿这类**学科论断型**产物继续走它们，不受本 ADR 影响——本 ADR 限定的是
  **表达型**产物通路）。
- 若未来某类产物出现真实的学科事故案例，重开本 ADR 需给出事故证据与
  既有校验为何拦不住的分析。
