## 一、"全"的定义：三层粒度模型

| 层 | 粒度 | 行业基准 | 我们现状 |
|---|---|---|---|
| L1 教材节级 | 一节 = 一条 | 人教五册约 150 节 | **150 条，全覆盖 ✅** |
| L2 考点/细目级 | 可独立出题的最小单元 | 考纲口径 51 知识点 / 167 考点；化学自习室"必备知识点"374 条；主流题库知识树 400~800 细目 | 未拆分，仅节级 |
| L3 题库标签 | 试题侧标注文本 | — | 163 类，157 已映射（KB4a 后）；**内容级去重后全库仅 305 道独立题** |

结论：**150 是 L1 的全，不是体系的全**。老师觉得"不可能只有这么一点"是对的——缺的是 L2。
我们的目标定为 **L2 ≈ 350±50 条**（介于化学自习室 374 与题库树下限之间），理由见第五节。

## 五、为什么目标定 350±50 而不是一次到位 500+

1. **教师审校带宽**：150 篇语料老师审了四轮；350 意味着同样的轮次 ×2.3。
2. **错误率分母效应**：MIN_ANSWERS=5，拆到 500 时多数细目一学期内作答次数 <5，
   错误率列大面积空置，图谱热力反而失真。拆分粒度应满足
   "该细目一学期 ≥5 次作答"的题量下限——这正是按题量数据驱动拆、不按清单铺满的原因。
3. **检索分辨率**：bge-large 对相近概念（酯化 vs 水解）在 350 docs 规模的区分度需要实测，
   到 350 后再评估是否值得上 500。
4. **题目多样性上限（2026-10-28 深夜修订补充，最硬的一条）**：内容级去重后全库仅
   **305 道独立题**。图谱粒度超过题目多样性就是建"冷节点"——无题可挂、错误率永空。
   目标 350 里的增量必须与题库扩容配对推进；只铺图谱不进题，完备性是纸面的。
