## 1. 错误率数据链（T15 错误率权重）

```
student_answers(is_correct) → questions(knowledge_points 标签)
  → kp_tag_map(标签→词典码) → 按 code 聚合 {错误次数, 作答次数}
  → 错误率 ≥0.3 且作答 ≥5 次的知识点 → 出题 hint 注入：
     「该知识点学生错误率 X%（高频易错），易错方向：<misconceptions 或错因标签>」
```

- **真实数据校验**（2026-10-27）：15873 题映射进词典码；TOP 错误率——离子检验 89%（1206 次）、物质的量浓度 86%（1634）、铁单质 78%（1598）、元素周期律 66%（3700）。
- 注入点：`kb_graph_context_for_questions` 的 hint 组装段追加错误率行；读取失败静默跳过（与图谱故障同一降级纪律）。
- 阈值常量：`ERROR_RATE_THRESHOLD = 0.3`、`MIN_ANSWERS = 5`。

## 2. M2 词典与语料

- 词典：`content/kb/kp_dictionary_m2.json`，编码 `M2-T{n}-KP{nn}`，结构同 M1；40→75+ 条预估（硫 4/氮 4/能量速率 5/有机 8/可持续工艺 3/检验与计算 5，以课标内容要求为准）。
- 语料：`content/kb/必修二/*.md`，frontmatter/四层切块/摄取管线**零改动复用**（module=必修二）。
- 标签映射：`kp_tag_map_m2.json`——future 桶的硫氮/有机/工艺/能量类标签转正（化学反应热 1169 题、氯家族已映射、硫氮 743+656、有机 1606）；电化学/平衡/水解类留 M3。
- 有机篇（T4 新域）：延续 [SMILES:...] 惯例（共价键篇已用）；易错点侧重同系物/取代与加成的混淆。

## 3. misconceptions 结构化（Q4）

- 列：`kb_frontmatter.misconceptions_json`：`[{"wrong": "…", "right": "…", "why": "…"}]`。
- 摄取时从正文"## 常见易错点"小节按列表项正则提取；解析失败降级为空（不阻塞入库）。
- 消费方：出题 hint（陷阱定向）+ kb_context 易错增强段（可选，第二期先只做出题侧）。

## 4. 评测扩容与重标定（Q6）

- 金集：追加 15 道 M2 命中题（硫氮/能量/有机每主题 ≥2）+ 应拒题换血：kb51/54 随有机语料转为应命中，新增应拒题换选择性必修（平衡常数 K、电化学、盐类水解）。
- 重标定：0.45 在 80 篇/400+ 块语料上重跑 `--threshold` 扫描（0.40/0.45/0.50），取"命中率 ≥80% 且应拒答 ≥80%"的最优点；常量与 hint 阈值一起更新。
- 回归纪律不变：每批语料入库后必跑。
