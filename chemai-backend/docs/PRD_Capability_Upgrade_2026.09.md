## 1. Problem Statement（用户视角）

**老师（高中化学，10 年教龄）**：

- 我说"给学生做个盐类水解的微观动画"，产品只能回我一段文字。隔壁通用 agent 工作台
  已经能一键生成可交互动画、PPT、教案，做完右侧直接预览。我做完的东西**下次找不到了**，
  传上来的**答题卡图片连原图都看不到**，只给我 OCR 出来的文字卡。
- 我批改完一次考试，错题数据都在系统里躺着，讲评课还要我自己从零写讲评稿。

**学生**：错题复习现在按**固定艾宾浩斯节点**（1/3/7/14/30 天）排程，不管我实际
记得牢不牢——连着答对的卡照样按老节点来，快忘的卡也不会提前；没有"按我的记忆
表现排出来的今日清单"。

**家长**：报告里的"正确率 62%"我看不出孩子到底掌握没掌握。

**产品层面**：教学内容生产能力与交付形态（预览、迭代、分发）落后于通用 agent 客户端；
而批改/诊断数据闭环的优势没有转化成通用工具做不了的教育特异性（记忆调度、掌握度、自适应出题）。

## 2. Solution（用户视角）

三批次递进，每批可独立演示：

1. **工件链**：对话里说一句就产出**教学动画 / 课件 / 教案 / 评语 / 讲评稿**，右侧
   **可收缩工件面板**实时预览（附件原图 / 工件渲染 / 版本历史三个 tab），改一版存一版，
   做好的工件进"我的工件"库跨会话复用；发给学生、导出文件才需要确认。
2. **记忆卡**：批改完成的错题**自动**变成记忆卡（老师零操作），学生每天在"今日复习"
   里看到该复习的卡；复习即重做，自动判对错，主观题自评兜底。调度引擎从固定节点
   **升级替换**为 FSRS（记忆模型自适应）——学生端复习入口不变，排程更聪明。
3. **掌握度**：诊断和周报从"答对率"升级为**知识点掌握概率**（薄弱 Top N 一目了然）；
   自适应练习从规则匹配升级为按学生能力实时选题；家长报告保持文字化表述不出现概率数字。

学科特点的表达方式（ADR-0028）：方程式用化学式排版、结构式自动出图、微观动画带
"比例已放大便于观察"式诚实标注——**气质自然透出，不做强制校验关卡**。

## 3. User Stories

**教师 · 内容生产（批次 A）**

1. 作为老师，我想让 AI 生成一个可交互的化学教学动画（如盐类水解微观机制），省去自己
   找素材做课件动画的时间。
2. 作为老师，我想在右侧面板里**直接预览**生成的动画并与之交互（暂停、调速、切场景），
   而不是下载文件再打开。
3. 作为老师，我想对动画提修改意见（"深色看不清""加个温度滑块"），AI 修订后自动存成
   新版本，随时切回任意旧版对照。
4. 作为老师，我想生成 HTML 幻灯片课件并全屏放映，保留化学式渲染与动画效果。
5. 作为老师，我想把课件导出成 .pptx 文件用于学校统一要求的课件检查。
6. 作为老师，我想按模板生成教案（含教学目标、环节设计、板书），产物同样进面板预览迭代。
7. 作为老师，我想给全班学生生成个性化期末评语，逐条可改。
8. 作为老师，我想基于一次考试的批改数据一键生成**讲评稿**（正确率、错题分布、错因
   分析、讲评动线），不再从零写。
9. 作为老师，我在输入框想 **@** 引用刚上传的答题卡图片或上次做的动画，让 AI 拿着
   它干活，不用重新描述。
10. 作为老师，我想用 **/动画 /讲评 /课件** 这类斜杠指令直接触发技能，少打字。
11. 作为老师，我想在"我的工件"列表里按类型/时间找到三周前做的动画，点开即预览，
    不依赖翻聊天记录。
12. 作为老师，我想生成带结构式的有机化学动画，苯环、官能团自动画出（SMILES 出图），
    不用手绘。

**教师 · 附件预览（批次 A）**

13. 作为老师，我想点开上传过的答题卡/试卷图片**看原图**，右侧面板放大核对，
    而不是只看 OCR 文字。
14. 作为老师，我想让面板可收缩——投屏讲解时全屏聊天，批改核对时展开附件。

**教师 · 分发（批次 A）**

15. 作为老师，我想把做好的动画"分享给学生"，确认后学生端能看到；这是对外动作，
    系统要我确认一次（与发学习计划/家长报告同等的确认门）。

**学生（批次 A 触达 + 批次 B）**

16. 作为学生，我想在收件箱收到"老师分享的动画"，点开全屏就能看，可交互。
17. 作为学生，我批改完的错题**不用做任何事**就自动出现在复习体系里。
18. 作为学生，我想每天看到"今日复习"清单（就挂在学习计划里），数量合适、按记忆
    规律排出，而不是整个错题本压过来。
19. 作为学生，复习一张卡就是**重做那道题**：客观题做完自动判我记得/忘了；主观题
    写完自己评一档（忘了/模糊/记得）。
20. 作为学生，我连续答对的卡自动少来，快忘的卡自动先来——不用我自己安排。

**教师 · 复习与学情（批次 B/C）**

21. 作为老师，我想看班级复习进度（谁在跟、谁掉队）进周报，不用挨个问。
22. 作为老师，我想在诊断页看到**知识点掌握概率**（如"化学平衡 0.41"）和薄弱
    Top N，比正确率更接近真相。
23. 作为老师，我想布置"自适应练习"时系统按每个学生的能力实时选题（会的不刷、
    弱的多练），题目质量有既有四维审核兜底。
24. 作为老师，数据不足的题我希望系统自动退回难度先验继续可用，不要出现
    "标定一半"的半成品状态。

**家长（批次 C）**

25. 作为家长，我想在报告里看到文字化的掌握结论（"盐类水解基本掌握，化学平衡
    需巩固"），而不是看不懂的概率数字。

**管理员（批次 A）**

26. 作为管理员，我想确认工件面板与技能只对教师 persona 开放，学生/家长端不出现
    生产入口。

## 4. Implementation Decisions（产品层面的约束）

- **工件 = 可预览产物**，五类首发：动画 / 课件 / 文档 / 结构图 / 表格；每类注册一个
  前端渲染器；HTML 类在沙箱 iframe 中渲染（禁外部网络、禁同源、允许本站静态资源）。
- **迭代轻量、分发过门**：任意次版本快照；"分享给学生 / 导出文件"才走既有确认门。
- **教学技能可插拔**（ADR-0027）：新内容种类 = 注册一个技能，agent 不感知；斜杠指令
  是技能快捷键；本期不开放老师自定义技能（预留 author 字段）。
- **学科气质**（ADR-0028）：渲染层（化学式排版、SMILES 出图）+ 语言层（教学动线、
  诚实标注写进技能模板）+ 工具层（agent 涉及配平/审核时自主调用既有工具，模板提示
  可用但不强制）；**不做化学事实强制校验管线，chempy 不引入**。
- **记忆卡自动建卡 + 双信号**：判卷钩子建卡；重做自动判定为主、自评兜底；调度用
  FSRS（开源记忆调度算法，Anki 同款内核），升级替换既有固定节点调度，不并存。
- **掌握度递进**：先概率（知识追踪）后自适应选题（IRT 标定 + CAT，用演示库 7.6 万条
  作答数据冷启动跑通链路）；题库数据不足自动降级回难度 1–5 先验；家长口径永远文字化。
- 工具总数只加一（技能入口），CI 冒烟断言一次到位不再随内容种类变。

## 5. Testing Decisions（产品验收口径）

- 验收只看**外部行为**：对话→工件出现→面板可看可改可回滚→分发有确认记录；
  判卷→卡片出现→复习滚动；诊断页概率与降级行为。
- 动画验收含**结构性检查**：自包含（无外链脚本）、有参数集中区、有诚实标注文案位、
  化学式按 mhchem 排版。
- 讲评稿验收对拍批改数据（正确率/错题分布与产物内容一致）。
- 详见 Spec 的 Testing Decisions。

## 6. Out of Scope

- 论文写作 / 课题研究 / 网站开发 / 教师培训等通用办公能力（架构可承载，产品不进）。
- 老师自定义技能与技能市场；定时任务；学生端工件面板（学生只消费不分发）。
- Manim 视频管线（二期）；molstar / Remotion（license 或场景不匹配）。
- 化学事实强制校验管线（ADR-0028 明确否决）。
